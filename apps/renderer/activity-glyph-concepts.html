状态行图标：一种操作，一种动作

替换对话底部 Working 左侧的旋转星芒。三套方案各自是一门统一的“动作语言”，覆盖 12 种状态；切换操作时图标会连续变形或交融过去，而不是硬切。点任意卡片可以把它送到上面的实况区看真实尺寸。

实况模拟真实尺寸 14px · 12px 文字，与对话底部一致；右侧为 2.8× 放大

落地方式（选定后）

  • 状态来自现有 KIND_VERB 的 tool kind：read / edit / write / bash / grep·glob / web / task·hub / todo，加上 thinking、responding、waiting、retry；lsp、image、mcp 等就近归类，未知 kind 回落到“工作中”。
  • 只换 .al-glyph 这一处，文字、计时、文件图标不动；周期、曲线从 tokens.css 的 Motion 段推导，不新增字面时长。
  • 减弱动效（motionReduced() / L1 档）时每种状态停在一个能认出来的静态姿势，切换也不做过渡。
  • 开销：A 每帧只改 6 条 SVG line 的属性；B 是 25 个点的小 canvas；C 约 30 段线。都只在可见时跑一个共享 rAF。
