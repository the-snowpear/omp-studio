# Graphical acceptance samples

Tiny local valid and damaged samples for every promised format. No remote resources or executable scripts. GLB contains one triangle; ZIP exercises a local X3D texture. Inspect through preview-graphics-harness.html.

Additional samples: textured-embedded.glb embeds its PNG in a BIN buffer view; linked-usda.zip contains a root layer and a relative USDA reference. The harness also covers native numeric Markdown table charts and streamed SVG prefixes.
