四件事，就是整个工作台

  1. 拖出来就是一个窗口

    从侧栏拖一场会话到列表外，松手就是一个浮窗。移动、最小化、收回都不会重建对话，草稿、阅读位置和终端状态全部保留。

  2. 贴边吸附，六种模板

    左右边缘是半屏，四角是四分之一，顶部是最大化。新窗口吸附进来时，原来的窗口自动移到剩下最大的空位。

  3. 工具停在哪都行

    Explorer、Git、Browser、Terminal、Agents 等工具都能在左侧栏、对话工具区、右侧栏、底栏和浮窗五个位置之间移动。

  4. 钉住，或者干脆独立出去

    图钉有五档，决定窗口跟着谁走。独立窗口在任务栏有自己的图标，可以拖到另一块显示器，重启后恢复位置。

窗口之外，也在同一个应用里

最近项目一键回到工作台，集中管理 Token 用量、Time Travel 快照、Agent Hub、多模型供应商与 MCP 能力中心。

  • 首页与用量

    最近项目一键回到工作台。Token 折线图和热力图按年、月、周、日切换。

  • 会话历史与 Time Travel

    按回合保存工作区快照。可以只恢复代码、只恢复对话，或两者都恢复，恢复前会留备份。

  • Agent Hub

    集中查看主对话和全部子 Agent 的状态、请求数、Token 用量和花费。

  • 模型配置

    Anthropic、OpenAI、OpenRouter、本地 LM Studio 在同一页管理，并为不同角色指定模型和思考强度。

  • 能力中心

    Skills、Plugins、MCP 和 Slash Commands 在同一页开关和探测。

  • 设置与更新

    设置可搜索，配置按全局、项目、会话分层。应用内更新会验证签名。

常见问题

OMP Studio 和 oh-my-pi (omp) CLI 是什么关系？

OMP Studio 是 oh-my-pi（omp）的跨平台桌面工作台外壳。模型、登录状态、Skills 与会话记录都直接沿用 OMP 自身的配置和格式，并通过类型化的 Studio Bridge（query / command / event）调用 Runtime 能力，不解析终端文本，也不模拟按键。

支持哪些 AI 模型供应商？应用内需要预置或购买 API 密钥吗？

支持 Anthropic、OpenAI、OpenRouter、本地 LM Studio 等 OMP 可连接的全部供应商，并可在模型配置页为 @default、@plan、@task 角色分别指定模型和思考强度。密钥与登录完全沿用你本机的 models.yml 或 omp login，本应用与仓库不内置任何供应商密钥。

支持哪些桌面平台与 Linux 发行版？

桌面端提供 Windows x64 / ARM64 安装包（支持应用内自动更新）、macOS Apple Silicon（macOS 13+ DMG），以及 Linux x64（AppImage 与 deb，面向 Ubuntu 24.04+ / Debian 13+ 与 glibc 2.39+、支持 AVX2 的处理器）。Linux 沙箱与环境细节可查阅仓库中的 docs/linux.md。

如何连接远程 SSH 服务器、WSL 2 或在手机上继续会话？

Windows 桌面版可直接从工作区选择器进入 WSL 2 发行版目录运行 Agent、Git 和终端；SSH 工作区支持按需向远端部署经过 Ed25519 签名的运行环境，并在短时断线后自动尝试重连；在设置中开启手机访问或独立 Web 工作台后，可在局域网 HTTPS 下扫码配对手机审批工具调用或继续对话。

Time Travel、Agent Hub、Computer Use 和 WebMCP 分别有什么作用？

Time Travel 可按回合保存工作区快照并对比文件变化，支持只恢复代码、只恢复对话或两者都恢复（恢复前自动留存备份）；Agent Hub 集中展示主 Agent 与全部子 Agent 的派生关系、请求次数、Token 用量及花费；Computer Use 为每个动作留存画面并支持随时叫停与回看；聊天浏览器支持直接圈选网页元素引用进输入框及原生 WebMCP 能力。

遇到问题去哪里查看日志或反馈 Bug？

可以在应用内的「诊断中心」直接查看运行状态，或检查本机 Host 日志（Windows 位于 %APPDATA%\omp-studio\logs\，macOS 位于 ~/Library/Application Support/omp-studio/logs/）。欢迎前往 GitHub Issues 提交反馈。
