OMP Studio 是 oh-my-pi 的桌面工作台。对话、Git、终端和浏览器都是窗口：拖出来，吸附分屏，停到任意一侧，或钉成独立窗口。

下载 OMP Studio Windows 与 macOS，MIT 开源

右边下面这张是真的能用的，试试看

  1. 拖住窗口顶栏，贴到左右边缘，吸附成半屏
  2. 鼠标停在最大化按钮上点一下最大化按钮，选一个布局模板
  3. 从底部工具架再打开一个工具
  4. 点图钉钉住一个窗口，然后往下滚动
  5. 点右上角的月亮，换成深色

五项都做完了，真实的 OMP Studio 就是这样用的。去下载
