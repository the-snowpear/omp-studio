OMP Studio

给你的 Coding Agent 一个像样的家

OMP Studio 是 oh-my-pi 的桌面工作台。这扇窗不是视频，是真实界面。会话、审批和 Git 都在一扇窗口里。

    先看计划，再批准执行

    逐段批注计划，批准后才开始动手。Ask 卡片和三档权限都在 Composer 旁边。

    子 Agent 不再是黑盒

    状态、花费、上下文和实时记录一个列表看完，还能恢复或终止。

    走错了就退回去

    60+ 供应商，一处管理

    能力来自 OMP Runtime。仓库不内置任何密钥，沿用你自己的 models.yml 和 omp login。

    控制台，不是套壳终端

    界面通过类型化的 Studio Bridge 接到 Runtime，不解析 TUI 文本、ANSI 输出或按键宏。

    Renderer
    StudioClient
    Desktop IPC
    Host facade
    omp --mode studio-host

    Renderer 看不到Bridge token、进程句柄和 OMP 会话路径。

    未知操作失败关闭。accepted 只代表已受理，不等于成功。

    Runtime 断了会封住旧 epoch，没完成的操作如实标为结果未知。

    下载 OMP Studio

    版本信息读取中

    装好之后，应用内更新走差分下载和 Ed25519 验签，需要时可以恢复上一桌面版本。

    从源码运行

    需要 Node.js 22+。Linux 目前没有桌面安装包。

    查看源码 全部版本 完整步骤 
    git clone --recurse-submodules https://github.com/the-snowpear/omp-studio.git
cd omp-studio
npm install
npm run omp:overlay:apply
npm run preview

    本页内嵌的窗口和片段都运行在演示数据上，不连接真实 Runtime，也不会读取你的任何文件。
