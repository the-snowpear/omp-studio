对话是窗，工具也是窗。

OMP Studio 是 oh-my-pi 的桌面工作台。对话、Git、终端和浏览器都能拖成窗口，吸附分屏，停到任意一侧，或钉成独立的系统窗口。

下载 OMP Studio 从源码运行

Windows x64、Windows ARM64 和 macOS Apple Silicon

图 2吸附

拖到边上，它自己对齐。

拖到左右边缘占半屏，拖到四角占四分之一，拖到顶部铺满。新窗口吸附进来时，原来的窗口会移到剩下最大的空位，不会被盖在后面。

拖动标题栏试试。键盘：聚焦窗口后按 ← → 占半屏，↑ 铺满，↓ 还原为浮窗。

六种分屏模板

在应用里，把指针停在最大化按钮上 300 毫秒，就会弹出这张选择器。点一种，窗口按它排好。

  • 拖动相邻窗口的分界线，两边一起调整；双击恢复默认比例。
  • 按住 Ctrl（macOS 为 ⌘）临时关闭吸附，Esc 取消这次拖动。
图 3停靠

五个位置，工具放哪都行。

把工作台按层拆开看：左侧栏、对话工具区、右侧栏、底栏，再加上浮窗。九种工具可以在这五个位置之间随意移动。

把工具放进选中的位置

拖动超过 6 像素就会显示落点预览，松手才生效。不想拖，右键菜单或 Shift F10 也能移动。

图 4钉住

一扇浮窗，可以跟到多远。

每扇浮窗的 Pin 菜单有五档。越往右，窗口跟着你走得越远，直到离开应用，成为一扇独立的系统窗口。

    固定保留的是窗口本身。切换会话不会重启里面的 Shell，也不会改变任务的归属。独立窗口在任务栏有自己的图标，重启后恢复到原来的位置。
