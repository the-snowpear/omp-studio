Four rules, one workbench

  1. Drag out into a window

    Drag any session out of the sidebar to open a floating window. Moving, minimizing, or docking back never reloads the chat — drafts, scroll position, and terminal state stay intact.

  2. Snap edges, six templates

    Snap to halves, quarters, or maximize at the top. When a new window snaps in, existing windows automatically move into the largest remaining space.

  3. Dock tools anywhere

    Explorer, Git, Browser, Terminal, and Agents move freely across five dock locations: left sidebar, chat tools, right sidebar, bottom bar, or floating tab groups.

  4. Pin or pop out separately

    Five pin levels control what a window follows. Standalone OS windows get their own taskbar icon, move across monitors, and restore after restart.

Frequently Asked Questions

How does OMP Studio relate to the oh-my-pi (omp) CLI?

OMP Studio is a desktop workbench shell for oh-my-pi (omp). It reuses OMP's own models.yml, omp login, Skills, and session formats, invoking Runtime capabilities over a typed Studio Bridge (query / command / event) instead of wrapping a terminal or scraping ANSI text.

Which model providers are supported? Are API keys included?

All providers supported by OMP work — including Anthropic, OpenAI, OpenRouter, and local LM Studio — with separate model and thinking-effort assignments for @default, @plan, and @task. Neither the app nor this repository ships any API keys.

Which operating systems and architectures are supported?

Installers are provided for Windows x64 (Windows 10+), Windows ARM64 (Windows 11), macOS Apple Silicon (macOS 13+ DMG), and Linux x64 (AppImage and deb for Ubuntu 24.04+ / Debian 13+, AVX2, glibc 2.39+). See docs/linux.md in the repo for sandbox and update details.

Does it support SSH remote workspaces, WSL 2, and mobile access?

Yes. Windows desktop launches directly into WSL 2 distributions; SSH workspaces deploy an Ed25519-signed remote runtime and attempt automatic reattachment after brief disconnects; and LAN HTTPS mobile pairing lets you continue chats and approve tool calls from your phone.

What are Time Travel, Agent Hub, Computer Use, and WebMCP?

Time Travel saves turn-level workspace checkpoints so you can restore code only, chat only, or both (with automatic backup). Agent Hub tracks main and worker subagent states, tokens, and spend. Computer Use records per-action screenshots with pause/resume controls, while Chat Browser supports element quoting and native WebMCP.

Where can I find diagnostic logs or report bugs?

Open the in-app Diagnostics view or inspect local Host logs under %APPDATA%\omp-studio\logs\ on Windows and ~/Library/Application Support/omp-studio/logs/ on macOS. Please report issues on GitHub Issues.
