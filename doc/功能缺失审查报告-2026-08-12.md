# OMP Studio 功能缺失审查报告

**审查日期**: 2026-08-12  
**审查范围**: 前端功能与后端能力对比架构文档要求  
**参考文档**: `architecture_review_v2_work/omp-studio-complete-parity-architecture-pack-v5/`

---

## 执行摘要

当前项目已完成**核心协议层、基础命令执行和状态管理**的实现，typecheck 全部通过。但对比 v5 架构包的 Full Parity 目标，**前端缺失 5 个重要功能模块**，后端有完整支撑但前端未暴露给用户。

### 完成度评估

| 层级 | 完成度 | 说明 |
|------|--------|------|
| **协议与类型** | 95% | Studio Protocol、Client Contract 完整 |
| **后端 Host** | 85% | 21 个核心模块已实现，Agent/Job/PTY 后端存在 |
| **前端基础** | 80% | Workbench/Home/History 可用，核心命令完整 |
| **前端高级功能** | 30% | Agent Hub、TUI、Live、复合命令缺失 |

## 二、功能缺失详情

### 2.1 **Agent Hub UI** ❌ 【高优先级】

**架构要求** (05_AGENT_HUB_AND_JOBS.md):
- Agent roster/tree 展示
- Agent 控制：send/spawn/kill/revive/release
- Transcript 查看器（增量加载、opaque cursor）
- Job 列表和管理（owner scope、cancel）
- Generation CAS 防止过期操作
- Limited Runtime 精确禁用缺失控制

**当前状态**:
- ⚠️ Workbench 显示 `snapshot.agents` 和 `snapshot.jobs`，但只是简单的 4 行摘要
- ❌ 没有交互式 Agent Hub 页面
- ❌ 没有 agent.send/spawn/kill/revive/release 按钮
- ❌ 没有 transcript 查看器
- ❌ 没有 job 列表和 cancel 操作
- ✅ 后端已有完整模块支撑（Agent/Job API 在 Host 中存在）

**缺失影响**:
- 用户无法通过 GUI 管理子 agent
- 无法查看 agent 对话历史
- 无法取消或恢复 async job
- TUI Agent Hub 的功能在 GUI 不可用

**工作包**: WP-050 ~ WP-055 (M5)

---

### 2.2 **Plan Review UI** ❌ 【中优先级】

**架构要求** (04_COMMAND_REMOTE_UI_AND_TUI.md, WP-030):
- Plan proposal 展示
- Review 界面：approve/refine/dismiss
- Draft list/read
- Feedback 输入

**当前状态**:
- ✅ `mode.plan.enter/exit` 命令存在
- ✅ `mode.plan.review.open/respond` 命令定义存在
- ❌ 没有 Plan Review 专用 UI
- ❌ 没有 draft 展示组件
- ❌ approve/refine/dismiss 按钮未实现

**缺失影响**:
- Plan mode 进入后，用户无法在 GUI 中 review 和 approve plan
- 需要回退到 TUI 或等待自动执行

**工作包**: WP-030 (M3)

---

### 2.3 **TUI/Terminal 集成** ❌ 【中优先级】

**架构要求** (04_COMMAND_REMOTE_UI_AND_TUI.md, WP-046):
- PTY attach ticket
- Terminal renderer
- Manual control lease
- Interaction transfer（GUI → TUI）
- 安全边界：只接受真实键盘输入，不自动发送按键

**当前状态**:
- ✅ 后端有 `PtyTicket` 和 `RuntimePtyTransport`
- ❌ 前端完全没有终端渲染器
- ❌ 没有 terminal attach 入口
- ❌ 没有 interaction transfer 流程
- ❌ `SurfaceCapabilities.terminalAttach` 定义存在但未使用

**缺失影响**:
- 遇到 custom TUI 命令时，用户无法在 GUI 中手动操作
- 无法查看 Runtime 内部的 TUI 输出
- 无法调试 ANSI/OSC 序列问题

**工作包**: WP-046 (M4)

---

### 2.5 **Runtime 安装/升级 UI** ❌ 【中优先级】

**架构要求** (01_RUNTIME_RESOLUTION_AND_DISTRIBUTION.md, WP-003/062/064):

- ❌ 没有安装/升级触发按钮
- ❌ 没有进度条或安装日志
- ❌ 没有 channel 选择器
- ❌ 没有 rollback 操作

**缺失影响**:
- 用户无法从 GUI 安装或升级 Managed Runtime

**工作包**: WP-003/062/064 (M0, M6)
