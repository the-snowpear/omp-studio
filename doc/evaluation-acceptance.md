# 评测工作区实施与验收记录

日期：2026-11-02（Asia/Shanghai）。功能基线为项目固定的 OMP 18.13.2；没有升级上游版本。

## 已实施

- 四个模块共用 1080px 页面、配置与确认、结果、历史、复跑和导出。
- 性能基准复用原生计划解析；完整阶段请求计数、thinking、服务档位、缓存前缀、缓存证据、各阶段统计可用。
- 指令遵循使用原生题目、判分与重试，增加请求及等待重试期间的取消。
- 单项／批量评判支持三类问题、图片、Judge 角色链、按问题汇总、失败项复跑和原生批次接入。
- Ratchet 支持配置向导与代理辅助准备、三阶段审批、基线／迭代、修订、指标及判定证据、最佳版本补丁。
- Host 独立持有常驻 Runtime、审批和结果存储，页面切换不取消任务。评测后台状态入口可回到待审批任务。
- 结果明细按身份追加更新，原生报告分块读取；本机和远程导出走所属 Host。旧版报告可读，缺少输入时禁止完整复跑。
- 配置保存原生解析后的模型、有效设置与缓存前缀内容，图片保留产物引用；配置不一致的报告不直接判定性能改善。
