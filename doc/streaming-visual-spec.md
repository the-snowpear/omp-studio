## 1. 消息类型与视觉形态

对话时间线由五种行类型组成：

### 1.1 用户消息（User）

| 属性 | 规格 |
|---|---|
| 对齐 | 右对齐 |
| 气泡 | 强调色实底（`--accent`），白字（`--text-on-accent`） |
| 圆角 | 上左、上右、下左大圆角（`--r-10`），下右小圆角（`--r-4`）——尖角朝右下 |
| 最大宽度 | 78% |
| 字号 | `--fs-14`，行高 1.7 |
| 选中高亮 | 白色 38% 透明覆盖，保持白字可读 |
| 内联代码 | 白色 16% 透明底 + 白字 |
| 头部 | 右对齐：角色徽章 `S`（灰底）+ "你" + 时间 |
| 缩略图 | 气泡上方，64×64px 圆角方块，右对齐 flex-wrap |
| 文件/技能胶囊 | 气泡下方引用行 `.ev-refs`，颜色与气泡一致 |
| 操作按钮 | 悬停时出现：复制、恢复到输入框（undo 图标）、新会话（branch 图标） |
| 发送中状态 | 头部追加灰色 chip "发送中" |
| 发送失败状态 | 头部追加红色 chip "发送失败"，气泡下方显示错误信息 + "恢复到输入框"按钮 |

### 1.2 Assistant 回复（Reply）

| 属性 | 规格 |
|---|---|
| 对齐 | 左对齐，无气泡背景 |
| 头部 | 角色徽章 `π`（强调色底）+ "OMP" + 时间 + 可选状态 chip |
| 正文 | Markdown 渲染，字号 `--fs-14`，行高 1.75 |
| 子元素间距 | 统一 `--sp-10` gap（头部、工具链、正文、变更卡、计划入口） |
| 操作按钮 | 悬停时右上角出现复制按钮 |
| 已中止 | 头部灰色 chip "已中止" |
| 出错 | 头部红色 chip "出错" |
| 模型错误详情 | 红色边框卡片，显示 `[status · provider · model]` + 错误消息 |

### 1.3 Assistant 过程（Process）

| 属性 | 规格 |
|---|---|
| 对齐 | 左对齐，紧贴上方 Reply 行 |
| 头部 | **不显示**（隐藏重复的头像和名称） |
| 间距 | 与前一行的间距更紧（`--sp-10`） |
| 内容 | 仅工具链 / 思考块，无最终文本回复 |
| 折叠后 | 显示为单行批次摘要 |

### 1.4 上下文压缩（Compaction）

| 属性 | 规格 |
|---|---|
| 形态 | 水平分割线居中文字 |
| 文字 | "**Compact** · {摘要标签}" |
| 图标 | minimize 图标在左 |
| 可折叠 | 有详情时：点击展开压缩摘要内容（chevron 箭头指示） |
| 摘要区 | 展开后最大高度 `min(40vh, 28rem)`，自带滚动 |
| 进行中 | 线条减淡 + spinner + "压缩中"文字，强调色 |

### 1.5 重置边界（Reset Boundary）

| 属性 | 规格 |
|---|---|
| 形态 | 上下虚线水平线 |
| 文字 | commit 图标 + "上下文边界" + 时间 |
| 颜色 | 弱文字色 `--text-3` |

## 2. Assistant 段落模型

一个 Assistant Turn 被拆分为若干 **段（Segment）**：

| 段类型 | 说明 |
|---|---|
| `text` | Markdown 正文，可能处于 `streaming` 状态 |
| `thinking` | 思考推理块（CoT），独立展开/折叠 |
| `batch` | 一组工具调用，渲染为折叠链 |

**聚合规则**：
- 连续的工具调用和思考块合并成一个 `process` 呈现行（不显示头部）
- 最终的文本回复标记为 `reply` 呈现行（显示 `π OMP` 头部）
- 如果整个 Turn 只有工具没有文字，也渲染为 `process`

## 3. 工具卡片总览

### 3.1 卡片结构

每张工具卡嵌套在折叠链项中，结构为：

```
┌─────────────────────────────────────────────────────┐
│  [图标] 工具名 · 细节/路径        +N −M        [∨]  │ ← 行头（可点击展开）
│  ┌─────────────────────────────────────────────────┐│
│  │ [已截断 chip]（如有）                            ││
│  │ [KV 元数据标签行]（如有）                        ││ ← 卡片正文
│  │ [主体内容：代码/Diff/终端/树/表单…]              ││
│  │ [底栏：状态 chip + 耗时]（如有）                 ││
│  └─────────────────────────────────────────────────┘│
└─────────────────────────────────────────────────────┘
```

### 3.2 行头各部件

| 部件 | 规格 |
|---|---|
| 图标槽 | 14px 宽，12×12px 图标 |
| 运行中 | 图标替换为 spinner 动画 |
| 排队中 | 图标替换为 clock 图标 |
| 出错 | 图标和文字变红色 |
| 工具名 | 粗体标签（如 "Read"、"Edit"、"Bash"） |
| 分隔符 | 中点 `·`，仅在有细节时显示 |
| 细节 | 文件路径（等宽+下划线）/ 命令 / 搜索词 / URL，单行省略 |
| Diff 计数 | 等宽字体：绿色 `+N` 红色 `−M` |
| 展开箭头 | 默认隐藏，悬停/聚焦/展开时显示；展开时旋转 180° |

### 3.3 卡片正文容器

| 属性 | 规格 |
|---|---|
| 内边距 | 底部 `--sp-8` |
| 左缩进 | 对齐行头文字（跳过图标宽度） |
| 展开动画 | CSS Grid `0fr → 1fr` + opacity + translateY |
| 滚动 | 代码/树/diff/JSON 区域独立滚动，`overscroll-behavior: contain` |
| 最大高度 | 代码/树 220px（流式中 320px），diff 240px，JSON 180px |

## 4. 各类工具卡片视觉规格

### 4.1 Read（文件阅读）

- **行头细节**：文件路径（等宽下划线）
- **KV 标签**：行数 / 编码 / 大小
- **主体**：等宽代码视图，右对齐行号 gutter（28px 宽） + 代码行
- **回退**：无代码时显示摘要文字

### 4.2 Write（文件写入）

- **行头细节**：文件路径
- **KV 标签**：操作类型（"新建" / "覆盖" / "写入"）+ 行数 + 编码
- **主体**：带行号的代码视图
- **附注**：可执行文件时显示 "已设为可执行"

### 4.3 Edit（Diff 编辑）

- **行头细节**：文件路径 + `+N −M` diff 计数
- **摘要行**：编辑意图描述
- **主体**：统一 diff 视图
  - 新增行：绿色背景 + `+` 标记
  - 删除行：红色背景 + `−` 标记
  - 不变行：无色 + 空格标记
  - 双列行号 gutter（旧行号 + 新行号）
- **回退**：无结构化 diff 时显示原始代码块

### 4.4 Bash（终端命令）

- **行头细节**：命令文本
- **KV 标签**：cwd（工作目录路径）
- **主体**：黑色终端代码块
  - 首行：`$ 命令`（粗体命令行）
  - 截断提示："仅显示末尾 N 行"
  - 输出行：支持 ANSI 颜色类（`.c-ok` 绿色、`.c-err` 红色、`.c-dim` 灰色）
- **底栏**：
  - 运行中：蓝色 chip "运行中"
  - 成功：绿色 chip "exit 0"
  - 失败：红色 chip "exit N" 或 "failed"
  - 耗时：等宽数字

### 4.5 Grep / AST Grep（代码搜索）

- **行头细节**：搜索模式
- **KV 标签**：pattern / lang / scope / searched
- **摘要**："N matches · M files"
- **主体**：层级树视图
  - 文件组标题：强调色文件路径 + 命中数
  - 命中行：缩进，行号 + 代码片段

### 4.6 Glob（文件匹配）

- **行头细节**：glob 表达式
- **KV 标签**：pattern + files 数量
- **主体**：文件路径垂直列表（强调色）
- **空态**："No files found"

### 4.7 AST Edit（AST 结构重构）

- **KV 标签**：pattern / rewrite / replacements / files
- **主体**：文件级变换树
  - 文件标题
  - 删除的 AST 节点：红色高亮
  - 插入的 AST 节点：绿色高亮

### 4.8 Ask / AskUser（用户提问与选择）

- **行头细节**：选中的答案文本
- **主体**：
  - 问题提示文字
  - 选项列表：
    - 选中项：强调色背景、实心对勾圆圈、粗体、右侧 "已选" 标签
    - 未选项：空心圆圈、普通字重
    - 推荐项：追加紫色 chip "推荐"
- **空态**："无回答"

### 4.9 Task（子代理任务）

- **行头细节**：目标描述 或 "N agents"
- **主体**：结构化任务说明
  - **Goal** 节：粗体标题 + 段落正文
  - **Constraints** 节：破折号列表 + 内联代码 chip
  - **Agents 花名册**：
    - 每行：强调色圆点 + 等宽代理名 + `[状态]` 标签 + 耗时

### 4.10 Debug（调试器）

- **KV 标签**：action / program
- **摘要**：执行快照
- **主体**：调试器控制台输出代码块

### 4.11 Eval（代码执行 / REPL）

- **主体**：Jupyter 风格执行单元
  - 语言标签
  - 输入代码块（带行号）
  - stdout 绿色输出块
  - stderr 红色输出块
  - 单元底栏：状态 chip + exit code chip + 耗时

### 4.12 GitHub

- **KV 标签**：op / repo / pr
- **主体**：格式化 JSON 响应

### 4.13 LSP（语言服务诊断）

- **KV 标签**：action
- **主体**：诊断表格
  - error 行：红色严重性标签
  - warning 行：琥珀色严重性标签
  - 每行：严重性 + 文件路径 + 行号 + 消息

### 4.14 Inspect Image（图片分析）

- **KV 标签**：mime / model
- **摘要**：用户提问文字
- **主体**：模型的分析回答

### 4.15 Browser（浏览器自动化）

- **KV 标签**：action / tab / url
- **脚本**："script" 标签 + 代码块
- **主体**：结果输出代码块

### 4.16 Computer（桌面自动化）

- **KV 标签**：screenshots 数量
- **脚本**："script" 标签 + 代码块
- **主体**：命令输出代码块

### 4.17 Hub（子代理中心）

三种子变体：
1. **Jobs 集群**：KV + 代理花名册（同 Task）
2. **IRC 消息**：KV（to / receipt）+ 消息文字
3. **App Launch**：KV（name / pid / state）+ 日志代码块

### 4.18 Todo（任务清单）

- **KV 标签**：op
- **主体**：分阶段清单
  - 阶段标题
  - 已完成：绿色对勾 + 删除线文字
  - 进行中：强调色圆点
  - 待定：空心方框

### 4.19 Web Search / Web

- **KV 标签**：provider / sources 数量
- **摘要**：综合回答文字
- **引用条**：水平环绕的圆角药丸
  - 每个药丸：link 图标 + 标题 + 弱色域名

### 4.20 Retain（记忆存储）

- **KV 标签**：stored
- **主体**：存储的知识项列表

### 4.21 Recall（记忆检索）

- **KV 标签**：query / matches 数量
- **主体**：左侧强调色竖线的记忆摘录段落
- **空态**："0 matches"

### 4.22 Reflect（自我反思）

- **KV 标签**：query
- **主体**：反思综合文字

### 4.23 Goal（目标跟踪）

- **KV 标签**：op / status / budget
- **主体**：目标声明 + 进展报告

### 4.24 Generate Image（图片生成）

- **KV 标签**：images 数量
- **主体**：生成提示文字 + 状态说明

### 4.25 Vibe（并行后台同步）

- **主体**：会话状态列表
  - 每行：状态图标徽章（spinner / 对勾 / 叉 / 时钟）+ 等宽会话 ID + 活跃工具 + 耗时

### 4.26 Resolve（合并决策）

- **主体**：决策横幅
  - Accept：绿色柔底 + 绿色 chip "Accept" + 理由
  - Discard：红色柔底 + 红色 chip "Discard" + 理由

### 4.27 Think（思考推理）

- **行头**：brain 图标 + "Think" + 截断的预览文字
- **展开主体**：左侧强调色竖线容器
  - 预格式化 Markdown 文字
  - 流式中实时跟底
  - 截断时顶部显示 "已截断" chip

### 4.28 MCP（Model Context Protocol）

- **行头细节**：`MCP · server.tool` 或 `MCP · tool`
- **主体**：两段式 JSON 载荷
  - "args" 标签 + JSON 代码块
  - "result" 标签 + JSON 代码块

### 4.29 默认回退

适用于：`checkpoint`、`rewind`、`security_scan`、`memory_edit`、`learn`、`yield`、`tts`、`manage_skill` 及所有未知工具。

- **主体**：
  - "Args" 标签 + JSON 代码块
  - "Output" 标签 + 原始输出代码块
  - 或仅显示摘要文字

## 5. 工具链折叠与批次摘要

### 5.1 单工具模式

只有一个工具/思考块时，直接渲染卡片，不显示批次摘要头。

### 5.2 多工具批次模式

显示可点击的批次摘要行，点击展开/折叠整个链：

**摘要格式**（各部分用 ` · ` 连接）：

| 优先级 | 条件 | 文案 |
|---|---|---|
| 1 | 有文件编辑 | "正在编辑 {文件名}" 或 "编辑 {文件名}" |
| 2 | 有文件阅读 | "阅读 N 个文件" |
| 3 | 有搜索 | "搜索 N 次" |
| 4 | 有命令 | "运行 N 条命令" |
| 5 | 有网络请求 | "请求 N 次" |
| 6 | 有子代理 | "N 个子 Agent" |
| 7 | 有问答 | "Ask · {首个答案}" 或 "回答 N 次" |
| 8 | 仅思考（有时长） | "思考了 N.Ns" |
| 9 | 仅思考（有文字） | "思考 · {前36字}…" |
| 10 | 兜底 | "工具调用" |

摘要行右侧显示聚合 diff 计数：绿色 `+N` 红色 `−M`。

### 5.3 折叠状态规则

| 场景 | 状态 |
|---|---|
| 当前轮次流式进行中 | 工具链展开，实时显示输出 |
| 流式结束 / 历史轮次 | 默认折叠为摘要行 |
| 用户手动点击 | 展开/折叠切换 |

### 5.4 子代理条

当批次中有子代理时，在工具链上方显示代理状态条 `.subagent-strip`：
- 网格布局，自动适应宽度（min 320px per card）
- 每张卡片：名称 + 耗时 + token 用量 + 状态（左侧 2.5px 彩色边框指示状态）
- 状态颜色：运行中/启动中 蓝色、等待中 琥珀色、完成 绿色、失败 红色

## 6. Markdown 正文排版

### 6.1 标题

- h1–h3：`--fs-14`，semibold，上间距 `--sp-12`，下间距 `--sp-6`
- h4–h6：`--fs-14`，semibold，上间距 `--sp-10`，下间距 `--sp-6`

### 6.2 段落与列表

- 段落上下间距 `--sp-6`
- 列表左缩进 `--sp-20`
- 任务列表复选框使用强调色

### 6.3 引用块

- 左侧 3px 强调色竖线
- 柔和强调色底（`--accent-softer`）
- 右侧圆角 `--r-4`

### 6.4 表格

- 外层水平滚动容器，1px 边框 + `--r-6` 圆角
- 单元格 6px 10px 内边距，底部 1px 分割线
- 表头：`--surface-2` 背景，semibold，不换行

### 6.5 围栏代码块

- 外层容器：1px 边框 + `--r-6` 圆角 + `--code-bg` 背景
- 标题栏：语言标签（小写等宽）+ 复制按钮
  - 复制按钮：透明底，悬停变色，点击后 1.5s 内显示对勾

- 语法高亮配色：
  - 注释/引用：`--text-faint` 斜体
  - 关键字/标签：`--purple`
  - 字符串/新增：`--green`
  - 数字/符号：`--blue`
  - 函数/标题：`--purple`
  - 属性/变量/类型/删除：`--red`

- 流式中：显示为源码代码块

## 7. 流式行为规格

### 7.1 文本打字与呈现

| 表现维度 | 业务与视觉规格 |
|---|---|
| 文本展示 | 内容实时平滑流出，呈现打字机推进感 |
| 排版渲染 | 实时解析 Markdown 富文本（标题、列表、加粗、代码等），未闭合语法不引起布局抖动或格式错乱 |
| 思考块（Thinking） | 推理内容实时流出，独立展开并支持内容随生成向下滚动 |

### 7.2 工具卡片动态行为

| 表现维度 | 业务与视觉规格 |
|---|---|
| 启动与进行中 | 触发工具调用时立即呈现工具卡，显示旋转加载状态与当前执行信息 |
| 结果产出 | 工具执行完毕后，卡片更新为成功（绿色）或失败（红色）状态，并展示返回结果 |
| 展开与折叠 | 正在执行的当前工具卡默认展开；执行完毕进入历史或整批完成后折叠为摘要状态 |

### 7.3 回复生命周期视觉状态

```
回复开始   → 出现新 Assistant 行（显示 OMP 标识与正在思考/执行态）
文本流出   → 正文逐字追加排版
工具调用   → 工具卡创建并动态展示执行细节
轮次完成   → Assistant 行定稿，工具链折叠为精简摘要，展示变更统计卡与操作栏
异常中止   → 头部呈现“已中止”或错误卡片，保留已产出的过程内容
```

## 8. 滚动与视口交互

### 8.1 自动贴底跟随

- 流式输出过程中，视口默认锁定并自动跟随最新内容平滑向下滚动。
- 当内容发生排版重排或图片加载导致高度变化时，视口保持平稳贴底，不产生视觉跳跃。

### 8.2 手势脱离锁定

- 用户主动向上滚动（通过滚轮、键盘方向键/翻页键或触摸）时，立即解除贴底跟随锁定。
- 锁定解除后，后续流式生成的内容在下方静默追加，不再将用户视口强行拉回底部。

### 8.3 嵌套滚动隔离

- 鼠标在已展开的工具卡内部、长代码块或思考框内滚动时，仅滚动卡片内部区域，不影响外层主会话的滚动位置。

### 8.4 回到最新快捷按钮

- 当视口脱离底部且下方有新内容时，右下角展示悬浮圆形按钮（36×36px，强调色背景，向下箭头图标）。
- 按钮带有浮入动效；点击后视口平滑滚回最底部，并重新恢复贴底跟随锁定。

### 8.5 历史消息查看位置锚定

- 点击顶部“加载更早消息”时，保持用户当前所看到的阅读位置平稳固定，不发生跳屏。

### 8.6 工具卡内部独立跟随

- 展开且正在运行的工具卡（如长日志输出）内部同样支持贴底跟随；用户在卡内向上翻阅时仅解除卡内跟随，卡片折叠或展开时不干扰主视口。

## 9. 长内容与截断展示

### 9.1 超长终端与日志展示

- 针对大规模命令输出或日志流，界面保留尾部核心结果，并在顶部提示“仅显示末尾 N 行”或展示“已截断”标识，避免页面被无限撑长。

### 9.2 长代码块与多行内容

- 代码块和复杂数据视图设定最大展示高度，超出时在容器内部提供独立滚动，保持整条消息的紧凑排版。

### 9.3 历史长会话浏览

- 长会话上下滚动顺畅，消息行之间的视觉间距与层级结构保持一致。

## 10. 状态指示体系

### 10.1 状态 Chip 颜色语义

| 颜色 | 语义 | 用途 |
|---|---|---|
| 绿色 | 成功 | exit 0、完成、Accept |
| 红色 | 错误 | 非零退出、失败、Discard、出错 |
| 蓝色 | 运行中 | 命令执行中 |
| 紫色 | 推荐 | Ask 推荐选项 |
| 灰色 | 中性 | 已截断、已中止、元信息 |
| 琥珀色 | 警告 | 待审批、诊断警告 |

### 10.2 活动状态线

对话底部的实时活动指示：
- 强调色旋转图标（3.6s 周期）
- 标签文字（粗体）+ 操作名 + 细节（省略溢出）+ 等宽计时器
- 等待阶段：文字扫光渐变动画（2.4s 周期）
- 重试状态：琥珀色显示

### 10.3 角色徽章

| 角色 | 内容 | 样式 |
|---|---|---|
| 用户 | `S` | 18×18px，灰底（`--surface-3`），深色字 |
| Assistant | `π` | 18×18px，强调色柔底（`--accent-soft`），强调色字 |

### 10.4 会话切换过场

切换会话必然有一段空窗（engine 按新 identity 重建，首份快照零行 `loading`）。空窗不允许出现占位文案或空白，只允许淡出 → 骨架 → 淡入：

| 阶段 | 时长 | 画面 |
|---|---|---|
| `leaving` | 140ms（`--ease-in`） | 上一段 transcript 原地淡出，位置与滚动位不动 |
| `waiting` | **无时限** | 骨架屏；读取多久就停多久 |
| `revealing` | 320ms（`--ease-out`） | 新 transcript 淡入，与骨架淡出（200ms）交叠 |
| `idle` | — | 不挂任何 transition / animation |

- 骨架形状：assistant 组（18px 头像 + 72×9 名条 + 11px 正文行，可含 34px 工具卡）与右对齐用户气泡（34px，`--accent-soft` 渐变，圆角同 `.ev-user .ev-body`）交替共 5 组，组间距 `--sp-20`，下缘线性遮罩渐隐（52%→96%）。
- 骨架容器 `.convo-veil`：`position: sticky; top: 0; height: 0` + 绝对定位内层（高度 `min(420px, 46vh)`），对文档高度零贡献。**硬约束**：`ConversationVirtualList` 的 `scrollMargin` 相对滚动容器量算，骨架占真实高度会把虚拟行反向补偿；正文层同理只允许动 `opacity`，位移只由骨架做。
- 入场闸门：骨架挂载后下一拍才置 `data-in`，transition 带 60ms 延迟。读取落在淡出窗口内则完全跳过骨架；稍慢的读取只亮到半途就被淡出反向接走（可逆 transition，不用 `animation`）；`SWITCH_SLOW_MS`（2.4s）后在骨架下缘补一行"正在读取会话记录…"。
- 连续切换：骨架不重建，`waiting` 一直兜到最后那个会话读完。
- `prefers-reduced-motion`：跳过淡出，骨架保留但为静态（`.skeleton` 退化为 `--surface-3` 平铺）。
