## 4. 每项修复的核心实现

### P0-1 空闲 CSS 动画（`styles/workbench.css`、`styles/base.css`、`styles/pages.css`）

- `omp-text-breath`：`text-shadow` 无限动画 → **静态双层霓虹（原 keyframes 峰值帧）+ 一次性 0.9s `opacity` 淡入**。视觉识别（橙红发光）保留，常驻合成层消失。
- `ce-sheen`：`background-position` → 渐变条 `::after` + `transform: translateX`，**只扫一遍**（3.2s，`1.4s` 延迟）。
- `pi-breathe`：无限 `opacity` 呼吸 → 静态 `opacity: .94`（= 原呼吸均值）。
- `magic-kw-shimmer`：正文静态（保留每字符不同 `--magic-hue` 的彩虹识读）；仅输入框镜像层保留扫光，且**每个关键字限前 39 字符**（`nth-child(n+40) { animation: none }`）。
- 空态热力图：只前 60 格错峰，其余随网格一次性淡入（峰值并发从 253 降到 3）。
- `omp-shimmer`（骨架）也从 `background-position` 改为 `::after + translateX`（合成属性）。
- `prefers-reduced-motion: reduce` 覆盖以上全部（π 静态、热力图入场停、pill 停、`skeleton::after` 隐藏）。
- 不新增任何 `will-change`；不引入 JS 定时器/observer 控制动画。

### P0-2 Runtime 验签证据（`runtime-installer/src/verification-cache.ts` 新增、`installer.ts`、`studio-host/src/runtime-resolver.ts`、`host-backend.ts`）

- 新增 `StatKeyedVerificationCache<T>`：键 = 绝对路径 + `lstat` 身份（size/mtimeMs/inode/dev）+ assertion（校验类型/版本/期望摘要）；**默认 TTL 10 分钟**；stat 变化立即失效；single-flight（并发共享在途 Promise）；**失败永不记录**；`invalidate()` 同时作废在途读（generation 计数）。
- `currentManifest()`：**每次仍完整验签**（三份签名元数据 + payloadSha256 + ed25519），只有 entrypoint 的**字节**走证据缓存；`install/activate/rollback/uninstall/prune` 全部 `invalidate()`（含 `install()` 同版本幂等提前返回分支）。
- `runtime-resolver.ts`：抽出 `readExecutableFingerprint()`；**探针前指纹强制 `fresh: true`（执行边界必须当场读）**，探针后比对只在"重新 stat 仍一致"时复用；identity 算法逐字节不变（`sha256(platform\0||bytes)`，Thread binding 依赖它）。
- `host-backend.ts` 共享一份指纹缓存（并发 resolve 合并）+ `invalidateRuntimeVerification()`。
- 诊断计数：`installer.verificationStats()` / `backend.fingerprints.stats()`（`contentHashes`/`cacheHits`/`singleFlightJoins`/`skippedBytes`）。
- 轮询：新增 `usage/usagePolling.ts`，`document.hidden` 时不发起、恢复可见立刻刷一次、in-flight 不叠加；`HomePage`/`ConversationEmpty` 改为使用它。

### P0-3 快照零拷贝 seam（`host-client-api/src/facade.ts`）

- 新增 `#currentSnapshotRef()`（零拷贝只读引用）/ `#hasSnapshot()` / `#currentRuntimeEpoch()` / `#snapshotCopy()`（唯一对外出口）。
- 20 个调用点逐条分类：热路径与判空全部改窄接口（0 拷贝）；**只有 4 个真正的出口拷贝一次**（bootstrap、`home.get`、`session.state`、live telemetry 叶子）。
- `kind:"snapshot"` 事件确认下游只读（`ipc.ts:142` 直接 `sender.send` 由 Electron 跨进程结构化克隆；client reducer 只持有引用），保持零拷贝、不引入可变内部引用。

### P0-4 PTY 合批 + 有界流控（`terminal-batch.ts` 新增，`terminal-pty.ts`、`terminal-ipc.ts`、`remote/terminal.ts`、`terminalSessions.tsx`）

- 合批窗口 **8ms**；每会话一个 `StringDecoder`（跨 chunk 的半个 UTF-8 码点被重组，不产出 U+FFFD）。
- 有界：每会话硬上限 **2MiB**，到上限**先暂停源再交付**（不丢字节）；退出时先刷净再发 exit，并留一个合批窗口给 ConPTY 尾行；`resize()` 前先 flush 保证录制顺序。
- 流控：渲染侧 `xterm.write(text, cb)` → **ACK**（同 tick 合并成一条）；Main 水位 **HIGH 500KiB / LOW 100KiB**；无 ACK 的旧 preload 自动降级为"只合批、不暂停"。
- 录制跟着批次走（不再每 chunk `JSON.stringify`）。**输入通道零改动**（不排窗、不计水位）。
- 新通道 `TERMINAL_IPC_CHANNELS.ack`；`data` 事件新增 `bytes` 字段；`create` 新增 `flowControl?: boolean`。

### P0-5 Composer 击键路径（`App.tsx`、`composer/ChipComposer.tsx`、`composer/draftStore.ts` 新增）

- 草稿按会话挪进 `createComposerDraftBook()`（AppShell 内的外部 Map），击键**不再 setState AppShell** → "比较函数永不相等"的漏洞整体消失。
- `WorkbenchCanvas`：`draftLive` ref 立即更新（命令式读取全部走它：发送/续写/听写/发送按钮），可渲染视图只在**状态边界**（空↔非空、胶囊出现/消失）或 **140ms 停顿**后提交 ⇒ 击键 0 次父层渲染。
- `ChipComposer`：胶囊重编号 + 截断测量改为"胶囊签名变化才做"，改由宽度 `ResizeObserver` 重测；缩略图重建按 image 胶囊签名触发。
- 技能集合按内容签名上报。输入 `value`/`slashSource`/预测保持同步 urgent，不进 transition。

### P0-6 GPU / 动效分级 L0–L3（主进程 `perf-profile*.ts` 新增，渲染层 `perf/tiers.{ts,css}` 新增，`main.tsx` 接线）

- 主进程：`app.getGPUFeatureStatus()` 为主判据（`gpu_compositing`/`2d_canvas`/`rasterization`/`webgl` 任一含 `software`），**只在 status 无法证明硬件合成时才** `getGPUInfo("complete").glRenderer` 兜底（识别 SwiftShader/llvmpipe/WARP/Basic Render）；`gradePerfProfile()` 纯函数出 L0–L3（L3 = 低核或低内存；L2 = 软合成；L1 = 电池）；缓存到 `%APPDATA%/omp-studio/perf-profile.json`，Host 日志 `desktop.perf_profile` 记录证据；`gpu-info-update`/`on-battery`/`on-ac` 重探并推送。
- **新增"GPU 判定未稳定"闸门**：GPU 进程异步启动期间 `getGPUFeatureStatus()` 会报 `disabled_software`（本机实测第一次快照 software、下一次事件 hardware）。未稳定时把 GPU 状态视为未知（乐观 L0）、**不写缓存、不广播**，稳定后再定级 ⇒ 避免"本次启动先降级、随后又恢复"的闪烁，也避免把瞬时误判写进下次启动的首帧。
- 渲染层：`tiers.ts` 纯函数 + `applyTier()`；`tiers.css` 按 `data-gpu`/`data-motion`/`data-perf` 三属性分级（L1 只压时长不写 `animation:none`；L2 去 `backdrop-filter/box-shadow/filter` 并把原本用 box-shadow 表达的焦点环改回 `outline`；L3 追加 `content-visibility` 与装饰层隐藏）。入口在 React 挂载前写属性；用户只能"更严"（`prefers-reduced-motion` 或 `omp.perf.motion=off`）。

### P1-1 IPC 订阅生命周期（`ipc.ts`、`ipc-validation.ts`、`preload.ts`、`transport-desktop/src/channels.ts`）

- 新通道 `omp-studio:desktop:unsubscribe`；`subscribe` payload `{ scope, subscriptionId }`，返回 `{ ok: true, subscriptionId }`；事件 envelope 变为 `{ subscriptionIds, event }`。
- 订阅 id 由 **preload 桥**在发 IPC 前生成（取消不依赖 resolve）；Main 按窗口维护 `id → scope` 与 `scope → 唯一的 Host 订阅`，同一 scope 只建一条 Host 订阅、一条消息覆盖该 scope 的所有 id（>64 id 才拆包）。
- 幂等取消；先到取消（有界 FIFO 1024）在注册落地后立即自杀；`destroyed`/`did-navigate`/`render-process-gone` 三路兜底（用 `on`+`removeListener`，不留监听器），`forward()` 前再查 `closed`/`isDestroyed()`。

### P1-2 Electron 权限最小授权（`security.ts`、`main.ts`）

- `RENDERER_PERMISSION_MATRIX`：只放行 `media`（实测 `media/AudioCapturePane.tsx:34` `getUserMedia({audio})`）与 `clipboard-sanitized-write`（`navigator.clipboard.writeText` 多处使用）。
- 显式拒绝并写明依据：`notifications`（Main `chrome-notify.ts` 发，渲染层无 `new Notification`）、`clipboard-read`（无 `readText`）、`fullscreen`/`pointerLock`（无 `requestFullscreen`/`requestPointerLock`）、`display-capture`、`mediaKeySystem`、`geolocation`、`midi`、`idle-detection`、`hid/serial/usb`、`openExternal`、`speaker-selection`、`top-level-storage-access`、未知 permission。
- 三道 handler 一起设：request / check（`file:` 打包入口接受 Chromium 报的裸 `file://` origin，但带 `requestingUrl` 时仍按完整 URL 校验）/ device（一律 false）。CSP、sandbox、contextIsolation、nodeIntegration、webSecurity 一行未动（`security.test.ts` 仍钉死 `secureWebPreferences` 全字段）。

### P1-3 Dock 持久化与观察器（`dock/store.ts`、`dock/hosts.ts`）

- 持久化：`PERSIST_DELAY = 200ms` 合并写；scope 切换、draft 交接、`pagehide`、`beforeunload`、`visibilitychange→hidden` 强制同步刷盘；生命周期监听只在有待写数据时注册、写完即解绑。
- 配额：先全量 → 失败用精简载荷重试一次 → 再失败 `blocked = true` 本次会话不再写；全程不抛错。
- 观察器：`MutationObserver` 丢弃面板正文内的 mutation，属性变化只认 dock 几何选择器；`measure()` 先读全部 rect 再写，并按每 host 的**几何签名早退**（不变不写 DOM）；`clip-path` 计算逻辑未改（有测试钉住）。

### P1-4 conversation.open 事件分片（`studio-host/src/conversation-coalescer.ts`、`conversation-events.ts`）

- 拆成"物化（同步，分组语义不变）→ 投递泵"两段：每片默认 **64 envelope 或 4ms**，`setImmediate` 让出，一轮事件循环最多一片。
- `flush()` 仍是**同步屏障**（审批/回执/publication/runtimeLost 语义不变），新增 `flushSliced()` 供 open/可见性/溢出使用。
- 顺序/完整性：单 FIFO、跨片 streamSeq 严格递增；epoch 变更丢弃已物化的旧事件；outbox > 2000 退化为一次全量排空（防无界积压）。
- **双投递未改**（单 fanout 同时喂所有窗口，取消会饿死其它订阅者，属协议变更），已在 §10 记录。

### P2-1 正文→卡片列滚动交接（`dock/scrollChain.ts` 新增、`dock/hosts.ts`）

- 纯函数 `planScroll(event, inside, outside, viewport)`：内部链任一层还能滚 ⇒ **完全不拦截**；到边界才把剩余量交给 slot 最近的**外层一个**可滚容器，`clamp` 到自身余量，**只 `preventDefault` 一次**；`defaultPrevented`/`ctrl|meta`/横向主导/`deltaMode`(0/1/2)/小数 delta 全处理；1px 浮点容差避免高分屏卡死。
- `hosts.attach()` 给 layer 挂**唯一**一个 `wheel`（`passive:false`），teardown 移除；host→slot 每事件从 live Map 解析（换位/重挂不会留下失效映射）。

### P2-2 窄窗"视图"菜单打开真实抽屉（`dock/store.ts`、`dock/DockMenus.tsx`、`App.tsx`、`layout/useWorkbenchLayout.ts`、`layout/workbenchLayout.ts`）

  - `right`/`bottom` 的 `groups` 为空 → `visible = false`；`bottom.expanded`/`size`/`ratio`/`rail.lastMode` 全部保留。
  - `before` 是本次动作的起始布局：**本来就空**的区域不会被强制关闭 ⇒ `{type:"region",visible:true}` 仍能打开空区域显示"添加工具"空态。

### 12.1 安全相关改动

1. **权限策略收紧**（`security.ts`）：`notifications` / `clipboard-read` / `fullscreen` / `pointerLock` / `geolocation` / `hid|serial|usb` 等 17 项从"可信 Origin 全批准"变为显式拒绝；新增 check/device handler。风险：将来若新增"读剪贴板 / 网页通知 / 元素全屏"功能会被拒，必须同步在 `RENDERER_PERMISSION_MATRIX` 加一行（代码注释已写明流程）。
2. **验签证据缓存**（`verification-cache.ts`）：签名验证、checksums 覆盖、逃逸检查、`lstat().isFile()`、失败即拒全部保留；只有 entrypoint 字节校验被记忆化，三层失效 + spawn 前 fresh 指纹 + 安装/激活/回滚/卸载/prune 全失效。风险：TTL 窗口内的"stat 保持不变的替换"看不见（见 §10.3）。
3. **IPC 订阅协议变化**：新通道 `unsubscribe`、事件 envelope 带 `subscriptionIds`。**Main 与 preload 必须同版本发布**；旧 preload + 新 Main 会因 envelope 不匹配收不到事件（读侧静默丢弃畸形 envelope，不会崩）。回滚需两侧一起回滚。
4. **终端 IPC 变化**：`ack` 通道 + `bytes` 字段 + `flowControl` 入参。旧 preload 自动降级为"只合批不流控"（有测试 `without the handshake the PTY is never paused`），因此 Main 单独回滚是安全的，preload 单独升级也安全。
5. **GPU 探测**：只读、不 `--disable-gpu`、不关闭硬件加速、不改 CSP；preload 暴露面只读（`cached`/`probe`/`onChanged`），无写方法。
6. **未放宽任何既有安全设置**：CSP、sandbox、contextIsolation、nodeIntegration、webSecurity 一行未动（`security.test.ts` 钉死）。

### 12.2 回滚建议（按风险从高到低）

| 改动 | 回滚方式 | 影响面 |
|---|---|---|
| IPC 订阅协议（`ipc.ts`/`ipc-validation.ts`/`preload.ts`/`channels.ts`） | 4 个文件一起回滚（必须同版本） | 渲染层订阅（若不回滚会收不到事件） |
| 终端合批/流控（`terminal-batch.ts` + `terminal-pty.ts`/`terminal-ipc.ts` + `terminalSessions.tsx`） | 先回滚 renderer 侧（自动降级为只合批），再回 Main | 终端输出延迟/吞吐 |
| 验签证据缓存（`verification-cache.ts` + `installer.ts` + resolver/host-backend） | 回滚 4 个文件 + `index.ts` 导出 | 启动/usage CPU 回到旧水平，安全语义不变 |
| 权限矩阵（`security.ts` + `main.ts` 三行） | 回滚两个文件 | 安全性回退到"可信 Origin 全批准"——不建议 |
| Dock 三缺陷（`model.ts`/`hosts.ts`/`scrollChain.ts`/`store.ts`/`DockMenus.tsx`/`App.tsx`/`layout/*`） | 先回 `App.tsx` 的 `regionState`/`releaseFocus` 接线，再回 dock 内部 | 交互缺陷复现，不影响数据 |
| 渲染层动画与分级（`styles/*`、`perf/*`、`main.tsx`、`App.css`） | 纯 CSS/属性，回滚即恢复旧视觉 | 空闲 CPU 回到 6%+ |
| Composer 击键（`App.tsx`/`ChipComposer.tsx`/`draftStore.ts`） | 回滚 3 个文件；行为回归为"每键重渲" | 输入粘滞，功能不受损 |
| 首屏图标（`public/icon.png`） | 换回 342KB 原图 | 首屏 +324KB |

**数据完整性**：本轮不写用户配置/数据库/会话/凭证；dock 布局写入保持"预览模式不写真实存储"语义；配额失败只降级不修改已有数据；Runtime 校验失败仍拒绝启动，不会静默放行。

## 13. 是否满足发布前技术验收条件

### 13.1 结论

**技术门禁通过，可以进入发布候选（RC）阶段；但不能直接宣称"全平台验收通过"。**

- 代码门禁：`npm run check -- --production` **全绿（40.4s）**；`npm run check` **全绿（69.9s）**；桌面整包 695 例（679 pass / 16 skip / 0 fail）。
- 三项 Dock P2：真实浏览器 **18/18** 通过（含 P2-4 组合场景）。
- 性能（同窗口对照，§7.5）：空闲 CPU **2.55% → 0.11%（−95.7%，目标 <0.8% 达标）**、无限装饰动画 **3 → 0**、启动整文件 sha256 **10 → 6 份**、稳态 60s **2 → 0 份**、4× 降速击键 **9.074 → 2.443 ms/字符（−73.1%）**、首屏传输 **−9.5%**（JS 在 2.5MB/800KB 预算内）。
- 阻碍"全平台验收"的只有环境缺口（§11）：macOS 真机、真实安装态、低配真机、真 SSH/ConPTY、真 GPU 矩阵。这些是**未验证**，不是**已验证失败**。
