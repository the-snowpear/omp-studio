# 语音输入

工作台和 BTW 的麦克风使用 OMP 原生听写模型与设置。它是输入方式，不是 Live 语音助手：默认只填写草稿，不发起 Agent 回合。

## 首次使用

1. 在工作台输入框工具条点击麦克风，或打开 **设置 → 语音 → 语音输入**。
2. 启用语音输入，选择听写语言。中文夹英文技术词通常选 `zh`，同时在模型配置的 **Dictation 角色**中选择支持中文的模型。
3. 右键发送按钮左侧的麦克风，在选项面板选择输入设备。设备测试最多 10 秒，只显示本机输入电平，不上传、不保存录音。
4. 本地模型首次使用可能需要下载；云端转写会上传音频并可能计费。应用在首次使用或有效配置改变时说明这些操作，不会静默换服务。
5. 等待状态变为 **正在聆听**再开始说话。模型准备和设备权限等待不是正在录音。

听写需要更新后的桌面应用和提供 `dictation.inspect` / `dictation.open` 的 Runtime。缺少这些能力时，界面说明原因，不尝试旧版听写链路。浏览器独立 UI 和 SSH 工作区目前不转发本机麦克风。

## 操作模式

| 操作 | 行为 |
|---|---|
| 点击麦克风 | 开始听写，再点停止；始终只填草稿 |
| 右键麦克风 | 打开语音输入选项；聚焦麦克风后也可按菜单键或 Shift+F10 |
| 按住原生 `app.stt.pushToTalk` 绑定键 | 默认 Space；约 350ms 后开始，松开完成，短按可打印键仍输入文字；原生配置为空则禁用 |
| 切换快捷键 | 沿用原生 `app.stt.toggle`；设置中可添加 `Alt+H` 等 GUI 快捷键 |
| Enter（正在听写） | 停止并完成转写，不直接发送尚未完成的草稿 |
| Esc | 取消并丢弃本次听写，保留原草稿和同期键入 |
| 切会话、离开输入区、隐藏窗口 | 立即停止采集并保留一份待处理内容，不继续后台录音 |

按住/切换模式可选原生提交策略：不自动发送、松开且至少两个词时发送、松开且为完整句时发送、说出明确的句尾提交指令时发送。默认不自动发送。中文按词界判断，而不是要求空格；英文包含 `submit` 的普通单词不作为提交指令。

点击录音、恢复/重试、人工修改过草稿、失焦中断或发生错误时均不自动发送。自动发送仍使用当前输入框的正常发送/排队和审批规则，不绕过现有控制。

## 文字出现方式

模型能力不同，显示也不同：

- **逐字流式**：边说边显示临时文字。
- **分段识别**：短暂停顿后出现一段文字。
- **录后转写**：录音时显示电平和时长，停止后提交转写请求。

临时文字显示在开始时的输入位置，不进入已保存草稿或发送正文。完成后作为一次编辑合入，可用普通撤销撤回；附件、提及胶囊和同期键入仍保留。如果输入位置已被替换，不猜测新的插入位置，而是保留结果等待处理。

设置语言不会给模型增加语言能力。当前原生 Nemotron 流式模型仅英语；不要把 `zh` 配给英文专用模型。未知的云端语言支持会明确标为未确认，凭证已配置也不等于服务网络和额度已验证。

## 失败与恢复

每次最长 **10 分钟**，全应用只有一份内存音频恢复槽，PCM16 音频约 **19.2 MB** 上限。达到上限时结束录音，不覆盖开头。

发生网络失败、设备断开、Runtime 丢失或切走时：

- 原草稿不变；已识别文字与收到的音频保留在内存。
- 回到原输入位置可选择 **重试转写、保留文字、复制或丢弃**。
- 重试重放已有录音，不重新开麦，不重复追加同一结果。
- 恢复项归属原会话和原输入位置，不能自动写到另一会话或 BTW。
- 开始下一次录音前先处理旧恢复项。
- 云端重试可能再次计费，仅由使用者明确触发；不会自动重试或切换供应商。

成功填入草稿并确认、主动丢弃、窗口销毁或退出应用后清除音频。不保存音频文件，不建立录音历史；应用进程崩溃或退出后不能恢复录音。未发送转写正文和音频不进入 Host 命令账本、持久化事件或诊断日志。

## 常见问题

- **未启用**：用麦克风面板的“启用语音输入”，或在交互设置开启。项目/会话覆盖可能高于用户配置，请查看来源。
- **模型/语言不匹配**：打开 Dictation 模型角色，选择支持目标语言的模型，不要只改语言代码。
- **权限拒绝**：点击“打开系统设置”。Windows 打开麦克风隐私页，macOS 打开“隐私与安全性 → 麦克风”。
- **没有声音**：检查设备、电平、系统静音和其它应用占用；不要用文字有没有实时出现判断是否录到，因为批量引擎录音时没有文字。
- **准备很久**：查看真实下载/加载阶段，可随时取消。取消不会在稍后权限返回时偷偷开麦。
- **看不到升级后的能力**：同时更新 Renderer、Desktop preload/Main 和 Runtime；单独替换界面不能增加原生能力。

## 验证边界

自动测试覆盖状态、时序、草稿隔离、PCM 排空、恢复与原生策略。隔离浏览器页面可用合成音频验证真实 AudioWorklet 和编辑器交互，但这些不等于物理麦克风和所选识别模型通过验收。

本轮实现还需按实际平台/硬件验证 Windows/macOS 权限、真实设备和所选本地/云端模型的中英混说质量。付费模型请求须在明确账号、模型与费用范围后进行。
