# Studio 0.2.12 发布审查

日期：2026-11-28。基线：已发布 `v0.2.11`；候选：`main` 的 OMP Studio 0.2.12，候选源码提交 `d66b37889625058559be237760bbc1c47b274a2d`。审查依据 `docs/release-review.md` 与 `docs/releasing.md`。

## 变更范围

本次候选包含 OMP Runtime 19.2.1 升级（`19.2.1-studio.4`）、Composer 与模型菜单的思考强度滑块、Web 访问控制条设置与拖动行为、侧栏活动排序、会话草稿恢复、模型目录和供应商并发设置，以及审批控件遮挡与失败恢复修复。发布说明已准备中英文摘要、四平台桌面链接、六平台 Web/SSH 运行环境链接，并嵌入 Max 档位滑块局部特写。对应 issue #75/#76 在本次候选合并时已关闭；发布后仍需按流程补充包含版本号的 Issue 回复。

## 审查结论与边界

**Runtime 专项门禁现已通过，候选具备继续发布审查的条件。** 本机失败根因为原生插件缓存落后 Runtime 源码；重建后独立回归和完整补丁验证均通过。发布前生产门禁、tooling、Runtime pin 与候选基线 CI/Warm cache 均已有通过记录。Release Notes 已嵌入思考强度滑块 Max 档位局部特写，截图不含全屏桌面内容。

下一步提交本次版本准备变更并等待该 main 提交的 CI 通过；版本号与文档变更不会触发 Runtime 预热。随后从 `docs/releases/v0.2.12.md` 提供发布说明并启动桌面 Release。发布后核对四种桌面平台、六种远端环境、签名清单与 Latest 状态；最后在 #75/#76 回复已包含于 0.2.12 并确认 Issue 关闭。物理 macOS、Linux、Windows ARM64、实际 SSH 与真实移动设备尚无本地验收，本轮由跨平台 Release 打包门禁覆盖。
