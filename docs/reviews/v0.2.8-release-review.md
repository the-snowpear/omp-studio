# v0.2.8 发布审查

审查日期为 2026-11-22（Asia/Shanghai）。上一正式版为 `v0.2.7`。按[发布审查指南](../release-review.md)和[发布流程](../releasing.md)核对源码、版本元数据、打包和公开资产。

## 审查范围与修复

候选包含 `ce71d4a` 合入的活动图标、文件预览、SSH 和归档清理，`68ede2a`、`b0fabd1` 的会话引用与摘录，以及补充的 SSH 键盘焦点与高级设置样式调整。Git 恢复点为 `codex/backup-v0.2.8-before-release`。

| 发现 | 修复和验证 |
|---|---|
| SFTP 的 `-b` 先应用 `BatchMode=yes`，导致随后的密码认证配置失效 | 将显式认证配置放在批处理参数前，验证 OpenSSH 选项优先级 |
| 转换完成时遍历所有组件版本，可能删掉已经解压、仍在激活的新引擎 | 转换收尾只释放自己使用的退休版本，保留安装中的引擎 |
| 表格键盘选区可覆盖过大的行列范围，复制会生成巨量 TSV。重新解析 CSV 时会丢失选区 | Worker 限制单次复制的单元格数和文本量。CSV 更新后保留有效选区 |
| 演示对话切换语言时，新的对话引擎短暂提供空快照，导致 Advisor 披露状态重置 | 首次渲染前加载本地演示数据，并按会话隔离披露状态 |
| SSH 演示连接丢失用户填写的端口、网络策略和安装目录 | 实际和演示表单共用配置组装，演示准备页按选择展示。配置无用户名时密码页显示主机名 |

会话引用专项覆盖了复制与粘贴、重名来源的选择、跨工作区读取、断线恢复、选择后才序列化摘录、未匹配的 UUID 保持普通文本，以及带重复会话 ID 的归档读取。归档删除专项验证了取消归档先完成时跳过该会话，并验证清理结果和产物保留。

## 发布前核验

- 根清单及 14 个 workspace 的版本和内部依赖统一升至 `0.2.8`。锁文件由 `npm install --package-lock-only` 生成，第三方条目保持一致。根目录和 Renderer 的 Mermaid 声明一致。
- 预览开关为 `false`。下载表格列出四个桌面目标的六个安装及更新文件。发布计划包含 Windows x64、Windows ARM64、macOS ARM64、Linux x64，以及六个 Runtime 和 SSH 环境目标。
- 内置 Runtime 为 `19.0.1-studio.1`，上游固定提交为 `f40f335845f0b136453d12fec8d6057011082766`。已核对相对 `v0.2.7` 的 gitlink、overlay、接缝补丁和元数据。候选复用同源签名 Runtime。
- 核对了跨 Job 的可执行位恢复、沙箱 preload 生产打包和发布资产汇总。发布作业仅打包、审计并签名，源码检查由本地和 CI 执行。
- Windows x64 上 `npm run check -- --production` 通过，覆盖架构、类型、核心测试、Vite、远端 Host 和沙箱 preload。Renderer 专项 43 项通过，Desktop 与 Host 专项 69 项通过。`npm run test:tooling` 152 项通过、1 项按条件跳过。

## 人工验证边界

发布截图使用本版界面组件与隔离演示数据。Windows x64 / Chrome 检查了归档选择、Advisor 展开、摘录选择和 SSH 表单的 `zh → en → zh` 热切换，也验证了表格键盘框选、SSH 配置到准备页的传递，以及确认和上传阶段的键盘焦点。真实工作区文件读取和会话引用覆盖 Desktop Host 集成测试。在 WSL Ubuntu 24.04 实测了文件上传、进度、SHA-256、重命名和临时文件清理。验证范围未包含 macOS Gatekeeper、Windows ARM64 和 Linux 真机安装，以及完整的六平台 SSH 连接。
