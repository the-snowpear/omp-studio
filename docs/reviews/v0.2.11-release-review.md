# Studio 0.2.11 发布审查

日期：2026-11-25。基线：已发布 `v0.2.10`；候选：main 的 0.2.11。审查先读取 `docs/release-review.md` 与 `docs/releasing.md`。

## 变更范围与结论

覆盖上一 Tag 以来的独立 Web Host/浏览器传输、桌面生命周期与终端、后台任务批量停止、#72 Mermaid 浮窗、#73 同窗新会话、#74 命令补全关闭、显示器移除后的窗口恢复、Windows 上传回退，以及中英文官网与部署。远端已有 5 个官网提交已合并，本地原有修改均保留并提交。

发布审查修复了两项实际回归：

1. 共享 Host 通过 `ELECTRON_RUN_AS_NODE=1` 启动，原来的终端环境仅在 POSIX 移除 Electron 开关，Windows Shell 因而继承启动开关。现对各平台统一清除 Electron 开关，保留 PATH、LANG 及用户环境。
2. Host 抽离 Electron 时丢失了 `app.getPath()` 的系统目录，文件浏览器会退回默认目录，忽略 OneDrive 等重定向位置。现通过已认证的桌面回调动态读取实际目录；无桌面连接时沿用独立 Host 原有默认目录。

## 历史故障防线

- 版本脚本精确更新根及全部 14 个 workspace manifest，再由 `npm install --package-lock-only --ignore-scripts --no-audit --no-fund` 生成锁文件；比较确认只有 15 个 workspace 条目变化，第三方依赖未变。
- `PREVIEW_MODE_SWITCH_ENABLED=false`；根与 Renderer 的 Mermaid 依赖保持一致。
- 相对 v0.2.10 无 `omp-patch/` 改动。Runtime 保持 `19.0.1-studio.1`，上游固定为 `f40f335845f0b136453d12fec8d6057011082766`，不重新签发同版本不同内容。
- Release 矩阵保留四种桌面目标与六种远端环境。远端包包含 Web 资源、启动器和私有 Node；在实际私有 Node 下启动 PTY，检查架构及 POSIX helper/启动器执行权限。
- 源码测试留在本地及 CI；Release 只做打包、签名、产物核验。等待 main CI 与已触发的预热完成后推 Tag；瞬态失败仅原 Run 重试。
- 中英文 Changelog、Release、README 与文档入口同步，发布页覆盖四桌面平台实际文件名。
