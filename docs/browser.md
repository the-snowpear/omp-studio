# 聊天浏览器

本地桌面中，每个聊天都有自己的一组网页，人与 Agent 使用同一组页面。每个网页是工作台标签行里的一个标签，和 Git、Changes 等工具并列：可以拖到底栏、拆成两组并排、浮出成窗口或钉成独立系统窗口。同一个聊天的两个网页可以同时显示。

## 打开与使用网页

在工具菜单或标签行的 `+` 里选「Browser」，会打开新标签页。输入网址后回车，这个新标签页就变成该网页的标签。支持 HTTP / HTTPS、本地开发地址和空白页；带端口的本地地址可以直接输入，例如 `localhost:5173`。

每个网页标签显示网站图标和标题。网页正在加载时显示转圈，加载失败或崩溃时显示警告图标；还没加载的网页（例如重启后未查看过的标签）图标变灰。

网页上方是一行工具栏：

- 后退、前进、刷新（加载中变为停止）。
- 地址栏：平时主机名清晰显示，路径变淡；点击后显示完整网址并全选。缩放不是 100% 时，地址栏右侧会显示缩放比例，点击恢复 100%。网页使用非默认浏览空间时，也会在这里显示空间名称。
- 选择元素、开发者工具。
- 控制权切换「Agent | 我」。
- 「更多」菜单：新建标签页、在页面中查找、缩放、复制网址、在系统浏览器打开、关闭其他标签页、释放此对话的网页、下载、浏览器设置。

面板较窄时，选择元素和开发者工具收进「更多」菜单，控制权切换只显示图标。

消息与终端中的本机链接会在当前聊天打开为新的网页标签。右键菜单可以改为在系统浏览器打开。其他外部链接沿用系统浏览器。如果 Agent 正在控制且此对话已有网页，链接会先显示在新标签页上，点「接管并打开」后打开。

默认每个聊天最多 16 个网页，可在「浏览器设置」中调整。达到上限时保留已有网页，并提示关闭网页或提高上限。

## Agent 打开的网页

Agent 使用原有 `browser` 工具。`targets` 可列出聊天已有网页；`open` 的 `app.target` 可选择已有网页继续操作。

Agent 新开的网页会作为标签放在你最近查看的网页旁边，但不会主动展开已隐藏的区域。如果那组标签正在显示这个聊天的另一个网页，新网页会切到前面，方便你看到 Agent 正在做什么。你自己打开的网页（新标签页、Ctrl / ⌘ + T、网页里的「在新标签打开」和链接）会直接显示出来。

## 人工接管与 Agent 控制

工具栏右侧的「Agent | 我」显示当前控制者。点「我」接管：系统先阻止新的浏览器操作，等正在执行的操作完成后交给你。接管后网页四周亮起一圈主题色细框，可以直接在网页中选文字、输入、粘贴、滚动和使用右键菜单。Agent 的其他工作可以继续。

点「Agent」归还，Agent 可继续操作这一聊天的网页。选择元素和打开开发者工具会先自动接管；关闭开发者工具后才能归还。交接失败时会显示原因，可以在当前操作结束后重试。

人工控制时，网页支持 Ctrl（macOS 为 ⌘）+ L、F、R、T、W 以及 `+`、`-`、`0`，分别对应地址栏、查找、刷新、新标签页、关闭和缩放。Shift + Ctrl / ⌘ + R 强制刷新。

## 关闭网页

点网页标签上的 ×、在标签上按 Delete，或在标签右键菜单中选「关闭网页」，会关闭这个网页。网页标签不会被「隐藏」，关闭就是关闭。

Agent 正在控制时也可以直接关闭：系统等 Agent 当前一步做完，关闭网页，再把控制权还给 Agent，不需要先手动接管。等待期间标签上的关闭按钮显示转圈。交接失败（例如 Agent 一直没有交出控制）时网页保留，并显示原因。

浮窗里关闭整个窗口会关闭其中的网页，其他工具照常隐藏。

## 指着元素提出修改

1. 点工具栏的「选择页面元素」，在网页中点击需要修改的元素；选择模式会阻止该点击触发网页按钮。网页上方会出现提示条，可以连续选择多个。
2. 选中的元素会出现在网页下方的「已选元素」里，包含定位路径、文字和区域截图，可以为每个元素写备注。
3. 点「加入输入框」。元素成为可编辑的引用胶囊，截图成为独立图片附件，可与文字一起发送给 Agent。

Esc 或提示条上的「结束选择」结束选择模式。每个网页的已选元素各自保存，可以删除单项或清空。引用胶囊支持编辑备注、草稿恢复和复制粘贴。

同源 iframe 可选择内部元素，开放 Shadow DOM 会保留宿主路径。跨域 iframe 和关闭的 Shadow DOM 以外层区域为引用边界。页面导航后保留原来的采集内容，并提示页面已变化；引用不会自动改成新页面上的内容。

## 登录空间与权限

新标签默认使用共享持久空间，Cookies 和站点存储可在聊天之间复用。需要隔离测试账号时，在「浏览器设置 → 浏览空间」创建新空间，然后选择新标签使用的空间。已有网页仍使用创建时的空间。

网站申请麦克风、摄像头、通知、剪贴板、位置或全屏权限时，会显示原生询问。勾选记住选择后，该决定按网站来源和空间保存；可在「浏览器设置 → 网站权限」中撤销。macOS 的麦克风和摄像头还受系统权限控制。

## 下载与页面恢复

下载默认保存到系统下载目录，完成后通知。「更多 → 下载」列出下载进度，可以打开、在文件夹中显示或取消；「浏览器设置」中可以修改目录或每次询问保存位置。

隐藏网页标签、切换聊天、移动浮窗及 Runtime 退出都会保留活页面，包括登录、表单和 JS 状态。网页崩溃时保留标签和错误原因，由用户重新加载。

完整退出应用后，网页标签的位置和顺序、地址、网站图标、缩放和登录空间仍保留。网页在第一次显示时才加载，其余标签按需加载。未保存的表单、页面 JS 内存和导航历史不会随完整退出恢复。

「释放此对话的网页」用于回收活页面占用，保留标签和登录空间；之后在标签中点「重新加载」恢复。它同样会丢失未保存的页面内容。

## 预览与环境

全局「预览」开启时，浏览器使用演示网页和数据，按钮只改变演示状态。关闭预览后使用本机真实网页。原生托管浏览器用于本地 Desktop；Web UI、SSH 与旧 Runtime 中，「Browser」工具按各自现有能力显示观察视图。
