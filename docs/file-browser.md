# 文件浏览器

从工作台的“添加工具”打开**文件浏览器**，或在命令面板搜索“打开文件浏览器”。它可以浏览当前对话执行位置上的文件：本机对话显示本机磁盘与主目录，SSH 对话显示远端机器。Explorer 继续负责项目内文件。

文件浏览器默认以 960 × 600 的浮窗打开，也可以停靠、移动或添加多个实例。每个实例分别记住路径、视图、排序、隐藏文件开关和位置栏宽度；固定文件夹按连接目标共享。真实数据和演示数据的记忆相互隔离。

## 浏览与导航

| 窗口宽度 | 默认布局 |
|---|---|
| 小于 480px | 单树，位置入口收进工具栏 |
| 480–900px | 位置栏与详细列表，可切换到树 |
| 900px 及以上 | 分栏，可切换到树或列表 |

手动选择的视图会被记住。窗口变窄时临时降级，恢复宽度后回到原选择。列表可按名称、修改时间、类型和大小排序；目录始终在文件之前。分栏选中文件后显示信息与文本开头或图片预览。

位置栏提供主目录、桌面、下载、文档、图片、已注册项目、固定文件夹以及磁盘／卷。Windows 本机的常用目录来自系统已知文件夹，因此支持 OneDrive 重定向。点面包屑空白处或按 Ctrl+L（macOS 为 Command+L）输入路径，支持 `~`、带空格或带引号的路径。筛选只作用于当前文件夹中已加载的条目。

常用快捷键：方向键、Home／End、Page Up／Down 选择；Enter 打开；Backspace 或 Alt+↑ 返回上一级；Alt+←／→ 后退／前进；F5 刷新；Ctrl／Command+F 筛选；Ctrl／Command+Shift+. 切换隐藏文件。分栏内可以用左右方向键沿目录层级移动。

## 打开、编辑与文件管理

双击文件会打开内置文件窗口。项目内文件使用其工作区身份，与 Explorer 共用缓冲区并显示 Git 标记；其他文件显示“项目外”。文本沿用 UTF-8、带 BOM 的 UTF-16、换行格式保留、版本冲突处理和未保存关闭确认，编辑上限为 8 MiB。PDF、图片、媒体、表格和 Office 预览沿用现有文件查看器及可选组件。

右键菜单提供系统程序打开、打开方式、在系统文件管理器中定位、复制路径、添加到对话、固定文件夹，以及设为项目并新建对话。加入当前项目文件时使用相对路径；项目外文件或其他项目的文件使用绝对路径，使引用仍指向原文件。复制远端路径得到的是远端机器的路径。

Ctrl／Command+Shift+N 新建文件夹，F2 行内重命名。名称冲突会显示错误，重命名不会覆盖已有文件。Delete（macOS 也可使用 Command+Backspace）弹出回收站确认；已注册项目根目录会额外提示。确认后只移到系统回收站／废纸篓，没有永久删除操作。磁盘和卷根目录不能重命名或回收。符号链接可以浏览，内置编辑器不会通过文件末端的符号链接写入目标。

在项目目录或文件上选择“在 Explorer 中定位”，可以回到项目树。Explorer 的目录右键菜单也提供“在文件浏览器中显示”。

## SSH 与预览模式

SSH 文件的列表、文本读写和资源预览通过所属目标的 Host 传输；新建文件夹、重命名和设为项目同样在远端执行。系统程序打开、打开方式、定位和回收站在 SSH 下禁用，并说明远端文件不在本机。旧 Host 会提示更新；断开时保留路径和界面状态，可在连接恢复后刷新。

预览开关打开时只显示演示文件系统，新建、重命名和回收只修改内存中的 fixture，不执行真实文件操作。关闭预览后只读取 Host 数据。`?preview=1&marks=off` 隐藏演示标记和演示专用提示。

## 范围与限制

- 目录最多返回 5000 项，并显示截断提示；没有递归搜索。大列表和分栏按可见区域渲染。
- Windows 隐藏属性暂用名称近似：点开头文件和常见系统文件名视为隐藏；Unix 使用点开头规则。
- Windows 盘符并行探测，约 400ms 内没有返回容量的驱动器显示未就绪。UNC 路径可以直接输入。
- 当前没有后台文件监听。F5、刷新按钮、重新显示窗口以及文件操作完成后会重读；文件编辑器继续使用自己的版本检测。
- 常用目录仅列出实际存在的位置。没有权限、路径不存在和驱动器未就绪会显示具体错误。
- macOS／Linux 的无覆盖重命名通过系统 Perl 调用内核的独占重命名操作，需要 `/usr/bin/perl`。macOS 自带；精简 Linux 主机若未安装会提示安装。文件系统不支持独占重命名时返回错误，不降级为可能覆盖文件的操作。

样式验收入口为 `apps/renderer/file-browser-harness.html?preview=1&marks=off`。该页面可切换舞台宽度，也可把文件浏览器放入真正的 Dock 浮窗中检查。
