# 会话切换重构合并审查

审查基线：`0.2.0` 的 `7ae8772`；待合并实现：`codex/session-switch-refactor-recovered` 的 `08d4f8a`。审查前恢复点为 `codex/session-switch-before-review`。本次审查覆盖原重构差异、读取生命周期、缓存边界、归档 Worker、Git 写操作真值、滚动恢复以及本地/远端产物。

## 已修复的问题

| 问题 | 触发条件与修复 |
| --- | --- |
| 配置旧结果重新进入缓存 | 模型或技能读取尚未完成时写入配置，原实现只清除完成缓存，旧 flight 仍能回填。现在同时提升缓存代次并移除旧 flight 的可复用入口。 |
| Host 跨项目读取错配 | 共享读取延迟到 microtask 执行时，原实现再解析当前 cwd，可能把 B 项目结果存入 A 项目键。现在入队前取得绑定固定项目的读取方法。 |
| 迟到的项目上下文订阅 | 上下文打开超过 30 秒宽限期，关闭后又打开时，迟到的旧连接可能安装订阅或清空新连接引用。现在按 opening 身份检查，过期连接直接关闭，不安装订阅。 |
| 统计结果在配置更新后仍命中 | 归档 revision 不变但模型/技能/Runtime 环境改变时，旧统计可能继续复用。相关命令完成会提升统计缓存代次，新请求不加入旧 flight，旧结果也不能回填。 |
| 取消后的迟到探测进程 | 等待 Runtime executable 定位期间取消或 dispose，原实现仍可能启动子进程。定位结束后再次检查实际生命周期。 |
| Git 摘要串源与残留错误 | 不同连接使用相同 workspaceId 时，旧摘要可能短暂显示；成功重试也没有清掉旧错误。现在结果同时绑定 client 和 workspace，成功结果替换错误。 |
| 项目诊断重复计数 | 多项目共用连接缓存时，各项目重复上报同一预算。现在连接只注册一次预算计数，消费者单独汇总。 |

## 死代码和重复逻辑清理

- 删除底层统计 probe 的旧成功缓存、flight Map、executable stat 身份读取、TTL 选项和不再使用的 revision 参数。共享与缓存由 Host 的完整复制/探测/清理任务统一负责。
- 删除未读取的滚动 `metricsRef`、`resizeFollow` 及过时说明，避免只写状态和额外几何读取。
- 删除未使用的 Context Dock `layout`、未消费的 `stderrChunks`。
- 删除只由测试调用的 archive budget `clear()`；测试改用生产 Reader 的释放入口。
- 删除归档快照和投影重复的数量淘汰分支，由统一全局预算限制数量；自定义 raw-byte 上限仍保留。
- 合并启动时重复排入的项目预热；Git 日志读取恢复加入同一展示读取 flight，写操作前后的真实状态读取仍独立。

## 验证口径

新增行为回归验证：旧配置结果不能覆盖新配置；项目切换不能错配缓存；关闭期间迟到的连接不订阅；统计环境变化不复用旧 flight；取消后不生成子进程；Git 成功恢复清除错误且不同连接不串摘要。

验证使用项目 `scripts/check.mjs`：上述定向套件、完整 `--production`、归档/探测专项及 Desktop Git/远端部署专项。产物另外通过 standalone remote Worker 和 Electron ASAR Worker 检查。合并后的主工作树再运行完整生产检查与新增回归，避免仅验证实验工作树。

性能结论沿用 [重构实测报告](session-switch-refactor-20261110.md)：本次修复针对正确性、生命周期和重复代码，不把既有未达到的长任务/开发版峰值门槛改写为通过。macOS 原生验收仍需在对应设备上完成。
