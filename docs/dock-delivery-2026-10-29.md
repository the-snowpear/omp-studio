# 停靠工作台交付记录 · 2026-10-29

规格：[0.2.0 UI 升级实施计划](0.2.0-ui-upgrade.md)。用户说明：[工作台停靠与布局](workbench-docking.md)。

## 已实现

- 全应用实际标签的圆角矩形选择态；移除通用标签和模型配置中的镜像测量系统。通用标签支持溢出入口、激活项滚入和键盘导航，紧凑控件不强制放大。
- 四区域和应用内多标签浮窗；右侧上下／底部左右最多两组；卡片排序、折叠、手动高度和自动高度恢复。
- 稳定正文宿主、首次显示挂载、移动不更换 Portal target；隐藏和折叠使用不可交互状态，不结束业务资源。
- 独立对话工具区完整／紧凑／隐藏状态；紧凑图标和单模块覆盖层不占对话宽度；响应式首选／有效布局分离。
- 指针阈值、落点说明、修饰键暂停吸附、Esc／失焦取消、组移动、浮窗缩放／最大化／胶囊。
- 会话级布局、草稿交接、项目继承、全局预设库、项目／应用默认、撤销重做、旧布局迁移及预览隔离。
- 视图／模块／组菜单、设置页、命令面板和找回入口。BTW 已统一接入，不改 Host、Runtime、transport 或公共契约。

## 浏览器实际验证

环境：Windows 上的内嵌 Chromium，Vite 完整应用 fixture 入口；不是 Electron 产品实例。

- 实际 viewport 检查：768×1024，以及预览窗格有效尺寸 532×438。亮色／暗色、standard／compact／cozy、中英界面均有代表性检查。
- 标签检查：计算样式为 32px、9px 圆角；暗色有面底和边框，关闭控件保留可达空间。
- Agents 覆盖面板 → Ctrl 拖出浮窗 → 最小化胶囊 → 恢复 → 最大化／还原 → 拖入底栏：正文宿主 DOM 身份始终相同，只有一份内容。
- 覆盖工具层显示时对话宽度不变；实际 host 与 slot 矩形一致，点击命中正文而不是旧区域。
- Esc 取消浮窗拖动后矩形不变、预览高亮清除。
- 调试预设显示两组底栏；短窗口临时折叠，没有改写首选布局。
- 设置中另存演示预设成功，前后 `omp.dock.v1` 真实存储字节完全一致。
- 最新完整重新加载后的页面、菜单和覆盖工具可用；开发期间热更新导致的临时缺模块／Context 错误属于集成过程中日志，不作为最终运行通过证据。

## 不能宣称已完成的验收

- 未完成规格列出的全部 1920／1440／1280／1024／800／640px 真人手感矩阵。当前预览接口的 desktop preset 会覆盖自定义宽高，因此只记录实际测得尺寸，不假称大屏已验证。
- 未在 macOS 真机运行；Command 修饰键和原生窗口交互仍需目标平台验收。
- 未用真实 Electron PTY 进程做跨所有落点的输入／选择／滚动保活矩阵；浏览器显示现有不可用说明，没有伪造 Shell。
- 未用真实 Browser／Computer 观察流及人工接管验证全流程；稳定宿主和可见性边界已有测试，但不等于设备观察验收。
- 未做低配硬件、流式贴底／中部阅读、高 Composer、多浮窗并发的完整性能基准。
- Agent Hub、Skills 和 Skillshare 的内容标签也已接入通用标签键盘／溢出入口；紧凑字段分段控件保留其原有语义。
- 部分业务正文仍以 App 内的薄映射注册；元数据／新面板 render 接口已提供，尚未逐一搬成独立 panels 文件。
- 旧版停靠状态的 BTW 不能单独保留“上次浮动矩形”；实际浮动的 BTW 矩形和最小化状态会迁移。

这些是本次交付边界，不把模型测试或 Web 预览替代完整平台／资源验收。
