# OMP 18.4.4 GUI 使用说明

本轮固定 OMP 18.4.4，应用版本保持 0.1.7。Runtime 更新为 18.4.4-studio.31。完整变更与验证见 [迁移记录](migrations/omp-18.4.4-gui.md)。

- **消息队列**：空闲时 Enter 发送，生成中 Enter 排入 follow-up；纠偏使用 steering。队列按消息组标识取消和取回，重复文本也可分别操作。取回必须先获得 Runtime 成功回执；已有草稿时选择合并或取消。断线和不确定回执不会自动重发。
- **Ask 图片**：自定义答案与备注分别支持选图、粘贴、预览和删除。图片只属于当前问题、当前回答区。转换期间不能提交或换题；取消和过期释放尚未提交的内存附件。
- **子代理 BTW**：从 Agent Hub、子代理卡片或侧栏进入，话题和追问使用对应子代理上下文。目标失效后停止发送。
- **服务档位**：Composer 模型旁选择当前会话档位。可用选项由当前模型决定；全局、子代理与 Advisor 默认值在设置中单独管理。账户刷新只查询额度，不兑换重置券。
- **设置与技能**：设置显示配置来源、当前生效值、保存目标和重启要求。技能显示 Runtime 解析后的 namespace、来源与冲突信息；不能安全定位的按名称修改操作会禁用。
- **输入预测**：默认本地 N-gram，只学习已发送文本。未发送草稿仅即时查询。Tab 接受，Escape 隐藏；中文组合输入和提及菜单不抢键。设置中可关闭、清理语料、主动导入历史或下载 SmolLM2。
- **统计**：侧栏「统计」查看本机全部 OMP 历史，按时间、项目、模型、提供商过滤。先显示缓存，再同步。金额是 API 等价估算；未知价格不当作零费用。Frustration 先估算范围与成本，确认后才调用 Judge。
- **Benchmark**：模型配置中的 Benchmark 提供单用户吞吐、并发扩展和自适应 prefill；工作负载阶段与 cold/warm 独立展示，支持取消、失败结果与导出。
- **资源**：能力中心「资源」输入当前会话的 `local://`、`omp://`、`attachment://` 或 `conflict://` URI。分页校验内容版本；历史或其他会话的资源请先切换到其来源会话。
- **IDA**：能力中心 IDA 标签检测本地授权安装；文件树二进制入口可带入路径。支持数据库打开、关闭、保存、代码/符号视图和修改审阅。每次修改绑定数据库身份与版本，确认后执行；未安装时显示不可用说明，不自动安装。

旧 Runtime 未提供能力时，对应入口显示原因或禁用。浏览器侧栏继续暂缓；本地交付不包含远程发布、商业 IDA 安装、真实兑券或付费模型验收。
