# 电脑操作

电脑工作区把代理的 Computer Use 活动、目标画面、近期步骤和安全控制放在一起。实际的键鼠、窗口和辅助功能操作仍由原生 OMP 工具执行。这个工作区不是远程桌面，点击截图不会向电脑发送鼠标或键盘输入。

## 打开与开始使用

从工作台工具菜单或命令面板打开 **电脑**。对话中的电脑工具结果也提供“在电脑中查看”，会打开该会话已有的面板位置，不重置停靠布局。

先核对抬头显示的设备和会话。当前会话未启用时，在详情中的电脑设置为本次会话启用，然后回到对话说明任务。启用不代表所有操作已获批准，前台控制和其他原生工具审批仍需分别处理。

系统能力按项展示：

- 截图、键鼠输入、辅助功能和全局 Esc 监听是不同能力。
- 能看画面不表示代理一定能输入。缺少 Eval 或 Computer prelude 时，界面说明执行能力不可用。
- macOS 屏幕录制、辅助功能和输入监控可能需要分别授权。全局 Esc 不可用不能被“全部已授权”掩盖。
- 后端报告锁屏或显示器休眠时暂停额外观察。原生可靠检测目前限于 macOS；其他后端会说明检测不可用，不能把未报告解释为已解锁。Studio 不会为补画面自动唤醒或解锁电脑。

## 看懂画面和步骤

### 跟随代理与固定观察

默认跟随当前会话及其子代理的真实电脑活动。可按代理来源筛选，也可固定一个显示器或应用窗口观察。

**观察目标不是操作目标，也不是权限范围。** 固定看某个窗口不会要求代理只操作这个窗口。界面分别显示观察画面和执行来源，目标未知时不会猜测。

默认显示执行过程中已经产生的截图，不额外持续采集。打开“自动观察”后，才会为可见面板增加低频观察截图；空闲时降频，持续空闲后暂停。隐藏、最小化、查看历史、断线、锁屏或休眠时停止额外采集，代理任务本身不会因此停止。

### 执行截图与观察画面

每张画面带有来源、目标、采集时间和像素尺寸。

- **执行截图**来自原生 Computer 调用。只有确实进入对应工具结果时才标记“已包含在工具结果”。
- **观察画面**是为用户额外采集的快照，不会自动发给模型，也不会冒充某一步的执行证据。
- 某个步骤没有截图时会明确说明，不会用之后补拍的画面填补历史。
- 锁屏前的窗口旧帧、过期或不可读的资源都有对应状态，不能把读取时间当作原始采集时间。

点近期动作查看关联画面。“正在查看历史”时，新活动不会抢走所选内容；使用“回到当前”恢复跟随。“在对话中查看”会定位原来的工具步骤。

### 查看大图和保存

共享图片查看器提供适应窗口、100%、缩放、平移、复制和另存为。100%指收到的截图像素，不代表显示器全分辨率，也不会改变原生工具的点击坐标。

明确保存到产物库的图像会保留为独立资源。复制和另存为只在用户点击时执行；取消系统保存对话框不是错误。

### 查看界面结构

详情中的“界面结构”按需读取所选目标的辅助功能树，显示角色、名称和可用状态。结构不存在、权限不足或平台不支持时，不影响仍可用的截图功能。

只有同次截图与结构之间具备可靠坐标变换时才高亮节点。窗口移动、布局变化或几何信息不完整时，不在新画面上猜旧元素的位置。结构查看是只读功能，不提供执行元素动作、菜单操作或剪贴板按钮。

## 审批、停止与本人接手

前台控制申请使用对话中已有的原生审批卡。电脑工作区只提示和定位同一项审批，不创建第二个“允许”入口，也不替用户批准。

**停止电脑操作**立即对本会话及其子代理设置停止状态，并取消正在进行的原生电脑操作和待决控制确认。只有收到取消与保存结果后才显示已停止。超时或断线时显示停止尚未确认，不能保证已发往操作系统的动作被撤回。

这个按钮不终止其他会话，也不默认中断本会话无关的代码或终端工作。需要结束整个代理回合时，使用对话中的全会话停止功能。

**我来操作**先走同一停止流程，再让用户到系统桌面操作目标应用。它不保证独占整台电脑，其他会话或应用可能仍在运行。

**继续电脑操作**需要明确的新用户操作，并绑定当前停止代次。请求进入队列不等于已经恢复；只有被执行链实际接纳后才放行新的电脑调用。停止前已排队的消息、普通追问、自动 Loop、重新启用开关或隐藏的继续消息，不会解除操作者停止状态。迟到的旧批准也不能恢复旧操作。

原生物理 Esc 和用户介入检测保留各自的作用范围与恢复规则。不要假设在所有后端、所有后台输入中按 Esc 都能停止；始终以实际能力和工作区的停止结果为准。

## 设置范围

电脑设置复用全局/会话范围、配置来源与清除覆盖的交互。

| 设置 | 含义 |
|---|---|
| Computer Use 启用 | 当前会话是否可以使用原生电脑工具，或修改继承的全局默认 |
| 默认显示器 | 原生工具默认使用的显示器，可为 active、all 或原生显示器标识 |
| 截图宽度和高度 | 原生配置上限；有效尺寸还受模型与传输限制 |
| 后台回退 | 后台输入不可用时，接管前台执行或拒绝该动作 |

全局修改按原生规则影响继承该值的会话，不覆盖显式项目或会话设置。选择一个观察窗口不会更改这些执行设置，也不授予前台控制。

## 隐私与保存期限

额外观察截图只进入有界的短期缓存，不写入对话、命令账本或默认产物库。最后一个可见观察者退出后释放对应缓存。

原生已产生的执行截图通过私有媒体引用读取，不把大图 base64 塞入实时事件。Studio 新增、未明确保存的托管执行副本默认采用以下限制：

| 范围 | 默认限制 |
|---|---|
| 额外观察缓存 | 每 profile 64 MiB，120 秒有效期 |
| 未明确保存的托管执行副本 | 30 天或每 profile 1 GiB，先触及的限制生效 |

过期后保留动作记录和不可用原因，不补拍替代图。明确保存的图像、用户导出文件、其他功能产物以及原生会话自己保存的截图，不属于这项自动清理范围。清空观察缓存不等于删除了全部原生截图。

活动元数据不默认记录输入正文、剪贴板内容或屏幕文字。权限检查、目标名称、图像本身仍可能涉及敏感信息，应在适合执行任务的账户和桌面环境中使用。

## 平台、版本与窗口

- 完整工作区需要支持新版 Computer 契约和被动观察的 Runtime/native binding。旧 Runtime 保留手动观察，并说明能力限制。
- 本地 Windows 和 macOS 使用原生桌面能力。是否可用以当前系统权限和实际构建为准，不以操作系统名称推断。
- Web 与 SSH 只展示连接实际提供的能力；本地私有截图接口不能用来读取远端桌面。当前不提供 VNC/RDP 或远端图像代理。
- 面板复用现有停靠、Pin 和独立系统窗口。窗口固定只改变展示，不改变会话归属、控制权或审批范围。
- 重连重新获取快照和观察身份，不自动重发已发送的点击、输入、批准或继续。旧 Runtime 画面只能作为历史证据查看。
