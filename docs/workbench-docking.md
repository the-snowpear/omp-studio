# 工作台停靠与布局

OMP Studio 的工具可以在左侧栏、对话工具区、右侧栏、底栏和应用内浮窗之间移动。项目／会话导航固定在左侧；对话和工具使用同一套窗口管理、拖拽预览、吸附布局和窗口控制。

窗口标题栏带有各自的淡色调。对话按打开顺序区分颜色；工具按类型取色，例如 Git 为橙色、Terminal 为绿色、Changes 为青色、Agents 为粉色。顶部窗口标签、浮窗内的工具标签和拖动预览沿用对应色调，浅色与深色主题自动适配。

点击或用键盘聚焦窗口时，同色边线和轻微外发光突出当前窗口，标题栏底色保持。移动、吸附、最小化与恢复保留色调；工具标签组随当前工具切换颜色。运行、等待和错误仍由原有状态圆点表示。

## 对话窗口

只有一个对话时，正文、输入框和对话顶栏保持原来的排版。主区域不增加窗口布局工具条、分割线或第二层标题外框。

- 从左侧列表把一场会话拖到列表外，松手后直接打开为浮窗；原来主区域的对话继续保留。普通单对话模式下，点击侧栏会在主区切换；进入窗口模式后，点击另一场对话会新开浮窗，保留当前窗口及其分区。已打开的会话只恢复并聚焦已有位置，包括主区、最小化和独立窗口，不重复创建。新窗口在对话工作区内错位排放，可继续拖动或吸附。
- 主区有一场可见对话时，拖动主对话顶栏的空白处，把主区实际显示的对话连同输入框和对话工具区变为浮窗。主区显示 A、焦点及顶栏内容是 B 时，超过 6px 后激活并拖出 A；取消恢复之前的焦点。主区为空或显示全局页面时不能拖出，顶栏按钮继续操作当前焦点对话。
- 对话与工具共用拖拽预览、窗口外壳和落地动画。已打开会话借用同一份正文、输入框和精简顶栏，源位置留下占位；拖动或落地期间只显示一份完整窗口。未打开会话先显示加载占位，松手后打开。Esc、失焦或指针取消恢复原状。
- 对话浮窗仅有一条顶栏，包含会话标题菜单、来源、状态、对话工具区、更多和 Pin／最小化／最大化／关闭。主区还有对话时，完整项目、分支与会话操作在主顶栏，主顶栏随焦点更新。自由窗口支持八方向缩放，吸附窗口通过共用分界线调整。
- 主区没有对话、全部对话都在窗口里时，主顶栏左侧换成窗口标签栏：按打开顺序列出每个对话窗口和从侧栏拖出的工具窗口，包括最小化和独立窗口。工具标签显示工具图标（网页显示站点图标）和“工具 · 所属对话”，一个窗口里有几个工具时带数量。点击标签聚焦该窗口，布局不变，最小化的窗口会恢复；× 与窗口自己的 × 相同：对话只关闭视图，工具隐藏，网页关闭。+ 打开和侧栏标签行“+”相同的工具菜单，顶上多一项“新建对话”，沿用当前对话的项目与连接新建对话窗口；选中的工具移进一个新窗口，即多一个标签，已在窗口里的工具不再列出，布局锁定时工具在原位置打开。原顶栏左侧的项目、分支、对话标题和 Fork／Handoff 移到每个窗口的标题行，连接与路径放在项目名的悬停提示里，标题菜单另带对话阅读宽度。窗口较窄时依次收起分支名、项目名和 Fork／Handoff（后两者仍在标题菜单里）。从独立窗口打开终端、Git、Changes、首页或设置时，会先把主窗口带到前台。主顶栏右侧保持不变，仍跟随焦点对话；把任一对话收回主区即恢复原来的顶栏。
- 浮窗的「对话窗口选项 → 收回对话区」将内容放回原主区域。原主区域已有的对话保留在本次运行的缓存里，可从左侧重新打开。左侧项目／会话列表沿用原来的行、状态、菜单和预览内容，直接拖动会话行即可开浮窗。
- 当前工作台只剩一个可见的应用内对话窗口时，点击最大化、双击标题或拖到顶部会回到普通单对话模式，移除浮窗外框。工具浮窗参与计数，停靠工具、最小化窗口与独立系统窗口不计数；仅剩工具窗口时仍正常最大化。关闭其他窗口不会自动改变当前排版。
- 主区空出后显示简洁的工作区背景，提供「新建对话窗口」「收回当前对话」及最近使用的已打开对话入口。新建沿用当前对话的项目与连接；收回沿用原内容和草稿。背景适配深浅主题，小尺寸时收拢对话列表；吸附布局下不在分区背后堆叠提示内容。
- 项目导航、右侧栏和底栏全应用各只有一份，始终留在主窗口；浮窗包含正文、输入框和对话工具区。右侧栏和底栏跟随最近激活的对话，宽度和高度跨对话共享；点击正文、输入框、工具或激活独立窗口会切换归属。新消息和鼠标悬停不抢焦点。右下角原有的底栏展开／隐藏按钮始终留在主对话区域，切换焦点或拖出当前对话后仍可使用。
- 移动、最小化和收回不会重新创建对话内容。草稿、阅读位置和所属工具保持；关闭只关闭视图，不停止任务或终端。最小化后的对话可从胶囊或侧栏恢复；全部对话都在窗口里时由标签栏代替对话和工具的最小化胶囊。最小化最后一个可见窗口不会换成新对话，主区显示工作区背景；关闭最后一个对话视图时才新建对话。
- 桌面版通过与工具共用的 Pin 菜单切换为独立窗口或置顶窗口；Web UI 使用应用内浮窗。重启恢复未关闭的会话和窗口位置；草稿、附件草稿和阅读位置只保留到本次应用退出。真实与演示窗口布局分别保存，演示布局不写真实存储。

每个对话通过自身的客户端上下文发送命令和接收事件，侧栏焦点变化不改变已经发起的操作。旧 Host 不支持客户端上下文时，保留原单对话入口或显示升级提示。

仍被对话或工具窗口引用的会话复用连接、正文和工具状态，切换焦点、最小化或移动窗口不会重新连接。主区切换到其他会话或关闭最后一个引用后，旧界面、订阅和客户端上下文释放；只保留本次运行中的身份、草稿、待发队列、布局和阅读锚点，重新打开时重新读取正文。首次加载只在该对话内提示，应用导航、主顶栏和共享栏持续保留，未就绪的会话操作暂不可用。真实断线和事件缺口仍会重新同步，提示限定到所属对话，不清除草稿与已读内容。

首页、会话历史、模型配置、设置等独立页面使用完整的页面区域，保留全局导航；项目／会话侧栏、对话顶栏、右侧工具栏、底栏及右下角底栏按钮一起隐藏。返回工作台时恢复原布局、草稿和工具实例，不重新建立会话连接。主动固定为跨页面显示的浮窗仍遵循原有 Pin 规则。

离开工作台时，正文、共享区域和普通浮窗一起淡出，再显示目标页面；全局导航保持稳定。返回时按同一时序恢复，快速切回可中止退场。开启减少动画时直接切换。

### 对话与工具共用停靠

拖动对话窗口标题，也可以将它放入来源会话的右侧栏、底栏或左侧栏工具区域。右栏和底栏显示为现有标签，左栏显示为可折叠、可调整高度的卡片；拖到区域开关可以展开并放入该区域。对话和工具可在同一浮窗中组成标签组。

再次拖动标签或卡片标题即可回到浮窗；右键菜单提供相同的移动、拆分和合并操作。关闭只关闭视图，任务和终端继续运行；布局撤销及重启恢复保留停靠位置。停靠沿用来源会话的工具上下文，切标签、移动或取消不重新创建正文、Composer 和客户端，也不把对话嵌套到自己的对话工具列。首次放入底栏时，为输入区保留足够高度。

### 窗口吸附与布局补齐

拖到对话工作区左右边缘可吸附为半屏，四角为四分之一，顶部为最大化；角落优先。吸附范围避开共享侧栏和底栏，自由窗口可以在整个应用工作台内移动。按住 Windows 的 Ctrl 或 macOS 的 Command 暂停吸附。

不必把鼠标贴到边框上：左右触发带按工作区宽度自适应，常见尺寸下宽 64–112px；角落触发区宽 112–192px、高 100–220px，顶部触发带高 48–72px。预览出现后允许再偏移 24px，避免在分区交界处来回闪动；深入角落会切换到上下分格，明显拖离恢复自由浮动。对话窗与工具窗采用相同的热区和缓冲规则；工具仍可优先落入合法的标签栏或工具卡片区域。按住 Ctrl／Command 立即解除预览保持，松手按当前修饰键状态提交。

对话窗和工具窗的最大化按钮都支持悬停 300ms 或按方向键打开布局选择器。提供左右各半、左右 2:1、三列、左侧上下与右半、左半与右侧上下、四宫格六种模板。单击仍最大化／还原。分区至少 360 × 280px，工具有更高尺寸要求时同时满足；选择器只开放当前空间能容纳的位置。

主区已有 A 时，将 B 对话或工具吸附后，A 自动进入剩余最大的空位，不再留在分区背后。空位相同则优先 B 对侧，再按从上到下、从左到右选择。拖动预览同时展示相邻窗口的目标位置，取消后恢复。

主区仍是一场完整对话时，首次把其他对话或工具拖到角落，只拆分拖入的一侧：例如工具放左上格，主对话占右侧全高，左下格留空。预览中的主对话也使用完整窗口标题和同一份正文、输入框，取消后回到原主区；不会把正文单独挤成半高区域。直接拖动主对话本身到角落，或从布局选择器明确选四宫格，仍按四分之一位置安排。

已有左右两列时，将第三个窗口拖到某侧上／下角，只把这一侧拆成上下两格；原窗口进入另一半，另一侧保持原位置与宽度。左右两侧都拆分后形成四宫格。布局内部使用同一棵分割树，工具与对话可以任意混排。

拖到某侧中部吸附为全高时，也只合并这一侧：另一侧已有的上下分区、空格及调整过的比例都保留。被占用一侧的原窗口恢复浮动位置，不会塞入另一侧空格。预览、取消和松手落地遵循同一规则；从布局选择器明确选择新模板时，才整体重新排布。

其余空位可选择已打开的对话或工具窗口补齐，包括最小化窗口，按窗口最近使用顺序排序。选择后才迁移或恢复；关闭补齐选择保留已完成的布局，不自动打开其他内容。

- 同一工作区使用一套吸附分区。选择新模板会安排当前吸附组，放不下的成员恢复为自由窗口；占用已有位置时，原成员恢复记忆的浮动位置。
- 拖动共用分界线联动调整相邻窗口；方向键微调，Shift 加大步长，Home／Enter 或双击恢复默认比例，拖动时 Esc 取消。
- 拖离分区恢复浮动尺寸；最大化后还原回原格。最小化腾空原格，恢复时原格仍空且模板相同则回原格；关闭或弹出独立窗口腾空自身位置。
- 保存模板、比例、成员和浮动恢复位置。已保存布局在较窄窗口中保留比例，通过工作区滚动查看。独立系统窗口沿用系统行为和菜单迁移，不加入应用内吸附助手。

## 移动工具

- 拖动工具标签、卡片标题或握柄。移动超过 6px 后显示真实内容预览：自由移动呈现浮窗，吸附时呈现目的地的卡片或标签样式，并显示落点说明。松手才完成一次布局修改；取消后回到原位。
- 右栏可上下分为两组，底栏可左右分为两组；浮窗可放多个标签，不再分割。
- 右栏和底栏的握柄都只在指针靠近各自标签行最左侧时展开，标签向右让位（触屏设备常显）。浮窗不显示握柄，拖动窗口标题栏即可移动整组；移入左侧或对话工具区时，组内标签按顺序拆成卡片。
- Windows 按住 Ctrl、macOS 按住 Command 临时关闭吸附；Esc、失焦或指针取消会放弃操作。
- 不想拖动时，右键标签、标签行空白或浮窗标题栏，完成移动、浮动、排序、拆分、合并和隐藏。标签菜单内的“标签组”提供整组操作；键盘可用 Shift+F10 或菜单键打开，Esc 关闭。卡片的已有操作入口保持不变。

工具浮窗、拖动预览和恢复入口以“工具名 · 来源会话名”辨认归属。自由移动使用整个应用工作台范围；停靠只能回到来源对话的工具区、来源工具浮窗，以及当前显示该来源对话的共享左／右／底栏。经过其他对话不会转移任务，也不会透过其窗口吸附到背后的工具区。点击工具窗会切换主顶栏与共享栏的上下文，不自动前置其对话窗。来源会话重命名后标题同步更新，移动菜单遵循相同归属规则。

右侧栏顶部只有一行标签栏，没有单独的区域标题行，也不显示“…”按钮；隐藏右侧栏在组右键菜单里（标签铺满时仍可从单个标签的“标签组”进入）。右栏被窗口压到只剩一组时，组切换也在这行。底栏的窗口按钮压在标签行上，仍保留那条工具条。

右栏和底栏每条标签行在最后一个标签右侧都有“+”。点开选一个工具，就在该组末尾新建标签并切过去；菜单只列这组还没有的工具。标签少时加号紧跟着最后一个标签，不撑满整行；标签多到需要横向滚动时，加号停在标签区右缘，不会跟着标签滚走。

标签拥挤时先缩窄并省略标题，活动标签保留更多阅读空间；达到最小宽度后才横向滚动，也可通过“全部标签”切换。

卡片可以折叠和调整高度；更多菜单中的“恢复自动高度”会恢复内容自适应。画面工具初始高度约 320px，Terminal 的正文最小高度为 240px。手动拉伸的上限停在工具区的可见底边（对话工具区、左栏工具区段各按自己的底边算），卡片底边与拖拽条不会掉到视野外再靠滚动找回。折叠后标题右侧保留一条轻量摘要：Git 报工作区状态计数（M／A／D／U／!）与领先／落后，Changes 报最近一轮的文件数与行数增减；摘要从仓库状态与会话时间线直接发布，折叠时不会为了它挂载 Git 快捷卡或 Changes 正文。摘要最多占四组计数，完整拆分在悬停提示里。

左栏使用贴边的全宽工具区段，不再在侧栏里套卡片边框。只有 Explorer 时直接铺到工具区底部，不显示添加工具底条或空白分栏。拖入其他工具才形成上下多栏，不限于两栏；展开的工具共同分配可用空间，分界线只调整相邻两栏，比例随布局保存。每栏可以独立折叠，折叠后的标题默认收到底部，空出的空间交给其他展开栏；重新展开会回到展开栏区域。全部工具折叠后，上方项目／会话列表接管空出的空间。Files 的文件操作和折叠按钮共用一行标题，工具仍可从“视图 → 工具”中打开。

## 对话工具区

顶栏独立按钮控制显示／隐藏。完整卡片悬在对话容器内部右侧，各张卡片独立描边，整列没有侧栏底色或分隔线；正文和输入框为卡片留出阅读空间。工具区操作按钮在悬停或键盘聚焦时显示。悬浮图标模式点图标向左覆盖打开一个工具；再次点击、点击外部或按 Esc 收起，工具内菜单和对话框不会被当作外部点击。

空间不足时，完整卡片列暂时变为图标模式；窗口放宽后恢复首选模式。这种临时退让不会写回布局偏好。内置默认布局展开此区域，依次放置 Environment、Context、Git 快捷卡、Agents 和 Background tasks；Environment 与 Background tasks 展开，其余三张卡片折叠。

## 浮窗与隐藏

单个工具拖出后是独立页面，仅保留浮窗标题栏和正文；拖入第二个工具才显示标签行，移出或隐藏到只剩一个工具时自动收回。浮窗支持移动、缩放、最大化、还原和最小化。最小化后默认在对话区底部靠右显示胶囊，点击恢复；全部对话都在窗口里时改由窗口标签栏恢复。

工具正文按自身宽度换版式，而不是按应用窗口宽度：浮窗最大化、标签组全屏或把侧栏拉宽后，正文变宽就切到宽版，缩回侧栏宽度时还原为原来的紧凑版式。宽版各自重排：Changes 左侧文件列表、右侧单个文件的完整 Diff（↑↓ 切换文件）；子 Agent 对话保持阅读宽度，「详情」改为右侧常驻信息栏；Agents 变成按列对齐的表格；Git 的更改与 Diff 并排、历史与提交详情并排，视图切换并入标题行；BTW 话题从下拉框移到左侧列表；Environment、Context、Token 计数分别变成项目概览卡片、环形用量图和左右分栏；Explorer、Git 快捷卡、Problems 与 Tests 收进居中的阅读宽度。

对话、工具和固定浮窗的最小化胶囊都可以单独拖动，按住胶囊即可在当前应用窗口内容区自由摆放，轻点仍恢复窗口。拖动时按 Esc 或切走应用会回到拖动前的位置；拖动松手不会触发恢复。调整应用窗口大小时，已移动的胶囊会保持在可见范围内，并避开顶部系统标题栏。同一个窗口再次最小化时沿用本次运行中的胶囊位置，重启后回到默认位置；真实与预览位置分别记忆。布局锁定时仍可点击恢复，但不能拖动胶囊。

上下文查看器第一次打开时居中并压暗背景，点击背景不会关闭，Esc 可关闭。开始拖动标题栏时立即解除遮罩，缩放或最大化时保留；最小化、合并标签或选择 Pin 时也解除遮罩。以后恢复或打开时沿用上次位置。查看器跟随当前会话，只在打开、切换会话或点击「刷新快照」时重新采样，关闭时释放；切换标签、折叠和最小化会保留快照。狭窄面板中点击条目进入正文，再用返回图标回到列表；高度较低时可展开「详细指标」。

隐藏工具、折叠卡片、切换标签或应用预设不会结束终端、子代理或 BTW 任务。Browser／Computer 在真正不可见时沿用原观察释放规则；移动仍可见的工具不会通过重挂载重启观察。

在“视图 → 工具”、标签组右键菜单的“添加工具”、左栏空态或对话工具区的“添加工具”按钮，以及右栏／底栏标签行右端的“+”中找回工具。原有“打开 Git”“打开终端”“查看 Changes”等入口会定位工具当前位置，不会把它搬回默认位置。

## 固定浮窗与独立窗口

仅自由浮窗的标题栏提供 pin：位于最小化按钮左侧，悬停标题行或键盘聚焦时出现。已固定时标题旁保留状态标记。多标签按整组生效。

| 档位 | 行为 |
|---|---|
| 不固定 | 使用当前会话布局，只在工作台显示 |
| 固定在工作区 | 同工作区跨页面、跨会话保留；换工作区隐藏，返回恢复 |
| 固定在应用 | 跨页面、会话、工作区与执行目标保留 |
| 独立窗口 | 桌面版中成为普通系统窗口，可移动到另一显示器 |
| 独立窗口并置顶 | 同一个独立窗口保持在普通应用窗口上方 |

固定保留的是窗口；内容继续遵循工具自身的上下文规则，不会因为切会话重启 Shell 或改变任务归属。没有工作区时不能选择工作区固定。Web UI 中两种独立窗口选项不可用。

- 最小化保留 pin；应用内固定窗在页面右下角提供恢复胶囊（全部对话都在窗口里时改由窗口标签栏恢复）。独立窗口使用系统最小化，工具入口也能恢复并聚焦它。
- × 关闭整组并取消 pin，不结束终端或任务。下次打开按当前会话的普通布局恢复。
- 拖回停靠区的标签取消 pin；留在浮窗内的标签保持固定，移入固定组的标签继承档位。
- 独立窗口通过 pin 菜单收回应用；选择“不固定”时返回工作台。第一版不提供跨系统窗口拖拽停靠，窗口内标签仍能切换和排序。
- 关闭主窗口时独立窗口继续显示并可操作；选择退出应用才一起退出。
- 重启恢复未关闭的固定组、档位、尺寸和位置。窗口布局恢复不代表 Shell 进程或运行任务恢复；显示器断开时窗口调整到可见区域。
- 应用布局预设、重置布局和会话布局撤销不改变 pin。真实与预览状态隔离，演示操作不保存到真实布局。
- “独立窗口”不包含在所有系统虚拟桌面同时显示；置顶使用正常应用置顶层级。

## Agents 与子 Agent 对话

Agents 名册与子 Agent 详情独立停靠。每个子 Agent 对应一个详情标签，名册和主对话委派卡片共用入口；重复打开同一目标会激活已有标签。第一个默认进入右栏，新目标加入最近操作的 Agent 标签组；卡片区则插在该 Agent 后方。拖出标签即可并排、合组或浮动，重开已关闭的标签会恢复原位置。点击主 Agent 行返回主对话输入框。

名册的「当前会话」行右侧用两个图标切换「标准／极简」，悬停显示说明。标准保留任务、活动与用量；极简每个 Agent 固定一行，显示名称、实际运行模型和状态，完整信息可悬停查看或点击进入详情。运行状态使用绿色。没有实际模型时显示「模型未知」，不会把模型角色当成具体模型。真实模式记住密度选择，独立于停靠位置和布局预设；预览中的切换仅影响本地演示。

名册折叠后，标题显示子代理状态计数；最小图标的分段外圈表示状态数量分布，角标是子代理总数，均不包含主 Agent，也不表示完成百分比。悬停可查看各子代理的名称、状态和模型。断连或历史记录使用中性色并标明来源。折叠时仍更新轻量摘要，不会因此挂载子代理对话。真实模式仅显示可确认的状态，不从运行状态推断「思考中」或「等待用户」。

Agent 标签显示名称与状态点，悬停查看名称、状态和实际模型；已打开项在名册中有标记，最近操作项使用选中态。详情的「对话」与主对话共用消息、Markdown、工具卡片、代码高亮和输入组件，遵循相同字体设置；窄面板和低高度面板只压缩身份栏、外边距与输入区，输入区域仍标明接收对象。工具区中的详情按固定高度阅读，可通过原有拖拽条调整高度。

「定位委派」定位发起任务的消息；来源尚未加载时提示先加载更早消息。名册入口没有可靠来源时不显示该操作。委派卡片是来源引用，详情读取父会话下该 Agent 的对话，并不是某次委派的独立历史快照。Agent Hub 保留完整管理功能，BTW 使用独立话题。

草稿、待发消息、内容页签与阅读位置按连接目标、工作区、父会话和 Agent 隔离。多个可见详情各自同步；切换后台标签、隐藏、折叠或最小化会暂停对应的热更新和本地队列，恢复查看并同步目标后继续。关闭标签释放正文和订阅，不停止 Runtime 任务；重新打开保留本次运行中的草稿与位置。Agent 产生新运行代次时，旧队列不会自动发送，需要逐条确认发送或移除。断连保留已读内容和草稿，历史对话只读。

每个主会话保存自己的打开标签和位置，重启后恢复；草稿、附件、待发队列和阅读位置只保留到本次应用退出。布局预设保存通用子 Agent 落点，不保存具体身份；应用预设时，当前打开的 Agent 移至该落点。自由浮窗中的子 Agent 也可使用下述全部 pin 档位，每个实例保留自身目标身份；离开其来源会话后保留窗口，沿用目标不可用／只读状态，不向其他会话中的同名 Agent 发送操作。预览使用同一套卡片与详情，演示输入不调用 Host。

## 保存与预设

每个连接目标、项目和会话独立保存布局。新会话默认使用项目默认预设，未设置则使用应用默认，再回退到内置默认。

内置默认布局的左栏只有 Explorer，右侧栏为空且隐藏，底栏完全隐藏，保留 Terminal、Problems、Tests、Output、OMP Logs 和 Preview Logs，当前标签仍为 OMP Logs。已有会话继续恢复保存的布局；选择“恢复出厂布局”可应用这套默认配置。

“设置 → 外观与布局 → 工作台布局”提供：

- 默认、专注、调试三个内置预设。
- 自定义预设的另存、更新、重命名和删除。
- 项目默认和应用默认的独立设置。
- “新会话沿用本项目上次布局”，默认关闭；开启后只复制新会话的起点，不联动已有会话。
- 锁定布局和停靠吸附。
- 恢复当前预设、恢复出厂布局、布局撤销／重做。

布局撤销只保留本次运行中当前会话的最近 20 次编辑，不占用编辑器／终端的 Ctrl+Z。普通标签浏览不加入撤销记录。

旧版布局会迁移为带来源名称的“旧布局”自定义预设；旧存储键不删除，新默认不会自动套用旧布局。预览模式的布局和预设演示不覆盖真实保存数据。

## 面板正文（排版归模块自己）

停靠宿主 `.dock-panel-content` 是一个固定尺寸、`overflow: auto` 的盒子，并且会把**直接子元素**撑成 `height: 100%`（`dock.css`）。支持保留活动内容的 DOM 移动时，展开的对话工具卡将宿主放在卡片占位框内，让正文和工具列表使用原生嵌套滚动；其他情况仍使用固定定位宿主。它不提供页边距，也不提供滚动结构 —— 这两件事都由模块自己负责；旧底栏 `.bp-page` 提供的 10/14px 页边距在停靠后已经不存在。

所以一页正文只能是**一个根元素**，由根元素决定排版：

| 形态 | 适用 | 说明 |
|---|---|---|
| `.dock-doc` | Output、OMP Logs | 标题栏（masthead）+ 自己的滚动区；账本行、sticky 列头都在滚动区内。卡片模式（`data-dock-auto-height`）下改为按内容高度，列表最高 220px。见 `apps/renderer/src/panels/panels.css`。 |
| `.dock-pad` | Problems、Tests、Preview Logs | 保留各自的行／提示条结构，只补回页边距；滚动交给宿主。 |
| 自己的 `height: 100%` 根 | Terminal、Browser、Computer、Files、Git | 画布／终端填满面板，页边距与滚动都由模块内部负责。 |

不要直接返回多个兄弟块（工具栏 + 列表）：每个兄弟块都会被撑成 `height: 100%`，带 `flex: 1` 的列表会被挤到 0 像素。`.ch-toolbar` 把 `.ch-list` 挤没就是这个结构，属于必须避免的写法。

## 快捷键

| 动作 | 快捷键 |
|---|---|
| 左栏 | Ctrl/Cmd+B |
| 底栏 | Ctrl/Cmd+J |
| 对话工具区 | Ctrl/Cmd+Shift+L |
| 下一个／上一个区域 | F6／Shift+F6 |
| 取消拖动／收起覆盖层 | Esc |

所有自由浮窗（包括多实例子 Agent 与网页标签）均支持应用内固定和独立系统窗口。终端、浏览器、电脑操控与 BTW 为单实例；文件、变更、Git、Agents、环境、Token 计数、Problems/Tests/Output/Logs 可在每个区域各开一个实例（id 形如 `files@2`），同一区域仍只保留一个。子 Agent 详情与聊天浏览器的网页可有多个实例。网页标签的 × 关闭网页本身（不是隐藏工具），Agent 新开的网页落在最近查看的网页旁且不展开隐藏区域，布局预设只记住「Browser」的位置，不记具体网页；详见 [浏览器使用说明](browser.md)。不支持无限嵌套分组或预设文件导入导出。Web 布局可用，但本机终端等桌面能力仍按原规则显示不可用说明。


## Background tasks

Background tasks 在内置默认布局的对话工具栏中展开，也可从「添加工具 / 新建标签页」的「自动化」分类中打开。已有会话继续恢复保存的布局；既可作为正常窗口，也可加入对话工具栏。两处可以同时显示，服务与后台任务共用一份状态。

- 活动列表显示主对话 Agent 启动的服务与后台命令，按实际会话归属过滤，不显示子代理、其他会话和未标明归属的基础设施进程；最近结束项默认折叠，有失败时仍显示失败数量。结束项受 Runtime 保留窗口约束，并非永久历史。
- 工具栏卡片支持展开、折叠、图标态；展开后每项一行，使用小号类型图标，保持紧凑行高。「最近已结束」是卡片底部，不再有「打开窗口」底栏。
- 点击工具卡里的后台命令或「查看启动过程」时，优先复用已在右侧栏的 Background tasks 页；右侧没有时，仅复用点击前正聚焦且活动标签为 Background tasks 的其他工具窗口，否则在右侧栏新开详情页。不同任务在同一页内切换，保留工具卡和原有未聚焦浮窗，不为每项新建标签；沿用来源会话隔离和布局锁定规则。
- 过程视图以只读最近输出为主，执行信息可展开；运行中更新，向上阅读时暂停跟随。正文宽时左右分栏，窄时通过返回按钮切换列表和详情。
- 停止服务需要确认，并只操作对应服务实例；任务取消沿用 Runtime 确认。收到停止请求不代表已结束。关闭/隐藏工具不会停止资源。
- 只有可见的选中详情刷新日志，隐藏后暂停。未连接或部分能力不可用时保留明确提示，不填充假任务或假服务地址。
- 点击带 Runtime 预览地址的活动服务，打开或聚焦对应 Browser 标签；服务页面内部跳转后再次点击也会复用原标签。右键或 Shift+F10 可查看启动过程。未上报地址、已结束或当前连接不支持内置网页时显示运行输出，不弹出手填地址表单。
- 预览使用同一组件，所有演示操作仅修改本地数据。服务网址由 Agent 的启动调用提供，并绑定 Runtime 服务实例；不是从名称、命令或终端文字猜测。

### Agent 开发服务地址

主对话 Agent 用带 `name` 的 `bash` 工具启动托管服务；对于网页服务同时提供 `previewUrl`。这些是 Agent 工具参数，不是需要用户填写的设置。例如本项目的 Vite 服务：

```json
{
  "name": "renderer-dev",
  "command": "npm run dev -w @omp-studio/renderer -- --host 127.0.0.1 --port 5173 --strictPort",
  "previewUrl": "http://127.0.0.1:5173/",
  "ready": { "host": "127.0.0.1", "port": 5173 }
}
```

Broker 保留实际实例的预览地址、PID 和会话归属，再通过 Studio 服务列表发布给界面。非网页服务无需地址。旧 Runtime / 旧 broker 没有这项元数据时不能伪造网页，升级不会自动终止已有服务；新的服务预览链路需要相应 Runtime 产物与 broker。
