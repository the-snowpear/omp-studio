# 工作台停靠与布局

OMP Studio 的工具可以在左侧栏、对话工具区、右侧栏、底栏和应用内浮窗之间移动。项目／会话导航固定在左侧，对话和输入框不参与停靠。

## 移动工具

- 拖动工具标签、卡片标题或握柄。移动超过 6px 后显示落点说明，松手完成一次布局修改。
- 右栏可上下分为两组，底栏可左右分为两组；浮窗可放多个标签，不再分割。
- 整组握柄移动整组；移入左侧或对话工具区时，组内标签按顺序拆成卡片。
- Windows 按住 Ctrl、macOS 按住 Command 临时关闭吸附；Esc、失焦或指针取消会放弃操作。
- 不想拖动时，使用标签／卡片／组的更多菜单，完成移动、浮动、排序、拆分、合并和隐藏。

卡片可以折叠和调整高度；更多菜单中的“恢复自动高度”会恢复内容自适应。画面工具初始高度约 320px，Terminal 的正文最小高度为 240px。

## 对话工具区

顶栏独立按钮控制显示／隐藏。完整卡片列占用宽度；悬浮图标模式不占对话宽度，点图标向左覆盖打开一个工具。再次点击、点击外部或按 Esc 收起；工具内菜单和对话框不会被当作外部点击。

空间不足时，完整卡片列暂时变为图标模式；窗口放宽后恢复首选模式。这种临时退让不会写回布局偏好。新会话默认完全隐藏此区域，Agents 已预放其中。

## 浮窗与隐藏

浮窗支持移动、缩放、最大化、还原和最小化。最小化后成为输入框上方的胶囊，点击恢复。

隐藏工具、折叠卡片、切换标签或应用预设不会结束终端、子代理或 BTW 任务。Browser／Computer 在真正不可见时沿用原观察释放规则；移动仍可见的工具不会通过重挂载重启观察。

在“视图 → 工具”或“添加工具”中找回工具。原有“打开 Git”“打开终端”“查看 Changes”等入口会定位工具当前位置，不会把它搬回默认位置。

## 保存与预设

每个连接目标、项目和会话独立保存布局。新会话默认使用项目默认预设，未设置则使用应用默认，再回退到内置默认。

“设置 → 常规 → 工作台布局”提供：

- 默认、专注、调试三个内置预设。
- 自定义预设的另存、更新、重命名和删除。
- 项目默认和应用默认的独立设置。
- “新会话沿用本项目上次布局”，默认关闭；开启后只复制新会话的起点，不联动已有会话。
- 锁定布局和停靠吸附。
- 恢复当前预设、恢复出厂布局、布局撤销／重做。

布局撤销只保留本次运行中当前会话的最近 20 次编辑，不占用编辑器／终端的 Ctrl+Z。普通标签浏览不加入撤销记录。

旧版布局会迁移为带来源名称的“旧布局”自定义预设；旧存储键不删除，新默认不会自动套用旧布局。预览模式的布局和预设演示不覆盖真实保存数据。

## 快捷键

| 动作 | 快捷键 |
|---|---|
| 左栏 | Ctrl/Cmd+B |
| 底栏 | Ctrl/Cmd+J |
| 对话工具区 | Ctrl/Cmd+Shift+L |
| 下一个／上一个区域 | F6／Shift+F6 |
| 取消拖动／收起覆盖层 | Esc |

首版不支持独立系统窗口、跨屏弹出、无限嵌套分组、同一模块多个实例或预设文件导入导出。Web 布局可用，但本机终端等桌面能力仍按原规则显示不可用说明。
