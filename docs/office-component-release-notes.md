# Office 文档预览组件

OMP Studio 现在可以在通用工作台窗口中查看文件，并直接编辑文本与代码。

Word、PowerPoint、ODT、ODP、RTF 使用单独安装的 **Office 文档预览** 组件。在 **设置 → 更新与维护 → 可选组件** 中安装，安装后无需重启应用。

组件默认不安装，不随 OMP Studio 主程序打包。点击需要组件的文件时，文件窗口内会显示安装入口。Excel 和 CSV 已内置支持，无需安装 Office 组件。

组件基于 LibreOffice，在本机将文档转换为静态页面。SSH 工作区的文档同样在桌面本机转换，远端无需安装 LibreOffice。PPT 动画、Office 编辑和公式重算不在本组件范围内。

安装包保留 LibreOffice 及其第三方组件的许可文件。来源及许可证信息见每个平台的已签名组件清单。
