# 设置

设置页左侧按用途分类，可搜索中文、英文或 Runtime 配置键。选择搜索结果会打开对应分类并定位到设置项；搜索未启用的记忆后端时可以查看其设置，不会自动切换后端。

语言、主题、字体、背景、布局和通知等应用偏好保存在当前设备。运行设置默认保存到用户配置；在分类顶部可切换为仅当前会话。项目配置、启动覆盖、环境变量或现有会话覆盖可能优先于用户配置；页面会显示设置来源和覆盖提示。部分设置需要重启 Runtime 才会生效。

上下文压缩的固定 token 阈值优先于百分比阈值；模型专属配置可能进一步覆盖它们。子任务运行时限是硬时限，请求预算是软预算。回答详略只影响支持该参数的 OpenAI Responses 和 Codex 模型。

附加工作区目录会成为 Agent 的额外工作区根目录，可供读取和搜索；相对路径按当前项目解析。工作区树会进入系统提示，目录变化可能影响提示缓存。编辑模式可能被模型专属规则或环境变量覆盖；Hashline 模式即使关闭默认行号也会使用行号。LSP 复用设置影响后续建立的连接，不会改变已运行的连接。

记忆后端可选择关闭、本地摘要、Mnemopi、Hindsight 或 Sharpshooter。Mnemopi 与 Hindsight 的自动召回发生在会话首轮；自动保留会处理完成的对话轮次。记忆功能可能使用已配置的模型服务；Hindsight 会向所选服务发送对话内容。设置页的“检查服务”会请求当前记忆库，并区分连接、认证和未找到等结果。

在桌面设置页输入的 Hindsight 令牌按运行环境和服务地址存放在系统加密的本机存储中，界面不会读回令牌。SSH 连接只临时把该目标的令牌传给远端 Host／Runtime，远端不落盘；断开时清除远端临时凭据，重新连接后再次同步。已有环境变量和 Runtime 配置中的令牌优先。浏览器访问使用 Runtime 环境已有的凭据配置。改变服务地址时，原地址的加密令牌不会发送给新地址。

异步后台任务并发有效范围为 1–100，默认读取行数有效范围为 1–3000。隔离设置允许子任务按需请求隔离；未请求隔离的子任务仍共享工作区。启用自动应用时，成功的隔离任务可通过补丁或分支合并将修改带回。新会话默认 Plan 只作用于全新且没有明确模式的会话。

电脑操作设置提供会话/全局启用、原生默认显示器、截图尺寸和后台回退。观察面板的固定目标不是这些执行设置，也不是授权范围。关闭当前会话能力会先停止本会话的电脑操作；修改全局默认不会覆盖明确的会话配置。详细的审批、停止/继续与截图保留范围见[电脑操作](computer-use.md)。

运行设置需要连接支持相应能力的 Runtime。旧版本缺少某项时，该项会说明不可用原因。尚未接入的功能集中在“待支持”，不会改变运行行为。

模型、Provider 和模型角色由模型配置页管理；设置页提供相关入口。对话宽度、字体、听写和更新设置的细节分别见[对话宽度](conversation-width.md)、[字体](fonts.md)、[语音输入](dictation.md)和[更新](updates.md)。
