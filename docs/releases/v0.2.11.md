## 独立 Web 工作台

浏览器与桌面连接同一个 Host，共用项目、会话、文件、Git、模型配置及交互终端。退出桌面程序后，Host 和终端继续运行。本机使用配对链接连接；局域网访问支持 HTTPS、导出 CA 证书、持久设备授权及单设备控制权接管。 [#60](https://github.com/the-snowpear/omp-studio/issues/60)

无桌面环境可下载对应的 `omp-studio-remote-0.2.11-<平台>` 运行环境包，解压后执行 `omp-studio-web.cmd start`（Windows）或 `./omp-studio-web start`（macOS / Linux），再运行 `pair` 获取配对链接。提供 Windows、macOS、Linux 的 x64 / ARM64 六种运行环境。升级前先结束活动并停止旧 Host，再替换运行环境包。 [Web 使用说明](https://github.com/the-snowpear/omp-studio/blob/v0.2.11/docs/web-ui.md)

## 图表、会话和输入

- **Mermaid 图表浮窗**：从正文打开大图，按原尺寸阅读，滚轮缩放、拖动平移、适应窗口或切换源码。支持停靠、最大化、Pin 独立窗口及置顶，离开原消息仍可继续查看。 [#72](https://github.com/the-snowpear/omp-studio/issues/72)
- **当前窗口开新会话**：`/new`、快捷键和菜单保留当前窗口的布局、运行中的终端、输出、活动终端及文件未保存编辑。布局继承默认开启；无项目时可沿用当前连接最近布局，已有偏好保留。 [#73](https://github.com/the-snowpear/omp-studio/issues/73)
- **命令菜单可靠关闭**：确认、Tab、Escape、点击外部、输入空白或离开命令 token 后保持关闭，后续输入与重新聚焦不再反复弹出。 [#74](https://github.com/the-snowpear/omp-studio/issues/74)

## 其他改进

- 后台任务窗口提供紧凑任务行及「全部停止」，修复并发停止时服务状态被旧请求覆盖的问题。
- 移除显示器后，完全离屏的独立窗口回到工作台。
- Windows 远端上传在 SFTP、SCP 不可用时继续尝试 SSH 流式传输。
- 共享 Host 终端不再向用户 Shell 传递 Electron 启动开关；文件浏览器保留系统重定向目录。
- 中英文官网新增可交互演示、FAQ、浏览器语言路由与自动更新的下载信息。 [访问官网](https://the-snowpear.github.io/omp-studio/)

## English

OMP Studio 0.2.11 adds a standalone Web workbench. Desktop and browser clients share one Host, projects, conversations, files, Git, model configuration and persistent terminals. The Host survives desktop exit. Local pairing and LAN HTTPS support remembered devices and explicit control transfer. Six Windows/macOS/Linux x64/ARM64 environment archives include the `omp-studio-web` launcher. This release covers a single account on the local machine or LAN; public multi-user hosting remains separate. [Web guide](https://github.com/the-snowpear/omp-studio/blob/v0.2.11/docs/web-ui.md) · [#60](https://github.com/the-snowpear/omp-studio/issues/60)

- Large Mermaid diagrams open in movable windows with actual-size viewing, zoom, pan, fit and source view, including native Pin and always-on-top controls. [#72](https://github.com/the-snowpear/omp-studio/issues/72)
- `/new`, the shortcut and menu reuse the current window while preserving layout, live terminals, output and unsaved file edits. Layout inheritance defaults on, including the connection's last layout without a project; existing preferences remain. [#73](https://github.com/the-snowpear/omp-studio/issues/73)
- Command completion stays dismissed after selection, Tab, Escape, outside clicks or leaving the command token. [#74](https://github.com/the-snowpear/omp-studio/issues/74)
- Background tasks gain compact rows and Stop all. Offscreen native windows return after display removal, Windows uploads retain SSH streaming fallback, terminal environments exclude Electron launch switches, and system folder shortcuts retain redirected locations.
- The bilingual website adds interactive demos, FAQ, browser-language routing and current release downloads.

Runtime remains `19.0.1-studio.1`. Windows x64 has local execution and UI evidence; other platforms require the release packaging checks and have not received local physical-device acceptance in this review. See the [verification record](https://github.com/the-snowpear/omp-studio/blob/main/docs/reviews/v0.2.11-release-review.md).
