## 修复内容

- **新对话能正常发出第一条消息。** 新草稿绑定自己刚创建的会话时，不再误报「发送期间已切换会话」并取消发送。真正切换到另一场对话时仍保留原有取消与草稿恢复行为。
- **Runtime 连接后恢复正确的操作能力。** 冷会话初始的空能力清单会失效并重新读取，避免已经连接仍无法发送；旧请求结束也不会覆盖新 Runtime 的能力读取。
- **首条消息前可以选择模型。** 选择时使用对应模型新建或恢复会话，连接期间保留输入框草稿；打开菜单和阅读历史仍保持按需启动。
- **点击「更多模型」保持列表展开。** 修复鼠标移入已展开子菜单、紧接着点击又把列表关闭，导致无法继续选择模型的问题。
- **正常待启动状态不再显示成故障。** 没有失败记录的会话显示「Runtime 未启动」和「立即连接」。真实启动失败继续显示错误原因，重试成功后清除。
- **输入预测可以接入 v2 通道。** 修复输入框下方出现 `Invalid prediction fields`、灰色补全无法启用的问题。
- **当前项目可以再次展开。** 修复侧栏当前激活项目一旦收起，就无法重新展开查看会话列表的问题。
- **后台任务列表正常显示服务记录。** 合法的服务所有者、PID 和预览地址不再被旧结果字段白名单拒绝，避免面板反复报错和重复通知。该修复需要本次新 Runtime。

## 升级与范围

在「设置 → 更新与维护」检查桌面更新，或运行对应平台的完整安装程序。仅更新 Runtime 不包含桌面端的输入预测修复；仅更新 Renderer 也无法修复旧 Runtime 中的后台服务问题。

如果 0.2.0 首次发送失败后留下无消息的旧对话引用，升级后可点击「新建对话」重新开始。模型、凭据和历史会话使用既有配置目录。

本次仍使用 OMP 18.18.0，不包含 OMP 18.19.0 升级、官网改版或 Linux 桌面适配。既有六平台 SSH 远端环境继续发布，Linux SSH 环境与 Linux 桌面支持是不同功能。

「模型删除很慢」的反馈尚未完成现场计时与根因确认，本版不将其列为已修复。完整审查方法、验证结果和未覆盖范围见 [发布审查记录](https://github.com/the-snowpear/omp-studio/blob/v0.2.1/docs/reviews/v0.2.1-release-review.md)。
