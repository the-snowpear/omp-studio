# OMP Studio 0.1.17

修复 macOS 首次启动 Runtime 激活失败，以及升级后旧 Runtime 与 Worktree 弹窗阻塞的问题。内置 Runtime 继续使用 **OMP 18.13.2 / 18.13.2-studio.10**。

## 安装下载

| 平台 | 安装包 |
|---|---|
| Windows x64 | [下载 Setup](https://github.com/the-snowpear/omp-studio/releases/download/v0.1.17/OMP-Studio-Setup-0.1.17-windows-x64.exe) |
| Windows ARM64 | [下载 Setup](https://github.com/the-snowpear/omp-studio/releases/download/v0.1.17/OMP-Studio-Setup-0.1.17-windows-arm64.exe) |
| macOS Apple Silicon（M 系列，macOS 13+） | [下载 DMG](https://github.com/the-snowpear/omp-studio/releases/download/v0.1.17/OMP-Studio-0.1.17-macos-arm64.dmg) |

Windows 升级前，请在系统托盘右键 OMP Studio 并选择「退出」。macOS 用户请安装本版完整 DMG；此前被隔离的 Runtime 无需手工删除，新版会重新播种。首次打开被拦截时，可在「系统设置 → 隐私与安全性」选择「仍要打开」。会话与设置保留。

## 修复与改进

- **macOS Runtime 无法启动（[#18](https://github.com/the-snowpear/omp-studio/issues/18)）**：恢复构建工件下载时丢失的执行位。打包暂存与本机安装均设置 `0755`，不修改 Runtime 的签名字节；继续审计最终 App 与更新 ZIP 的权限、签名和架构。自检失败信息包含具体原因和隔离位置。
- **升级仍使用旧 Runtime（[#19](https://github.com/the-snowpear/omp-studio/issues/19)）**：启动时将旧 Runtime 升级到较新的随包版本，经过验签、自检后才切换。已有同版、新版或从该版本回滚的选择会保留；多版本兼容仍按协议握手和能力协商判断。
- **Worktree 弹窗关不掉（[#19](https://github.com/the-snowpear/omp-studio/issues/19)）**：支持关闭、Esc 和重新打开，等待时显示进度，失败后允许重试；断开 Runtime 时撤下弹窗。关闭提示不会取消已提交的创建操作，也不会跳过发送前的工作区选择。
- **启动状态准确性**：Runtime 在握手后断开时不再发布虚假就绪，启动错误保留在诊断中。

Windows Setup 尚无 Authenticode 签名。macOS 包采用 ad hoc 签名，尚未经 Apple 公证。Runtime 与更新清单继续使用既有 Ed25519 发布密钥验证。六种 SSH 远程环境包继续随 Release 提供。
