# OMP Studio 0.2.0

如果说 `0.1.x` 的 OMP Studio 还算是一个「长得挺规矩的单栏聊天控制台」，那 `0.2.0` 基本就是把承重墙拆了重装了一遍。

在这个跨版本大更新里，我们把单栏工作台改造成了支持自由拖拽、分屏吸附与多显示器独立窗口的桌面工作台；顺手造了一台不污染 Git 历史的「工作区时光机」（Time Travel）；把内置浏览器和文件查看器变成了真正能干活的生产力工具；并将底层引擎跨代升级到了 **OMP 18.18.0（`18.18.0-studio.1`）**。

更重要的是，塞进这么多东西之后，首屏加载反而比以前更轻了。

## 核心亮点

### 1. 工作台「拆墙」：多窗口、自由停靠与分屏吸附

以前切个会话就像电视换台，看一眼别的对话就得把当前画面切走；工具面板也各占各的坑，挪不动。现在，对话和工具共用同一套窗口系统：

- **对话随便拖**：从左侧列表把会话往外一拽就是独立浮窗，支持多场对话并排对照。拖到边缘自动预览半屏或四分之一屏吸附，悬停最大化按钮还能直接选「左右 2:1 / 三列 / 四宫格」等六种布局模板；按住 `Ctrl`（macOS 为 `⌘`）可随时反悔暂停吸附。
- **工具随便搬**：Git、Terminal、Changes、Agents、Browser 等工具可以在左栏、右栏、底栏、对话工具区和浮窗之间自由迁移或合并成标签组。面板拉宽或最大化时会自动切换为「宽屏双栏版式」（例如 Changes 左列文件、右列完整 Diff），缩回侧栏又乖乖变回紧凑模式。
- **钉上副屏与胶囊收纳**：桌面版支持把任何对话或工具浮窗 Pin 成真正的系统独立窗口，直接扔去副屏或置顶。最小化后的窗口会变成可自由拖动摆放的小胶囊；重启应用后布局、草稿与终端状态原样奉还。
- **防迷路指南**：怕老用户一升级找不着北，首次进入 0.2.0 会弹出一段 8 步低保真交互动画教程。老实看完一遍就能关掉，之后随时可以从「帮助 → 使用教程」重温。详见 [工作台停靠说明](https://github.com/the-snowpear/omp-studio/blob/v0.2.0/docs/workbench-docking.md)。

### 2. 真正的「后悔药」：Time Travel 工作区时光机

Agent 改代码改嗨了、或者聊到第五轮发现方向歪了，以前想退回三轮前的状态往往得自己去翻 Git 甚至手搓 `reflog`。

- **按回合存快照，不碰 Git**：开启 Time Travel 后，每轮对话前后会自动对工作区打下检查点（哈希去重 + 压缩存储），完全独立于 Git，不提交代码、不乱动 `HEAD` 和暂存区。
- **三种反悔姿势**：在历史时间线里可以选**只恢复代码**、**只恢复对话分支**，或者**两者一起恢复**。动手前会明确列出即将新增、覆盖和删除的文件清单。
- **给后悔药再买一份保险**：每次执行恢复前，系统会自动生成一份「恢复前备份」挂在时间线里——万一发现退错了版本，还能再退回来。功能默认关闭，在会话页或设置中阅读代价说明后即可开启。详见 [Time Travel 说明](https://github.com/the-snowpear/omp-studio/blob/v0.2.0/docs/time-travel.md)。

### 3. 聊天内置原生浏览器：人机同屏、指哪打哪

内置浏览器不再是只能干瞪眼的旁观小窗，而是直接并入工作台标签行的原生网页（支持多标签、持久登录空间、独立权限与下载管理）：

- **「Agent | 我」一键交接方向盘**：Agent 操作网页卡在登录页或复杂交互？点一下工具栏的「我」即可接管控制权，网页四周亮起主题色细框，你直接输入、滚动、点按钮；搞定后再点「Agent」把控制权交回去，不打断其它任务。
- **指着元素提修改**：不用再苦口婆心地跟 Agent 描述「右上角往下数第二个蓝色按钮偏左了」。开启「选择页面元素」直接点网页上的目标，它的 DOM 路径、文本和区域截图会自动打包成引用胶囊塞进输入框。
- **原生 WebMCP 与后台省电**：接入原生 WebMCP 控制器；网页标签隐藏且闲置满 30 秒后自动进入后台节流（但只要有 Agent 操作、音视频播放、下载或打开了 DevTools，就绝不偷懒装死）。详见 [浏览器使用说明](https://github.com/the-snowpear/omp-studio/blob/v0.2.0/docs/browser.md)。

### 4. 通用工作台文件查看器：少切几次外部编辑器

在文件树或对话里点文件路径（包括行内代码里的 `src/main.ts:42`），现在会直接在工作台打开文件窗口，本地与 SSH 远端共用同一套读写链路：

- **代码编辑与外部冲突保护**：支持语法高亮、查找替换、行号旁实时显示 Git 增删改色条，一键切换统一/并排 Diff，选中代码即可 `@ 添加到对话`。当源文件被 Agent 或外部程序改动时，编辑器会护住你的本地未保存草稿，让你从容选择对比、重新加载或覆盖。
- **多格式开箱即看**：直接预览 Markdown（源码/分栏同步滚动）、PDF、图片、音视频与 Excel/CSV 表格。
- **克制的 Office 预览组件**：如果你确实需要在里面看 Word 和 PPT，可以在「设置 → 更新与维护 → 可选组件」里按需安装独立的 Office 预览组件——我们没有为了它给主程序安装包平白塞进几百兆体积。详见 [文件查看器说明](https://github.com/the-snowpear/omp-studio/blob/v0.2.0/docs/file-viewer.md)。

### 5. Runtime 跨代升至 OMP 18.18.0

跨越上游 8 个版本、2,100+ 次提交的运行时大合流（详见 [18.18.0 迁移报告](https://github.com/the-snowpear/omp-studio/blob/v0.2.0/docs/migrations/omp-18.18.0.md)）：

- **Worker 子 Agent 与任务治理**：子代理支持运行在独立 worker 线程（第 9 个并发子代理起自动进入工作线程），支持任务文件（`taskFile`）及受原生配置约束的单次精确模型与 effort 选择；子代理账号策略直接并入详情页统一保存。
- **排队压缩与中途互动**：不用干等当前回合结束就能把「上下文压缩」排进队列；对话支持 `out://` 中途回复；BTW 旁路问答支持将回答直接注入主对话（运行中 steer、空闲时 prompt），支持中止后继续追问与粘贴图片路径。
- **输入预测与按住空格听写**：Composer 一次预测可给出最多 4 条候选，按 `Tab` / `→` 仅填入草稿不误发；工作台与 BTW 支持点击或按住空格语音听写，光标处直接插入并可撤销，断网或切走页面也能保住内存录音。详见 [语音输入说明](https://github.com/the-snowpear/omp-studio/blob/v0.2.0/docs/dictation.md) 与 [BTW 使用说明](https://github.com/the-snowpear/omp-studio/blob/v0.2.0/docs/btw.md)。
- **硬核可观测性**：新增原生 Shell Raw/Pseudo 可视化与时间轴回放、Context 提示缓存冷热与保温详情、作业用途说明、Bash 精简统计，以及 Eval JSON 树展开与内核重启提示；对话工具区新增 **Environment 卡片**，一眼看清项目路径、执行位置、Runtime 版本、分支与未提交变更。
- **模型、语音与评测生态**：内置 4,963 个模型的注册表目录；补齐 Mistral Vibe / Devin 登录、Modular Cloud、Keenable、Hindsight 全局记忆、手动 Skills；Web/SSH 环境支持通过浏览器 WebRTC 使用实时语音；电脑操控（[电脑操作说明](https://github.com/the-snowpear/omp-studio/blob/v0.2.0/docs/computer-use.md)）与评测工作区（[评测说明](https://github.com/the-snowpear/omp-studio/blob/v0.2.0/docs/evaluation.md)）同步升级。

### 6. 性能、动效与安全打磨

功能翻倍通常意味着变卡，所以我们专门花了一轮时间把膨胀的苗头摁了下去：

- **首屏减负与按需加载**：首页、历史、统计、教程以及 Git、上下文查看器、Computer、本地文件编辑器全部改为首次打开时才加载，首屏静态 JS 体积缩减约 27%；打包产物剔除调试映射与非目标架构 PTY 文件。
- **切换会话与打开历史不再顿挫**：会话归档解析搬进共享 Worker，切换会话优先展示热缓存并锁死阅读位置锚点；Time Travel 时间线改读轻量摘要（200 个检查点场景下列表内存峰值下降 93%）；历史缩略图按当前消息分页读取，删会话时不再憨厚地先把所有图片读进内存；超过 8 MiB 的巨型会话依然能正常查看标题和翻页。
- **全界面动效收口**：页面切换、标签滑动、弹层升降与菜单入场统一为同一套节奏；切换明暗主题改为整窗一次平滑溶解，不再看着各个色块排队变色。开启「减少动效」或处于低配档位时，彻底停用逐元素过渡，点击响应干脆利落。
- **让人血压下降的关键修复**：后台取消作业、杀子 Agent 和发 BTW 不再排在主回合后面干等；Git 单文件操作改用字面路径（文件名里带 `[1]` 终于不再误伤兄弟文件）；Windows 关窗不再被隐藏的内置浏览器窗口拦住退出；还没发消息的空会话断线重连不再报 “Session not found”；SSH 出口代理强制要求连接认证并校验公共地址。

### Changed

- **次级页面按需加载与快照/缩略图减负**：首页、历史、统计和教程内容按首次打开加载；长会话缩略图按当前消息读取，删除时不再读回图片内容。Time Travel 时间线使用轻量摘要，捕获和恢复仅读取所需的完整快照，旧检查点首次访问时建立摘要缓存。
- **官网帧窗口与补丁字节稳定性**：官网滚动序列采用邻近帧窗口，限制在途加载并释放离开后的位图；性能采样只清理自身隔离进程，Runtime 接缝补丁在不同 Git 历史或配置下保持字节稳定。
- **重型工具面板延迟加载**：Git、上下文查看器、Computer 和本地文件编辑器首次打开时才加载；模型配置的专属样式随页面加载，降低工作台首屏读取量。
- **内置网页后台节流**：内置网页隐藏且闲置 30 秒后启用后台节流，保留页面和表单状态；Agent 操作、加载、下载、音视频和 DevTools 使用期间保持正常运行。
- **桌面发行物裁剪**：移除调试映射、工作区源码与非目标架构的 PTY 文件；原生终端和归档 Worker 保留。
- **全界面动效统一**：页面、标签、弹层与提示共用同一套节奏和方向——页面与标签按导航顺序横向切换，盖在上层的页面与编辑器升起、下沉；输入框的模型、模式、权限、指令菜单补齐入场；主题切换改为整窗一次溶解，不再逐块变色。开启「减少动效」或处于低配档位时不再为每个元素生成过渡，点击后的卡顿明显减少。
- **会话恢复与导入并入工具区**：会话历史的 OMP 恢复与 Claude / Codex 导入并入工具区，沿用原生选择器的搜索、键盘选择、会话预览和显式继续动线；恢复展示原生消息摘录与 Worktree 归属，导入支持原目录失效后的目标工作区选择，收起弹窗保留目录位置。
- **标注工作台三栏重做**：重做为来源、原文与意见并排的工作台，支持行号、高亮和双向定位；保留来源快照、审查准备与手动发送，关闭或切换来源后可恢复未完成标注。
- **子代理账号策略并入详情页**：使用提供商折叠列表与账号选择，和代理配置统一保存；列表显示规则摘要，切换代理或账户页保留账号草稿。
- **浏览器标签并入工作台标签行**：网页与 Git、Changes 等工具共用工作台标签行，可单独拖动、并排或浮出；地址、缩放、浏览空间与控制权集中在一行工具栏。
- **折叠卡片状态摘要**：折叠的 Git／Changes 卡片在标题右侧保留摘要——Git 报工作区文件状态计数与领先／落后，Changes 报最近一轮的文件数与行数增减；悬停可看完整拆分，展开后的正文与操作不变。
- **Environment 卡片快捷跳转**：变更行改为打开 Changes 面板；分支行仍打开 Git。
- **右侧栏与内容卡片精简**：简化边框与工具条；添加工具、组切换及隐藏侧栏集中在标签菜单中，卡片仍支持拖动、双击和键盘调整高度。
- **对话小地图左移**：对话小地图及配套浮层移到正文左侧，保持正文与 Composer 对齐；窄列仍使用原生滚动条。
- **Composer 项目上下文条按需显示**：仅在尚未发送消息的新对话中显示；已有对话通过顶栏查看项目和分支。
- **顶栏窗口标签栏模式**：主区没有对话时，顶栏显示对话和工具窗口标签，支持聚焦、关闭及新建；项目、分支、标题与 Fork/Handoff 操作随各自窗口显示。

### Fixed

- **Windows 关窗退出流程**：Windows 托盘不可用时关闭主窗口先走未保存文件确认与 Host 关停，不再被内置浏览器的隐藏窗口阻止退出；macOS 仍隐藏到 Dock，独立窗口继续保留。
- **特殊文件名与脚本换行符**：文件查看器保留 macOS/Linux 的合法反斜杠文件名；命令块执行将 Unix Shell 脚本的 CRLF 换行转为 LF，本地与 SSH 共用处理。
- **可选 Office 组件签名环境**：签名任务绑定现有 `release` 环境，沿用 Runtime 的签名密钥与审批流程。
- **Git 字面路径与监视器回收**：Git 单文件操作按字面路径执行，子目录工作区的 Git、Explorer 徽章和文件 Diff 使用一致路径，避免覆盖未选择的文件；工作区身份淘汰时释放文件监视器。
- **Bridge 丢事件恢复与中途操作并行**：Bridge 丢事件后继续结算在途请求并恢复快照；后台作业取消、子 Agent 终止和 BTW 中途操作不再等待主回合结束。
- **分页重同步与索引失效**：修复主、子对话分页重新同步后卡住，以及子 Agent 历史追加和 `@` 文件索引未失效的问题。
- **文档资源释放与 favicon 限流**：Renderer 重载、崩溃和关闭时释放旧文件资源并拒绝迟到的终端创建；favicon 超限时立即停止读取。
- **SSH 代理认证、公共出口校验与依赖更新**：SSH 网络代理要求连接认证，本机出口只连接已解析并检查的公共地址；修复可选 Web 传输的同源 GET 启动，并更新 Runtime ZIP 解码、Electron 和相关安全依赖。
- **后台任务卡片状态与离线空态**：可靠保留活动任务与已读服务日志，修复取消确认期间的任务替换、独立窗口摘要刷新和离线空态；打开已结束任务时自动展开并定位，隐藏任务不再因状态读取生成小组件。
- **子代理账号规则作用域**：账号规则只更新当前子代理的全局条目，避免将项目／会话生效配置写入全局；保留高优先级覆盖并显示其生效规则。
- **最小化最后对话窗口保留会话**：最小化最后一个可见对话窗口后保留该对话，仅在关闭最后一个对话视图时新建空对话。
- **中止后消息恢复与伴随附件**：中止后的待恢复消息保留主 Worker，直到显式恢复或删除；技能提示和附件随所属消息一起编辑、提升或删除。
- **服务等待停止与进程代次绑定**：服务等待就绪时可及时停止，启动等待始终绑定原进程代次。
- **超大会话读取与压缩来源保留**：大于 8 MiB 的会话仍可查看标题；长会话压缩阈值读取和 IDA 翻页减少重复扫描。实时对话消息与压缩记录保留完整 Runtime 来源信息。
- **卡片越界与横向滚动溢出**：修复 Changes 轮次标签过早省略、Agents 卡片拉高后行高异常和底边越界，以及用量热力图和首页 Token 日历造成整页横向滚动的问题。
- **统计页返回导航**：统计页返回按钮现在回到首页。
- **并排对话评测共享与导出减负**：并排对话共享后台评测任务与报告；准备失败和应用关闭时释放 Worker，导出结果不再逐页重读整份文件。
- **评测进度合并刷新**：评测进度事件合并刷新，避免慢查询叠出多条轮询链；隐藏窗口暂停读取，返回时立即刷新，后台任务继续运行。
- **浏览器空会话存档抑制**：浏览器临时加载状态不再反复写入标签存档，读取未使用浏览器的聊天不再积累空会话记录。
- **托管 Runtime 日常启动提速**：已验收的签名托管 Runtime 日常启动复用兼容性验收结果；文件、激活记录或验证契约变化时重新完整自检，保留每次文件内容检查和真实握手。大文件校验使用短生命周期 Worker，本地版本并行查找，减少启动等待。
- **空会话重连身份保留**：修复尚未发送消息的空会话在重连时因未保存而出现 “Session not found”；Bridge 就绪前保存会话身份，重连保留同一个会话。
- **SSH 重连上下文同步与 Web 连接释放**：SSH 重连时丢弃旧上下文结果，等待上下文期间失去同步的命令不会发送；Web 上下文关闭失败时仍释放本地连接。
- **Runtime 电脑控制能力元数据**：修复 Runtime 产物元数据遗漏电脑控制能力导致的能力哈希不匹配。
- **生产预览源码监听回收**：生产预览只保留一份递归源码监听，停止后释放监听器并停止调度重建。

<details>
<summary><strong>Release 底下那一堆附件都是干嘛的？（防误下指南）</strong></summary>

每次发版 GitHub Assets 列表里都有二十多个文件，普通用户**只需要认准最上面表格里的 `Setup.exe` 或 `.dmg`**，其余都是给自动更新器或远端部署准备的「口粮」：

- `OMP-Studio-Setup-0.2.0-windows-*.exe` / `OMP-Studio-0.2.0-macos-arm64.dmg`：**人类用的桌面安装包**，下这个就对了。
- `OMP-Studio-0.2.0-macos-arm64.zip`：macOS 应用内增量更新用的载荷包，首次安装请优先用 `.dmg`。
- `OMP-Studio-Runtime-18.18.0-studio.1-*.zip`：内置签名 Runtime 独立更新包，由 Studio 自动管理验签与激活，**切勿手动解压覆盖进安装目录**。
- `omp-studio-remote-0.2.0-*` 与 `remote-environment-*.json`：SSH 远端工作区自动部署用的环境归档与 Ed25519 签名清单。
- `updates-*.json`、`update-index*.json`、`*.blockmap`：自动更新目录与差分块映射，无需手动打开。
- `Source code (zip / tar.gz)`：GitHub 自动打包的纯源码（不含子模块与编译产物），不能直接运行。

</details>
