# OMP Studio 0.1.10

Runtime 升级至 **OMP 18.10.4 / 18.10.4-studio.8**。本次把会话迁移、Worktree、存储压缩、代理账号池和新的 Plan 评审能力接入现有工作台，并提供 Windows 与 macOS 安装包。

## 安装下载

| 平台 | 安装包 |
|---|---|
| Windows x64 | [下载 Setup](https://github.com/the-snowpear/omp-studio/releases/download/v0.1.10/OMP-Studio-Setup-0.1.10-windows-x64.exe) |
| Windows ARM64 | [下载 Setup](https://github.com/the-snowpear/omp-studio/releases/download/v0.1.10/OMP-Studio-Setup-0.1.10-windows-arm64.exe) |
| macOS Apple Silicon（M 系列，macOS 13+） | [下载 DMG](https://github.com/the-snowpear/omp-studio/releases/download/v0.1.10/OMP-Studio-0.1.10-macos-arm64.dmg) |

旧版本请使用完整安装包升级。应用和 Runtime 更新的最低兼容应用版本为 **0.1.10**；本次不会更新独立安装的全局 OMP CLI。

Mac 用户将应用拖入「应用程序」。本版采用 **ad hoc 签名，尚未经过 Apple 公证**；首次打开被拦截时，可到「系统设置 → 隐私与安全性」选择「仍要打开」。更新后，系统可能再次询问麦克风、文件夹或钥匙串授权。Windows Setup 尚无 Authenticode 签名；Runtime 与应用更新目录使用既有 Ed25519 发布密钥验签。

## 新功能

- **会话迁移与诊断导出**：历史页新增「迁移与导出」。可以打包会话及工件、导出匿名诊断包、检查归档并选择目标工作区。导入遇到同 ID 会话时创建新分支，保留本地副本；导入结果可重新查询，源副本交接另行确认。
- **会话 Worktree**：设置页和 Git 侧栏支持创建、打开、复制未提交修改及审核移除。新会话可以先选择当前目录或独立 Worktree；第一条消息会等待目录准备完成。退出清理会复查改动与提交，需要确认但应用已关闭的目录会保留，可从管理面板手动审核。
- **透明存储压缩**：诊断中心先扫描闲置会话，再显示候选文件与空间占用。确认后使用 NTFS/APFS 原生压缩；跳过活动会话和审核后已变化的文件，保留完整可读历史。
- **代理与模型设置**：模型配置新增代理 OAuth 账号池、按模型压缩阈值及实际触发点预览；扩展上下文需确认。新增回退条件、额外指令文件、结构化任务结果、Git 工作区保护和本地语音速度设置。
- **Plan 与 Ask**：Plan 支持原生执行档位和扩展响应，保留批注及清理/压缩/保留上下文的执行方式。Ask 支持折叠，回答、备注和附件不丢失；快捷键为 Alt+H，Mac 为 ⌥H。
- **下一条消息建议**：默认关闭；开启后通过当前模型预测下一条消息，会产生额外模型调用与用量。接受建议只填入草稿，不自动发送。本地词语补全继续保留。
- **评测与后台输出**：评测页可选择 Judge 模型；后台工具在当前回合结束后仍持续更新原卡片，取消和重连后的结果按作业身份恢复。

新面板支持中英文和明暗主题，预览演示与真实数据分别接入；演示操作不会写入 Host。

## 兼容与修复

- 跟随上游移除子代理单次模型覆盖，统一使用代理配置中的模型及候选链。旧覆盖请求会明确拒绝。
- 移除上游已取消的 Codex Code Mode 入口；保留旧字段读取兼容，新版拒绝写入。
- 对齐新版 IPC、会话恢复、标题、图片预算、压缩策略与模型目录。日期生效价格不再误标为非高峰折扣。
- 共享浏览器遵循原生 detach 限制；复用工具调用 ID 时，不再把旧后台作业结果写到新工具卡。
- Mac 的 Option+H 按物理键码识别，避免键盘布局产生特殊字符后快捷键失效；忽略输入法组合和长按重复事件。
- Worktree 识别兼容 Mac 临时目录别名和 Windows 短路径；自动进入独立目录时同步更新工作台项目、文件树及分支。

账号凭据导入/导出 GUI 暂缓，现有账号配置继续可用。

## 验证范围

Windows 本地完成全量源码检查、824 项 Runtime 补丁测试、29 项桌面端到端验收、旧版安装/回滚循环和 18 项 Chromium 性能门禁。正式发布包在 Windows x64、Windows ARM64、macOS arm64 原生 runner 上重建，并通过源码、补丁重放、签名、安装包审计、更新目录及打包版 Electron 验收后发布。

自动化桌面验收覆盖会话归档传输、真实/演示页面、Ask 附件和 Worktree 生命周期，全程不发起模型请求。Mac Gatekeeper 首次放行、物理输入法、麦克风授权，以及真实付费模型、授权 IDA、生产 Skillshare 和重置券消耗，不属于本轮自动化验证；自动化通过不等同于这些人工场景已全部验证。
