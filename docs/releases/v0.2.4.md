# OMP Studio 0.2.4

0.2.4 改善了会话切换、流式输出和归档的稳定性，并修复了保存自定义模型时凭据被改写、深色主题下用户消息链接不可见的问题。内置 Runtime 更新为 **18.20.2-studio.14**。 [完整变更记录](https://github.com/the-snowpear/omp-studio/compare/v0.2.3...v0.2.4)

## 模型与对话

- 保存或反复编辑自定义提供商时，保留数字形式、含引号和特殊字符的凭据，避免 Runtime 因类型错误而忽略整个自定义模型配置。感谢 @kenny-forge 提供修复和复现。 [#42](https://github.com/the-snowpear/omp-studio/issues/42) · [#43](https://github.com/the-snowpear/omp-studio/pull/43)
- 用户消息中的 Markdown 链接用气泡正文颜色显示，并始终保留下划线。深浅主题、键盘焦点和选中文本时均可读。感谢 @aEgoist 提供复现。 [#45](https://github.com/the-snowpear/omp-studio/issues/45)
- 切换会话时更快展示近期会话的内容，并保留各自的草稿、滚动位置和展开状态。长对话流式输出时减少重复渲染与语法高亮，关闭会话时释放相应终端资源。

## 稳定性

- 修复归档失败后回滚可能丢失会话、多窗口重复执行快捷键，以及预览模式意外写入实际设置的问题。
- 修复二级页面审批卡和表单有时无法操作、未保存文件的关闭对话框卡住，以及切换界面语言时草稿或连接被重置的问题。
- 修复评测图片导入的目录约束、Runtime 流式异常处理和更新启动恢复判断。 [综合审查合并](https://github.com/the-snowpear/omp-studio/commit/eff1617dafb7f016925b240db7401028a0528b92)
