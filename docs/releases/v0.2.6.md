# OMP Studio 0.2.6

修复 0.2.5 桌面版启动时出现 `ERR_MODULE_NOT_FOUND`、主窗口无法打开的问题。安装包已补齐手机访问所需的 HTTPS 证书依赖。内置 Runtime 为 **18.20.2-studio.15**。 [问题 #50](https://github.com/the-snowpear/omp-studio/issues/50) · [完整变更记录](https://github.com/the-snowpear/omp-studio/compare/v0.2.5...v0.2.6)

## 下载安装

如果 0.2.5 无法启动，请下载并运行适用于当前系统的 0.2.6 安装包。可以正常打开的桌面版本也可在「设置 → 更新与维护」检查更新。Linux 包需要支持 AVX2 的 x64 处理器和 glibc 2.39 或更新版本。 [安装指南](https://github.com/the-snowpear/omp-studio/blob/v0.2.6/docs/getting-started.md)
