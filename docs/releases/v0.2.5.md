## 新功能

- **WSL 2 工作区**。在空白对话输入框上方打开「工作位置」，选择已初始化的 WSL 2 发行版和项目目录。Agent、Git 和终端使用发行版的工具链。可以从资源管理器定位项目文件，也可以在 VS Code 的 WSL 窗口打开项目。发行版重启时，Studio 尝试恢复连接并报告 Host 实例变化。 [WSL 工作区](https://github.com/the-snowpear/omp-studio/blob/v0.2.5/docs/wsl-workspaces.md)
- **手机访问**。在桌面「设置 → 手机访问」选择本地项目和局域网地址，在手机上信任桌面证书后扫码配对。手机可打开所选项目的已有对话、发送消息、停止回合和处理单次工具审批。桌面可随时撤销授权。 [手机访问](https://github.com/the-snowpear/omp-studio/blob/v0.2.5/docs/mobile-access.md)

## 修复

- Advisor 审阅意见按发生顺序显示在桌面和手机对话中。已保存的意见重开会话后仍可看到，桌面复制时会保留来源。 [#46](https://github.com/the-snowpear/omp-studio/issues/46) · [#47](https://github.com/the-snowpear/omp-studio/pull/47)
- 切换项目时，会话继续显示在所属项目下，避免重复或残留会话行。 [#48](https://github.com/the-snowpear/omp-studio/pull/48)
- 对话里的文件链接在当前工作区正确解析。目录链接打开文件浏览器，确认缺失的路径显示为普通文本。已打开的目录在切换语言后保留。 [#49](https://github.com/the-snowpear/omp-studio/pull/49)
- 恢复原生提问表单的分页，可拖动调整提问卡片高度。
- 可在「原生登录与凭据」配置 OpenCode Go 或 Zen 的 API Key，并核对授权模型目录。
