# OMP Studio 0.1.14

本次集中完善 Windows 安装程序，修复安装位置不符和安装完成后 Setup 残留的问题，并改进安装进度、运行中重试和原生回退体验。内置 Runtime 继续使用 **OMP 18.12.6 / 18.12.6-studio.9**。

## 安装下载

| 平台 | 安装包 |
|---|---|
| Windows x64 | [下载 Setup](https://github.com/the-snowpear/omp-studio/releases/download/v0.1.14/OMP-Studio-Setup-0.1.14-windows-x64.exe) |
| Windows ARM64 | [下载 Setup](https://github.com/the-snowpear/omp-studio/releases/download/v0.1.14/OMP-Studio-Setup-0.1.14-windows-arm64.exe) |
| macOS Apple Silicon（M 系列，macOS 13+） | [下载 DMG](https://github.com/the-snowpear/omp-studio/releases/download/v0.1.14/OMP-Studio-0.1.14-macos-arm64.dmg) |

Windows 升级前，请在系统托盘中右键 OMP Studio 并选择「退出」；关闭主窗口仍会隐藏到托盘。安装器发现应用运行时可留在原处，退出应用后点击「已退出，重试」。会话与设置保留。

## 修复与改进

- **目录与退出（[#12](https://github.com/the-snowpear/omp-studio/issues/12)、[#6](https://github.com/the-snowpear/omp-studio/issues/6)）**：自选目录不再被重置为 AppData；更新、修复沿用已有目录。完成后退出图形宿主与隐藏的 NSIS 进程。
- **真实安装状态**：进度读取 NSIS 数值和阶段，准备阶段显示活动指示；失败时显示「安装未完成」。文件写入期间不能取消，不再承诺未经实现的回滚。
- **保留选择**：更新和修复沿用已有桌面图标状态；完成页显示实际写入位置，关闭按钮也遵循「运行 OMP Studio」选择。
- **中文路径与包审计**：NSIS 和图形宿主使用同一套 Windows INI 读取规则，正确处理中文目录；审计明确检查本次版本与架构的 Setup，不再误选目录里残留的旧安装包。
- **运行中重试**：提示从托盘退出并可直接重试，不强制终止任务，也不误判其他目录的 Studio/OMP。ARM64 宿主支持检查原生进程。
- **完整回退向导**：缺少 WebView2 或图形宿主启动失败时，可在原生向导中选择目录、确认修复/降级并完成安装。
- **界面完善**：保留紫色四步向导，精简文字，修复遮挡，改善明暗主题、长路径、键盘导航、弹窗焦点与发行说明链接。ARM64 显示真实目标架构；预览带「演示」标记。
- **宿主隔离**：安装 UI 与浏览器缓存使用当前账户的独立目录，退出时清理，不再授予共享缓存的 Users 写权限。

0.1.13 已修复的 Windows/macOS **Studio client unavailable** 启动问题继续包含在本版（[#11](https://github.com/the-snowpear/omp-studio/issues/11)、[#6](https://github.com/the-snowpear/omp-studio/issues/6)）。六种 SSH 远程环境包继续随 Release 提供。

Windows Setup 尚无 Authenticode 签名。macOS 包仍采用 ad hoc 签名，尚未经 Apple 公证。Runtime 与更新清单使用既有 Ed25519 发布密钥验证。
