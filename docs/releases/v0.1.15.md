# OMP Studio 0.1.15

内置 Runtime 升级至 **OMP 18.13.2 / 18.13.2-studio.10**，新增会话预算、上下文查看、草稿听写和本地会话文件编辑，并修复托管 Runtime 登录路径。

## 安装下载

| 平台 | 安装包 |
|---|---|
| Windows x64 | [下载 Setup](https://github.com/the-snowpear/omp-studio/releases/download/v0.1.15/OMP-Studio-Setup-0.1.15-windows-x64.exe) |
| Windows ARM64 | [下载 Setup](https://github.com/the-snowpear/omp-studio/releases/download/v0.1.15/OMP-Studio-Setup-0.1.15-windows-arm64.exe) |

升级前请从系统托盘选择「退出」，再安装对应架构的完整 Setup；会话和设置保留。本版应用与 Runtime 更新的兼容基线为 **0.1.15**，旧版本请使用完整安装包升级。六个平台的 SSH 远程环境包随本版提供。

## 新功能与改进

- **会话费用预算**：设置 USD 警告和上限，显示主会话、子代理和旁路请求的累计费用。上限拦截下一次请求，已运行的请求仍可能使总额超出上限。
- **只读上下文查看器**：从 Token 菜单或命令面板打开，分类、筛选和分页查看打开时的快照，关闭后释放。
- **草稿听写**：明确停止后才把转写填入草稿；取消不提交。使用配置的本地或云端 STT，云端服务可能计费；与 Live 互斥，远端目标暂不转发本机麦克风。
- **本地文件与恢复范围**：原地编辑 `local://` 会话文本，保存时检查外部修改；历史页支持当前目录或同仓库 Worktree 范围，恢复时跟随继续副本。
- **原生设置**：WATCHDOG 作用范围与推理开关、受限目录逐次审批、空闲回顾/压缩、自动压缩日志，以及不加载上下文指令文件的新会话入口。
- **Ask、BTW 与模型发现**：保留备注选项归属；BTW 支持图片和原生 side 命令，并保留停靠切换中的完整草稿；支持服务端 reasoning 配置和更新后的模型目录。
- **更新体验与构建**：改善窄窗口更新弹窗和下载状态文案，复用并预热 Electron、NSIS、WebView2 与原生模块缓存。

## 修复与已有修复版本

- **本版修复 #14**：模型页 OAuth 登录和模型刷新优先使用应用安装的托管 Runtime，无需额外把 `omp` 加入系统 PATH。
- **本版启动探测隔离（#3）**：探测显式固定临时工作区，并隔离继承配置，避免自动切到共享临时目录后加载外部扩展。用户报告的持续创建进程问题仍需升级后复测。
- **0.1.13 已修复 #11**：`Studio client unavailable` / preload 加载 `node:child_process` 失败，本版继续包含该修复。
- **#6 分阶段修复**：新建会话租约及 Runtime 兼容提示在 0.1.12 修复，preload 启动在 0.1.13 修复，Setup 完成后残留在 0.1.14 修复。关闭主窗口仍会隐藏到托盘；应用退出残留的报告继续跟进。
- **#2 的已完成项**：独立界面/终端/输出字体和字号、统一设置控件已于 0.1.11 提供；整体布局建议继续保留。

本版通过源码检查、完整 UI 测试、99 项打包/更新工具测试，以及 884 项 Runtime 补丁测试与 CLI smoke。正式附件由原生 runner 构建、签名清单验证和打包审计后发布；真实 OAuth 账号、物理麦克风与付费请求不属于本轮自动化验收。

Windows Setup 尚无 Authenticode 签名。Runtime 与更新清单使用既有 Ed25519 发布密钥验证。
