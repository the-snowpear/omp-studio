# OMP Studio 0.1.12

本次加入可调对话宽度与窄窗口布局，修复新建会话租约冲突、Runtime 更新兼容性提示和统计页白屏，并改进 SSH 私有环境准备与联网。Runtime 为 **OMP 18.12.6 / 18.12.6-studio.9**。

旧版本遇到 Runtime 更新阻塞时，请退出旧应用后使用完整安装包升级。本次 Runtime 的最低桌面版本为 **0.1.12**；不更新独立安装的全局 OMP CLI。Windows Setup 尚无 Authenticode 签名；Mac 采用 ad hoc 签名，尚未经过 Apple 公证，首次打开被拦截时可在「系统设置 → 隐私与安全性」选择「仍要打开」。Runtime 和更新清单使用既有 Ed25519 发布密钥验证。

## 新功能与改进

- **对话宽度（[#7](https://github.com/the-snowpear/omp-studio/issues/7)）**：在「设置 → 常规 → 对话宽度」或工作台对话菜单中选择标准（768px）、宽屏（1024px）、铺满、自定义（640–1440px）。窄窗口临时压缩或隐藏面板，恢复空间后沿用首选布局；调整宽度时保持长对话的阅读位置。[使用说明](https://github.com/the-snowpear/omp-studio/blob/v0.1.12/docs/conversation-width.md)。
- **中断后继续**：对话中止或报错后，空输入框提供继续入口；正常完成、正在运行、等待交互或编辑队列时不会误触发额外调用。
- **SSH 环境准备**：连接时自动识别系统并请求安装确认，准备独立 Node、Host、签名 Runtime。随发布提供 Linux、Windows、macOS 的 x64 / ARM64 六种远端环境包；桌面安装包仍为上表三种平台。
- **SSH 模型与联网**：复用本机模型配置、API Key 和凭证服务，OAuth 刷新令牌与 MCP 凭证留在本机。支持远端优先、仅远端、仅本机出口；远端连接建立失败时可通过本机出口，已发送请求不自动重放。请只连接可信服务器。[SSH 使用与限制](https://github.com/the-snowpear/omp-studio/blob/v0.1.12/docs/ssh-workspaces.md)。
- **更新设置**：自动检查和自动下载入口移至「设置 → 常规」，后台准备前再次读取开关，及时响应暂停选择。

## 修复

- **新建会话租约冲突（[#6](https://github.com/the-snowpear/omp-studio/issues/6)）**：CLI 的隐式 `autoResume` 不再影响 Studio 新建会话；历史会话显式恢复仍可用。
- **Runtime 更新兼容性（[#6](https://github.com/the-snowpear/omp-studio/issues/6)）**：检查阶段就展示最低桌面版本或协议不兼容原因，并禁用不可执行的更新入口；准备好兼容桌面后可一起更新。已被本机更高版本取代的旧更新事务会被丢弃。
- **统计页白屏与外部浏览器**：内嵌 OMP Stats 启动时不再额外打开系统浏览器；Renderer CSP 不再错误注入统计仪表盘。
- **启动诊断**：Runtime 自检超时后清理子进程树，保留启动阶段日志。此项不表示已解决报告者机器上的所有启动故障。
- **布局与终端**：修正窄窗口面板优先级残留、固定弹层定位、无实际重排时的滚动锚定释放，以及终端自动调整尺寸抢焦点。
- **SSH**：改善主机名与目录冲突提示，修复空模型文件阻断同步，以及 Intel macOS 远端环境依赖安装检查不匹配。

## 验证与范围

源码审查后执行架构、编译、全部工作区测试、打包更新工具测试与 Runtime 补丁重放检查，并对对话宽度做浏览器验收。发布流程在各目标原生 runner 构建新 Runtime、验证签名和架构、审计安装包并核对上传摘要；所有选定平台成功后发布。

SSH 仍是开发预览，真实密码登录、完整跨平台连接、OAuth 刷新及模型执行需继续实机验收。未在 #6 报告者机器上验证其配置与日志，#6 留待升级复测；源码测试和包审计不代替真实安装升级与系统权限验收。
