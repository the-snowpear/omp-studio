# OMP Studio 0.1.16

本次修复应用内更新在没有任何任务运行时仍拒绝重启的问题，并恢复 macOS Apple Silicon 发行包。内置 Runtime 继续使用 **OMP 18.13.2 / 18.13.2-studio.10**。

## 安装下载

| 平台 | 安装包 |
|---|---|
| Windows x64 | [下载 Setup](https://github.com/the-snowpear/omp-studio/releases/download/v0.1.16/OMP-Studio-Setup-0.1.16-windows-x64.exe) |
| Windows ARM64 | [下载 Setup](https://github.com/the-snowpear/omp-studio/releases/download/v0.1.16/OMP-Studio-Setup-0.1.16-windows-arm64.exe) |
| macOS Apple Silicon（M 系列，macOS 13+） | [下载 DMG](https://github.com/the-snowpear/omp-studio/releases/download/v0.1.16/OMP-Studio-0.1.16-macos-arm64.dmg) |

Windows 升级前，请在系统托盘中右键 OMP Studio 并选择「退出」；关闭主窗口仍会隐藏到托盘。macOS 首次打开被拦截时，可在「系统设置 → 隐私与安全性」选择「仍要打开」。会话与设置保留。

0.1.15 只提供 Windows 桌面包，macOS 用户请用本版完整安装包升级；本版起 macOS 重新随 Release 提供 DMG、App ZIP 与 `updates-darwin-arm64` 更新目录。

## 修复与改进

- **更新被误判为忙碌（[#17](https://github.com/the-snowpear/omp-studio/issues/17)）**：此前只要开着一个会话，点「重启更新」就会提示「后台任务仍在运行，请完成后重启更新」，从托盘退出重启后依旧。根因是会话创建时主 agent 即被登记为运行中，桌面端从未收到它的运行状态回落，而更新检查直接采信该状态。现在根 agent 的忙碌与否以会话是否仍在生成、是否有排队消息与未完成命令为准；失去会话的子代理残影不再阻塞，真正的后台代理和作业仍会推迟重启。
- **提示可定位**：更新被推迟时会列出真正占用后台的代理或作业名，不再只给一句无从处理的通用文案。
- **发布复用 Runtime**：每个平台只准备一次签名 Runtime，Windows／macOS 桌面包与 SSH 远程包共享同一份产物；main 在构建输入变化后预热六个平台的 Rust／Bun 缓存与 Windows 打包工具，供发布标签复用。预热已有 Runtime 时保留原始签名字节。

0.1.13 已修复的 Windows/macOS **Studio client unavailable** 启动问题、0.1.14 的 Windows 安装目录与 Setup 残留修复继续包含在本版。六种 SSH 远程环境包继续随 Release 提供。

Windows Setup 尚无 Authenticode 签名。macOS 包仍采用 ad hoc 签名，尚未经 Apple 公证。Runtime 与更新清单使用既有 Ed25519 发布密钥验证。
