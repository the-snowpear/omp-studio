# OMP Studio 0.1.11

Runtime 升级至 **OMP 18.12.6 / 18.12.6-studio.1**。新增记住审批、后台作业详情、模型参数推荐、字体与背景设置，并提供 SSH 工作区开发预览；同时改善 Windows 启动日志与应用更新恢复。

## 安装下载

| 平台 | 安装包 |
|---|---|
| Windows x64 | [下载 Setup](https://github.com/the-snowpear/omp-studio/releases/download/v0.1.11/OMP-Studio-Setup-0.1.11-windows-x64.exe) |
| Windows ARM64 | [下载 Setup](https://github.com/the-snowpear/omp-studio/releases/download/v0.1.11/OMP-Studio-Setup-0.1.11-windows-arm64.exe) |

本次发布 Windows 两种架构。旧版本请使用完整安装包升级；本版应用与 Runtime 更新的最低兼容应用版本为 **0.1.11**。不会更新独立安装的全局 OMP CLI。Windows Setup 尚无 Authenticode 签名，Runtime 与更新目录继续使用既有 Ed25519 发布密钥验签。

## 新功能与改进

- **OMP 18.12.6**：支持「Ask and remember」、会话级批准、按范围记住授权与忘记审批；Agent Hub 展示后台作业树、详情和 widget，对话中显示后台等待、MCP 进度及 Eval 结构化输出。能力中心可重新授权、退出或重连 MCP，历史页加入只读咨询。[迁移说明](https://github.com/the-snowpear/omp-studio/blob/v0.1.11/docs/migrations/omp-18.12.6.md)。
- **SSH 工作区开发预览**：接入远端 Host、Runtime、文件树与终端，支持凭据管理和短暂断线恢复。远端需预先导入匹配的签名 Runtime ZIP；真实账密登录仍有已知阻塞，普通终端断线后需重建。[使用方式与当前限制](https://github.com/the-snowpear/omp-studio/blob/v0.1.11/docs/ssh-workspaces.md)。
- **模型参数推荐**：根据端点元数据与内置目录推荐容量、思考模式和档位，显示目录、端点与手工来源，保留手工覆盖；目录更新需主动应用并保存。模型角色切换会映射到支持的思考档位。[配置说明](https://github.com/the-snowpear/omp-studio/blob/v0.1.11/docs/model-adaptation.md)。
- **字体与背景**：分别调整界面、终端、输出的字体与字号，支持搜索系统字体和手填名称；可将本机图片、动图、视频设为工作台或整个应用背景，并调整模糊、遮罩和透出效果。背景只保存在本机。[字体说明](https://github.com/the-snowpear/omp-studio/blob/v0.1.11/docs/fonts.md)。
- **界面与统计**：统一下拉选择器与设置控件，改善 Computer Use、主题与工作区布局；统计页内嵌原生 OMP Stats 面板，按需启动统计服务，移除旧统计 worker 和独立 Frustration 面板。会话目录复用文件头缓存，减少重复扫描。

## 启动与更新修复

- 修复 Windows 启动时部分身份查询和权限设置后台命令造成的终端短暂闪现，并将 Runtime 首装自检的标准输出与错误输出写入 Host 日志。Issue [#3](https://github.com/the-snowpear/omp-studio/issues/3) 报告的持续新增 Bun 进程、完整启动失败尚未复现，继续保留跟进；复测仍失败时请提供 `%APPDATA%\omp-studio\logs\` 下当天的 Host 日志，以及相关进程的路径和命令行。
- 更新检查与下载统一网络栈，改善镜像回退、瞬时故障重试、超时、断点续传和缓存失效处理。
- 重启更新前识别运行任务、压缩、交互、计划审阅、排队消息与后台代理，显示延期原因并保留已验证工件；修复同版本残留事务和关停失败后的恢复。[更新说明](https://github.com/the-snowpear/omp-studio/blob/v0.1.11/docs/updates.md)。

## 验证范围

发布前执行本地构建、核心回归及更新工具测试。正式发布流程在 Windows x64、ARM64 原生 runner 上构建或复用来源一致的签名 Runtime，检查安装包、签名更新目录与上传摘要，全部所选架构成功后发布。

源码测试和打包审计不代表已在 Issue #3 报告者机器上复现或解决完整启动故障，也不代替真实安装升级、付费模型、OAuth、SSH 账密和系统权限的人工验收。
