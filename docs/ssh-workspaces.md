# SSH 工作区

当前为开发预览功能，尚未发布。界面在本机，项目文件、Git、OMP Runtime 和模型执行在远端；不创建整个项目的本机镜像。

## 连接

在工作台输入框上方，点击“项目 / 分支”右侧的 **此计算机**，选择 **添加 SSH 连接**。填写连接名称、主机地址或系统 SSH 配置别名、用户名、可选端口与远端系统。认证方式可以选择 **系统 SSH 配置 / 密钥 / agent** 或 **用户名和密码**。

账密模式要求独立填写用户名。保存的配置不包含密码；点击连接时弹出密码框，断开后再次连接需要重新输入。密码仅保留在本次连接的主进程内存中，通过一次性 askpass 票据交给系统 SSH，不进入 argv、环境变量值或临时文件。SSH 子进程环境中只有 askpass 组件位置和短时票据。

账密模式当前仅支持服务器的 SSH `password` 认证，不支持 keyboard-interactive、OTP/MFA、登录时改密码或跳板机。密钥/agent 模式继续支持系统 config 中的跳板配置。Windows 构建会使用 .NET Framework 4.x 的 `csc.exe` 生成无窗口 askpass 辅助程序；macOS 构建复制可执行脚本到应用资源目录。Windows helper 和隔离认证回归已通过；真实密码登录仍未验收，两台授权服务器均禁用密码认证，未修改服务器配置。独立验收记录见 [验收报告](../doc/ssh-workspace-test-report.md)。

首次连接会确认是否在远端用户目录准备 OMP Studio Host。需要：

- 本机系统 OpenSSH Client；Windows 使用系统自带 `ssh.exe`。
- 已在系统 SSH 完成主机密钥信任。密钥模式需可使用密钥或 ssh-agent 非交互登录；账密模式由应用密码框提供本次连接的凭证。应用不保存 SSH 密码，不关闭主机密钥验证，不转发 agent。
- 远端 Node.js 22+；工作区使用 Git 时还需远端 Git。暂不自动安装 Node。
- 远端 Linux、Windows 或 macOS。已实测 Windows x64 与 Ubuntu x64；macOS 实测暂缓，不能视为已认证兼容。

选择远端绝对目录后，项目、文件树、`@` 文件提及和 Git 面板读取这台远端的文件。连接失败不会切换到一个假的 SSH 工作区，也不会悄悄回落到本机执行。

发送消息后，执行位置入口仍保留。其他页面也显示当前工作位置。切换工作位置保留各自草稿和已有终端；已有会话、收据和终端不会改投另一台机器。已提交给 Runtime 的消息队列留在原 Runtime。

## Runtime 与模型配置

SSH Host 可以在没有 Runtime 时浏览项目和 Git，但不能生成回复。在执行位置菜单中选择 **导入签名 Runtime**，导入与远端 OS / CPU 架构匹配的 ZIP。只接受桌面应用既有可信公钥验证通过的制品，不信任 ZIP 自带的公钥。

安装前必须完成远端任务、审批并关闭该目标终端。安装会验证签名、上传并校验文件、等待 Host 及 Runtime 退出、运行自检、激活后重连。不会修改正在运行的 EXE，不注册系统服务，也不改 `sshd` 或防火墙。

远端使用独立的 OMP agent 目录，模型设置可在连接后的 **模型配置** 页面管理。本机供应商凭证不会复制到远端；也不接管远端桌面已打开的会话。项目级 Skills / MCP 等仍按 OMP 现有发现规则运行。独立 agent 目录不等于隔离所有系统配置：OMP 用户级插件和统计等仍可能读取远端账户的共享根目录。

| 平台 | Host 默认数据根 |
|---|---|
| Linux | `$XDG_DATA_HOME/omp-studio/remote`，未设置时 `~/.local/share/omp-studio/remote` |
| Windows | `%LOCALAPPDATA%\omp-studio\remote` |
| macOS | `~/Library/Application Support/omp-studio/remote` |

其下 `versions/` 存放版本化 Host，`state/` 保存工作区注册表与私有连接信息，`state/agent/` 是独立 agent 配置，`state/runtimes/` 为签名 Runtime 安装。

## 终端与断线

底部终端是真实 SSH PTY，进入选定远端工作区，支持输入、尺寸调整和 Ctrl-C。终端标签属于创建时的目标；切换机器后仍可切回查看。点击关闭终端会结束它，不向当前前台程序输入 `exit`。普通终端不承诺 SSH 断线后的 Shell 恢复，需重新建终端；持久任务可由操作者自行选用相应远端工具。

**断开 SSH 不会停止远端 Runtime 任务。** Host 在无连接且无任务、待处理命令或审批时闲置约 30 分钟退出。恢复按以下规则执行：

- **短暂迟滞**：每 15 秒检查 Host 响应，一次检查最多等待 15 秒。首次未响应显示“响应迟缓”并暂停新操作；连续两次未响应才放弃控制通道。单个业务请求超时只触发健康检查，不直接判定远端任务失败。
- **偶发断线**：仅已成功连接过的会话自动恢复。优先附加已部署的原 Host，不重新上传、不调用 start、不重启 Runtime。退避为约 1 / 2 / 4 / 8 / 15 秒（±20% 抖动），最多 5 次且总预算 120 秒；连接连续稳定 60 秒后才重置连续抖动的预算。
- **停止条件**：认证拒绝、主机密钥变化、配置/协议不兼容、Host 已停止或被其他桌面占用，立即停止自动恢复。预算耗尽也停止，显示具体原因并提供手动重连。首次连接失败不自动反复尝试密码。
- **恢复同步**：控制通道恢复后还需同步 Client 快照，再开放写操作；对话、文件树、Git 和历史库存主动刷新。保留当前页面、未保存编辑和目标，不通过重挂整个工作台恢复。若 Host 实例已改变，会明确提示，不能保证原任务仍在运行。
- **取消**：等待重试和同步期间可取消。主动断开、整页导航/Renderer 崩溃期间的未完成连接、应用退出会终止恢复并清理密码。已稳定建立的连接不会因为页面重载被当作连接准备而关闭；远端任务不随之停止。
- **密码生命周期**：已验证密码仅在当前连接及最多两分钟的网络恢复窗口内保留；取消、最终失败或主动断开后清除。认证拒绝立即停止，不继续尝试同一密码。

**未收到最终确认的命令仍是结果未知，不自动重发。** 重连不等于 Git 操作、文件写入或模型任务已成功；查看对话、Git 状态或远端文件确认结果后再决定是否重新操作。终端使用独立 SSH PTY，不自动重开、不重放按键；控制通道恢复不会恢复已经退出的 Shell。

同一远端账户的数据根只允许一个桌面附加客户端。本次桌面的恢复通道凭仅存内存的连接标识和递增序号替换自身遗留的旧通道，迟到的旧连接不能反向抢占；另一个桌面或重复别名没有该标识，仍须先断开原连接。升级远端 Host 不会强行踢走其他客户端。

## 当前边界

- SSH alias 直接复用系统 config；暂未提供别名枚举和首次指纹确认。账密弹窗、Windows helper 和协议层已验证，真实密码登录仍阻塞；多因素、密码变更和账密跳板连接不在本轮范围。
- 图片可作为内容附件发往远端；普通本机文件上传尚未接入，请用 `@` 选择远端文件。
- 远端产物的本机预览/下载、外部编辑器与文件管理器打开、本机媒体/浏览器/屏幕转发、SSH 终端录制暂不支持；相关本机旁路不会操作本机同名路径。
- Runtime 自动下载尚未接入，使用签名 ZIP 导入。Linux Runtime 平台表和 ELF 校验已接入，正式制品仍应在原生 Linux runner 构建并执行完整自检；本次跨平台测试构建不作为发布制品。
- macOS 实机、macOS 客户端出站 SSH、跳板/MFA/休眠重启、真实模型文件修改尚未验收。
