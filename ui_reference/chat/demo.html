设计系统

颜色方案

深色 Slate 基调 + 天蓝/橙色强调色，专业开发者工具风格

--accent-cool: #38BDF8 --accent-warm: #F97316 --surface-0: #0B0E14 --text-primary: #F8FAFC

间距系统

基于 8pt 网格的系统化间距，保持视觉节奏

--space-2: 8px --space-4: 16px --space-5: 24px --space-6: 32px

动画参数

流畅的缓动曲线和适中的时长，提升交互体验

--duration-fast: 150ms --ease-out: cubic-bezier( 0.16, 1, 0.3, 1 )

字体系统

系统字体栈 + JetBrains Mono 等宽字体

--font-sans: Inter, system-ui --font-mono: JetBrains Mono font-size: 15px base

快速开始

三种方式预览界面：

1. 直接打开

在浏览器中直接打开 index.html

2. 使用本地服务器

# Python python -m http.server 8080 # Node.js npx http-server -p 8080 # PHP php -S localhost:8080

3. 集成到项目

<!-- 引入样式 --> <link rel="stylesheet" href="path/to/chat/styles.css"> <!-- 引入依赖 --> <script src="https://cdn.../marked.min.js"></script> <script src="https://cdn.../highlight.min.js"></script> <!-- 引入脚本 --> <script src="path/to/chat/script.js"></script>
