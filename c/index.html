OMP Studio 是 oh-my-pi 的桌面工作台。界面直连类型化 Bridge，不读 ANSI，也不模拟按键。

下载D 看源码G

中间隔着一层类型

OMP Studio 不读屏幕上的字。Renderer 发类型化请求，Runtime 回带状态的回执，谁都不用猜对方的意思。

  • 解析 TUI 文本
  • 解析 ANSI 序列
  • 模拟按键宏
  • Studio Bridge
