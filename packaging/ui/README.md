# OMP Studio 安装向导 — 视觉方案说明

> 预览：浏览器直接打开 `packaging/ui/index.html`（无依赖静态原型）。
> 右上角可在「跟随系统 / 亮色 / 暗色」之间覆盖切换，默认跟随
> `prefers-color-scheme`；已适配 `prefers-reduced-motion`。

---

## 1. 结构与页面层次

窗口 720×480，固定三段式骨架：**标题栏（34px）→ 内容区 → 底部操作条（52px）**。
标题栏：应用图标 + `OMP Studio 安装 v1.4.2` + 最小化/关闭（关闭等价于取消）。
底部操作条：左侧一行上下文提示（步骤位置 / 当前状态），右侧按钮组，随步骤切换。

### 第 1 步 · 欢迎
左幅品牌横幅（216px）+ 右侧内容。
- **视觉焦点**：品牌横幅 —— 深紫罗兰渐变底、发光 Logo、版本徽章，底部等宽字体
  `>_ 内置 OMP Runtime 1.4.2`。这是「第一印象」的锚点。
- **信息优先级**：主标题 → 一句话说明（装什么、装完即用）→ 三条功能亮点
  （运行时 / PTY 终端 / Agent & MCP，图标 + 标题 + 一行描述）→ 底部「单击下一步继续」。
- 三条亮点即产品三大核心能力，各一行，不展开。

### 第 2 步 · 安装位置
标准控件堆叠页（NSIS 装饰最少的一页）：标头带（页标题 + 副标题）+ 内容组。
- **视觉焦点**：路径输入框 + 浏览按钮 —— 本页唯一需要用户决策的地方。
- **目录规则**：浏览选的是文件夹；若末级不是 `OMP Studio`，安装器会追加并新建该文件夹。已是产品目录或已有安装则原样使用。升级/修复/降级锁定上次目录。
- **信息优先级**：目标文件夹 → 解析提示（新建 / 原样）→ 占用说明（仅升级等情景）→ 磁盘空间 → 附加任务（开始菜单始终创建、桌面可选）→ 底部卸载说明。
- 原型左上角可切换情景：全新 / 升级 / 相同版本 / 已装更高 / 进程占用 / **卸载**（跳过目录页，三步：确认范围 → 进度 → 完成）。

### 第 3 步 · 安装进度
标头带 + 进度区 + 日志区。
- **视觉焦点**：进度条（阶段文案 + 等宽百分比 + 当前文件路径）。
- **信息优先级**：阶段与百分比 → 进度条 → 当前文件（等宽小字）→
  滚动日志（NSIS Details 风格：时间戳灰色、正文次级色、"部署运行时" 一行用
  强调色高亮、"安装完成" 用成功色）。日志自动滚到底，最新行淡入。
- 此步「上一步 / 下一步」禁用，仅保留「取消」。

### 第 4 步 · 完成
与欢迎页镜像：同样的品牌横幅 + 右侧内容，首尾呼应。
- **视觉焦点**：成功标记（描边圆 + 对勾的入场动画）→ 「安装完成」标题。
- **信息优先级**：成功状态 → 安装摘要卡片（位置 / 版本 / 运行时，键值三行）
  → 底部一行做完结动作：**「运行 OMP Studio」复选框（默认勾选）** + 发行说明链接。
- 底部操作条只留「完成」。

## 2. 配色思路

**强调色：紫罗兰，锚定应用图标。**
图标本身是 品红 `#F95BD4` → 紫罗兰 `#8B5CF6` → 蓝 `#4C8DFF` 的三段渐变。
取渐变中段的紫罗兰做 UI 强调色（最具识别度、蓝紫两端留给品牌渐变与横幅），
品牌渐变只出现在：Logo、左幅横幅、进度条填充的末端。全 UI 仅此一套彩色，
成功绿与警示琥珀仅用于状态。

| 令牌 | 亮色 | 暗色 | 说明 |
| --- | --- | --- | --- |
| `--accent` | `#6444E0` | `#9178F2` | 同一色相两档明度 |
| 实心按钮文字 | 白（≈ 6.2:1） | 深色 `#171221`（≈ 5.5:1） | 暗色提亮强调色后改用深字 |
| `--window-bg` | `#FDFDFE` | `#1D1D25` | 低饱和冷调中性 |
| 文字三级 | `#1A1A24 / #54566B / #8A8BA0` | `#ECECF4 / #A6A7BC / #6F7089` | 正文 ≥ 7:1，次级 ≥ 4.5:1 |
| 描边 | 实色发线 `#E4E4EC` | 半透明白 `rgba(255,255,255,.08)` | 暗色用透明度描边避免脏灰 |

- **亮色**靠「分层阴影 + 实色发线」立层次：窗口大投影、控件白底、输入框实描边、
  页脚底色略深一级；不用透明度灰，避免发闷。
- **暗色**靠「亮度分层 + 半透明描边」：底 `#1D1D25` → 标头 `#22222B` →
  控件 `#262631` → 控件 hover `#2D2D3A`，日志区反向下沉到 `#16161D`（内凹感）。
- **品牌横幅双主题同一套深色渐变**：它是位图，NSIS 里只有一张图；
  也让两套主题拥有同一个稳定品牌锚。

## 3. 动效方案

统一令牌：`--ease-out: cubic-bezier(.16,1,.3,1)`（expo-out，缓且稳）、
in 版与 in-out 版各一；时长四档 `130 / 220 / 360 / 620ms`。
「反馈快（≈130ms）、转场稳（≈360ms）、仪式感慢（≈620ms）」。

| 位置 | 动画 | 时长/缓动 | 意图 | NSIS 落地 |
| --- | --- | --- | --- | --- |
| 步骤切换 | 双向淡出+位移 ±14px（退 200ms / 进 360ms，含 40ms 延迟） | ease-in / ease-out | **必保**：方向感与连续性 | 降级为原生页面直切——可接受 |
| 按钮 | hover 底色+描边（130ms）、按下位移 0.5px、focus 外环 | 130/80ms | **必保**（原生即有 hover/焦点态） | 原生控件直接支持 |
| 复选框 | 对勾描边书写（200ms, 30ms 延迟）+ hover 描边变强调色 | 220ms | 可保：细节质感 | 降级为系统复选框 |
| 输入框 | focus 描边变强调色 + 2px 柔环（130ms） | 130ms | **必保** | 原生 focus 近似 |
| 磁盘计量条 | 进入页后 700ms 增长到目标值（灰段先、紫段错 120ms） | 700ms ease-out | 可降级 | NSIS 用文本「所需/可用」即可 |
| 安装进度条 | rAF 连续插值 + 顶部高光 | 逐帧 | **必保质感**（原型）→ 实际降级 | NSIS 按动作分段刷新（原型已内置分段锚点，reduced-motion 时即为分段跳变预览） |
| 进度条光泽带 | 1.6s 循环 | in-out | **可牺牲**，NSIS 直接删除 | — |
| 日志行 | 逐行淡入 + 5px 上浮（260ms），自动滚底 | 260ms ease-out | 可保 | NSIS Details 原生追加，无动画 |
| 完成页对勾 | 圆环 560ms 描画 → 对勾 320ms → 光晕 720ms；内容四段 9px 上浮错峰 | 620ms 档 | **必保仪式感**（原型）→ 实际降级 | NSIS 完成页静态位图/文本 |
| 对话框/Toast | 遮罩 180ms 淡入，卡片 260ms 上浮缩放 | ease-out | 可牺牲 | NSIS 用系统 MessageBox |
| `prefers-reduced-motion` | 全部动画/过渡降为 ~0ms；进度条改按锚点分段跳变；对勾直接显示 | — | 无障碍 | 天然满足 |

## 4. 可落地 NSIS vs 必须简化

**可直接落地（原生控件 + 位图）：**
整体三段布局、标题栏文案与图标（由安装程序窗口本身提供）、左幅品牌位图
（欢迎/完成页同一张）、标头带页标题+副标题、路径输入框 + 浏览按钮 + 系统
目录选择对话框、进度条（分段刷新）、Details 日志列表（`SetDetailsView`）、
复选框（含「运行 OMP Studio」）、按钮组与禁用态（MUI2 默认行为即覆盖
hover/focus/disabled）、所需/可用空间文本。亮色/暗色在 NSIS 原生界面下
跟随系统主题由系统绘制完成；**横幅位图双主题共用一张**（深色渐变在亮色
窗口里也成立，这正是设计它有深底的原因）。

**必须简化 / 放弃：**
步骤滑动转场（→ 直切）、对勾描边动画（→ 静态图形）、进度光泽带（→ 删除）、
进度条连续插值（→ 每动作分段跳变；节奏锚点沿用原型 PCT_KEYS）、日志行淡入
（→ 原生追加）、计量条图形（→ 两行文本）、自定义确认对话框与 Toast
（→ `MessageBox` / 安装结束直接静默启动）。

## 5. 两个差异化方向

### 方向 A —「左幅品牌栏 · 克制原生」（本原型，推荐）
MUI2 经典骨架：首末页左横幅位图、中间页干净的原生控件堆叠；彩色只出现在
品牌渐变与强调色上；白底标头带区分页面层级。
- **气质**：可信、专业、零学习成本，与 VS Code / JetBrains Toolbox 的安装体感同源。
- **取舍**：个性主要靠横幅与配色承担，惊喜感集中在对勾一刻；工程上几乎 1:1 可还原。

### 方向 B —「终端气质 · Warp 式」
去掉横幅，整窗一张深色画布：上方细进度轨贯穿四步；欢迎页中央大 Logo +
等宽字体 `dim>` 提示符作为按钮前缀；日志区做成真正的迷你终端（行首 `$`、
彩色 exit code）；底部操作条做成状态栏样式。
- **气质**：更锐的开发者识别度，第一眼就与「终端工作台」呼应。
- **取舍**：偏离 NSIS 原生观感较远（自绘比例高、亮色主题反而像二等公民），
  落地要牺牲更多；第一印象更「酷」但也更冒险。

**推荐 A**：安装器是门面不是产品本体，「克制的专业感」与图标气质一致，
且几乎是唯一能在 NSIS 里保真落地的方向。可把 B 的两个元素收成细节借用到 A：
等宽字体的 `>_` 提示符（已用于横幅底部与提示行）与终端风格日志配色（已用于日志区）。
