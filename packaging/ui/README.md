# OMP Studio 安装向导

同一套 HTML/CSS/JavaScript 用于真实 WebView2 宿主和明确标记的浏览器/Electron 演示。窗口为 720 × 480。

视觉方向：保留紫色品牌栏，配合明暗中性色、清晰文字和留白。每页只有一个主要操作。
内容顺序：介绍安装内容 → 选择或确认目录 → 查看真实进度 → 确认结果并运行应用。
交互方向：短暂的页面过渡、控件焦点反馈、完成标记入场；跟随系统减弱动画设置。

## 页面行为

1. 欢迎页说明当前账户安装，读取真实桌面与 Runtime 版本及架构；同版修复先确认。
2. 目录页显示最终安装路径、磁盘空间和快捷方式选择。更新、修复与降级锁定已有目录；写入失败保持在此页。
3. 进度页读取 NSIS 百分比与实际阶段，没有数值时显示活动指示。写入期间禁用关闭，不提供未经实现的回滚。安装程序退出或失败时显示原因与关闭入口。
4. 完成页使用 NSIS 实际写入的路径，不再次解析目录。保留运行应用的选择，标题栏关闭与「完成」行为一致；发行说明链接可实际打开。

应用运行时提示从托盘「退出」，「已退出，重试」重新检查目标目录。版本确认和运行检查独立；不会因为接受了修复就跳过退出要求。

## 无障碍与尺寸

- Tab 仅进入当前页面和当前弹窗；弹窗限制焦点范围并在关闭后还原焦点。
- Enter 激活当前按钮，或推进当前页；不会重复提交。Esc 关闭弹窗或请求退出，写入期间不取消。
- 进度条提供无障碍数值，失败提示可被读屏器读取。
- 长路径可换行，内容区可滚动；路径输入、磁盘行和提示图标有明确尺寸。
- 标题栏可切换系统、亮色与暗色主题。

## 真实与演示

`wizard.js` 的演示情景只在浏览器原型中使用；Electron 预览带「演示」标记，模拟安装但读取本机目录。真实 Setup 必须有 `installerShell` 桥接；缺失时禁用安装并显示连接失败。

演示进度可以按时间播放，真实进度只读 NSIS。真实卸载仍使用原生 MUI2；原型「卸载」仅说明删除范围。
